1

สายเงินเข้า AR (FI-Q → FI-1 / FI-1Q → Post RV)

ที่มา: SL-4 · SL-3 · SV/ARI · เงินโอนเข้าธนาคาร (A3)
ขั้นงานถัดไปแคชเชียร์/สาขาการเงิน (AR)บัญชีสถานะจะเปลี่ยนเป็นSurface
1.1บิลค้างรับถึงกำหนด → การ์ดโผล่ในคิว (โชว์อ้างอิงบิลต้นทางเสมอ)→ 1.2/1.3—เห็นการ์ดในคิว—รอรับชำระA1
1.2ทางหน้าร้าน: ลูกค้าจ่ายที่เคาน์เตอร์ → sc-payment แบ่งจ่ายได้ → เข้า FI-1→ 1.5รับเงิน + สลิปเปิด FI-1—รอประกบบิลP1 + F·FI-1
1.3ทางธนาคาร: เงินโอนเข้า → กดดึง statement (manual sync ตาม A3) → เกิด URC เข้าคิว→ 1.4—กด sync—รอจัดสรร · URCA2
1.4จับคู่ในคิว: Ref+ยอดตรง=🟢 Auto / ยอดไม่ตรง=🟡 Partial → FI-1 จัดสรรเอง / ไม่รู้ใคร=🔴 Unmatched → เลือกลูกค้า หรือบันทึกเป็นมัดจำ→ 1.5—จับคู่/ยืนยัน F2—Auto/Partial/Unmatched → จับคู่แล้ว · รอประกบ A2
1.5ประกบบิลใน FI-1 — ทั้งใบ/บางส่วน · ใช้เครดิตค้าง (SL-CN) + มัดจำ ตัดที่จุดนี้จุดเดียว→ 1.6—เลือกบิล+จำนวน—ประกบแล้ว · รอ Post F·FI-1
1.6Post RV ลง BC → บิลปิด/ลดยอด · พิมพ์ใบเสร็จจบ—Post + พิมพ์BC ปิด ledgerPosted · บิลปิด / PartialF·FI-1
2

สายเงินออก AP (FI-Q → FI-2 → อนุมัติ → จ่าย → Post PV)

ที่มา: PO-6 · ตั้งเบิกช่างนอก (สาย 9 SV) · PO-CN หักก่อนจ่าย
ขั้นงานถัดไปการเงิน (AP)ผู้อนุมัติ (CF-2.6)บัญชีสถานะจะเปลี่ยนเป็นSurface
2.1บิลตั้งหนี้ครบกำหนด (มอง 7 วันข้างหน้า) → การ์ดโผล่ในคิว→ 2.2เห็นการ์ด+ยอด——รอจ่ายA1
2.2เปิด FI-2 เลือกเจ้าหนี้ → ติ๊กบิลค้างหลายใบ · WHT auto ตามหมวดเจ้าหนี้ (แก้เรทได้) → WHT = record pending ส่ง FI-12 ห้ามออก cert ที่นี่→ 2.3สร้างใบจ่าย——ร่าง · WHT → PendingF·FI-2
2.3ส่งอนุมัติจ่าย — tier CF-2.6 · Maker≠Checker→ 2.4ส่ง+รอผลอนุมัติ/ตีกลับ—รออนุมัติจ่ายAP-1
2.4จ่ายจริง (โอน/เช็ค/เงินสด) + แนบหลักฐานสลิป F4→ 2.5โอน + แนบสลิป——จ่ายแล้วF·FI-2
2.5Post PV ลง BC → ปิด AP entry + ตัดธนาคารจบPost—BC ปิด ledgerPostedF·FI-2
3

สายค่าใช้จ่ายนอก PO (FI-4)

ค่าน้ำ/ไฟ/เดินทาง/ซ่อมแซม · WHT ไปออกที่ FI-12
ขั้นงานถัดไปผู้บันทึก (สาขา/แอดมิน)ผู้อนุมัติการเงิน/บัญชีสถานะจะเปลี่ยนเป็นSurface
3.1กรอกค่าใช้จ่าย + แนบใบเสร็จ/ใบกำกับ→ 3.2กรอก + แนบ——ร่างF·FI-4
3.2ระบุ VAT + WHT ต่อบรรทัด — บรรทัดมี WHT → record pending ไป FI-12→ 3.3ระบุ——รอ WHTF·FI-4
3.3ส่งอนุมัติ (tier CF-2.6)→ 3.4รอผลอนุมัติ/ตีกลับ—รออนุมัติAP-1
3.4ตั้งหนี้/จ่าย + Post GL ลง BCจบ——Post GLบันทึกแล้ว → จ่ายแล้ว · ปิดF·FI-4
4A

สายภาษีขาย/ซื้อ VAT (FI-7)

รวบรวม → ตรวจ → Release ล็อก → ภ.พ.30 ยื่นใน 15 เดือนถัดไป
ขั้นงานถัดไปบัญชีภาษีผจก.การเงินระบบ BCสถานะจะเปลี่ยนเป็นSurface
4A.1BC post บิลขาย/ซื้อที่มี VAT → vatEntries สะสมเข้างวดอัตโนมัติ→ 4A.2——สะสม vatEntriesPosted · สะสมในงวดBC
4A.2เลือกนิติบุคคล + งวด → ตรวจรายงานภาษีขาย (Output) / ภาษีซื้อ (Input)→ 4A.3ตรวจรายการ——รอตรวจ F·FI-7
4A.3กด Release 🔒 ล็อกรายงานแต่ละฝั่ง ห้ามแก้ย้อน→ 4A.4กด Release—ล็อกงวดReleased · ล็อกF·FI-7
4A.4พิมพ์รายงาน + สรุป ภ.พ.30 (ขาย−ซื้อ) → ยื่นจบพิมพ์ + ยื่นอนุมัติ ภ.พ.30—ยื่นแล้ว F·FI-7
4B

สายหัก ณ ที่จ่าย WHT (FI-12)

จุดออกหนังสือรับรองจุดเดียวทั้งระบบ · ภ.ง.ด.3/53 ยื่นใน 7 เดือนถัดไป
ขั้นงานถัดไปบัญชีภาษีผจก.การเงินเจ้าหนี้ (ปลายทาง)สถานะจะเปลี่ยนเป็นSurface
4B.1record WHT ไหลเข้าอัตโนมัติจาก FI-2 (จ่าย AP) + FI-4 (ค่าใช้จ่าย)→ 4B.2เห็น list สะสม——PendingF·FI-12
4B.2ตรวจรายการ + เรท (1/2/3/5% dropdown แก้ได้ก่อน Release)→ 4B.3ตรวจ/แก้เรท——PendingF·FI-12
4B.3Release 🔒 ล็อก · แก้=Reverse+สร้างใหม่ (Mgr เท่านั้น)→ 4B.4Releaseแก้หลังล็อก—ReleasedF·FI-12
4B.4พิมพ์หนังสือรับรองหัก ณ ที่จ่าย — ใบเดียวต่อรายการ ที่นี่ที่เดียว→ 4B.5พิมพ์ Cert—รับหนังสือรับรองพิมพ์ Cert แล้วF·FI-12
4B.5Export ภ.ง.ด.3 (บุคคล) / ภ.ง.ด.53 (นิติ) → ยื่นจบExport + ยื่น——รอนำส่ง → นำส่งแล้ว F·FI-12
✅ F1ชื่อสถานะใช้ได้ + ทำตารางอธิบายสถานะในโมดูล (คอลัมน์ "สถานะ" ในตารางบนคือคำอธิบายแล้ว · จะเพิ่ม legend สรุปคำในโมดูล FI ให้ dev อ่านง่าย)
✅ F2จับคู่เงินเข้า = คนกดยืนยัน ทุกก้อน · ยังไม่กำหนดวันเตือน (ค้างนานไว้ทีหลัง) · 🔮 อนาคต: ถ้าทำ API PromptPay ได้ → ระบบจับคู่ให้เบื้องต้น แล้วคนมายืนยัน (Ref1/Ref2 ตรงบิล)
✅ F3ไม่ต้องทำการ์ดเตือน — "รอกระทบยอด" เป็นสถานะ/หน้ารออยู่แล้ว ในตัว ไม่ต้องเพิ่ม alert ซ้ำ
✅ F4แนบสลิป = ไม่บังคับ · แต่มี เตือน (soft-flag) ว่า "ยังไม่แนบสลิป / ยังไม่ระบุวิธีชำระ" ก่อน Post

สายพิเศษ — Edge cases (void / เช็คเด้ง / ถอนจับคู่ / พิมพ์ซ้ำ)

จุดเงิน = เข้มสุด
รหัสuse caseวิธี / กติกาสถานะ / ปลายทาง
FI-V1void ใบรับ/จ่าย ก่อน Postยกเลิกร่าง + เหตุผลยกเลิกแล้ว
FI-V2เช็คเด้ง / ยกเลิกการจ่ายหลัง PostReverse PV (BC) → เปิด AP กลับ · แจ้งบัญชี · แนบเหตุผลReversed · AP เปิดใหม่
FI-V3จับคู่เงินเข้าผิดคน/ผิดบิลถอนการจับคู่ (unapply) → กลับเป็น URC ในคิวถอนแล้ว · รอจับคู่ใหม่
FI-V4พิมพ์ใบเสร็จ / หนังสือรับรอง WHT ซ้ำreprint + audit · WHT cert ยังใบเดียวต่อรายการ (กันได้ 2 ใบ)ไม่เปลี่ยนสถานะ
