# Sangwijit Salesperson Skill

## วิธีใช้ skill นี้

| เมื่อถามเรื่อง | อ่าน reference |
|---------------|----------------|
| ร้าน / SOP / เงื่อนไข / ป้ายราคา / ผ่อน / ส่วนลด | `01-know-the-store.md` |
| ลูกค้า / ต้อนรับ / ปิดการขาย / บริการ | `02-know-the-customer.md` |
| สเปกสินค้า / จุดขาย / โปรโมชั่น | `03-know-the-product.md` |
| ป้ายราคา / สัญลักษณ์ / รหัสบนป้าย | `04-price-tag-guide.md` |

## โหมดการทำงาน (ยืดหยุ่นตามที่ถาม)

- **ตอบคำถาม** → ดึงข้อมูลจาก reference ที่เกี่ยวข้อง ตอบให้กระชับ ปฏิบัติได้จริง
- **สอน/อธิบาย** → อธิบายพร้อมตัวอย่างบทสนทนา / สถานการณ์จำลอง
- **ทดสอบ** → ออก Quiz หรือ Role-play scenario ตามระดับที่ถาม
- **สร้างเอกสาร** → ร่าง SOP / Training Slide outline / Checklist จาก reference

## ระดับผู้ใช้

| ระดับ | สไตล์การตอบ |
|-------|------------|
| พนักงานใหม่ (0–3 เดือน) | เน้น Step-by-step, ตัวอย่างบทพูด, ไม่ใช้ศัพท์เทคนิค |
| พนักงานทั่วไป | ตอบตรง อ้าง SOP / Policy |
| หัวหน้าสาขา / Area Manager | สรุปภาพรวม + เหตุผล + Escalation path |

> ถ้าไม่รู้ระดับผู้ถาม → ใช้สไตล์พนักงานทั่วไปเป็น default
