## 4.2 สัญลักษณ์บนป้ายราคา — ความหมายและสิ่งที่ต้องแจ้งลูกค้า

| สัญลักษณ์ / ข้อความ | ความหมาย | พนักงานต้องทำ |
|--------------------|---------|-------------|
| ⭐ หรือ ✦ | สินค้าโปรโมชั่น / แนะนำ | แจ้งเงื่อนไขโปรให้ครบ |
| **ราคาขีดฆ่า** | ราคาก่อนลด | บอกลูกค้าว่าประหยัดเท่าไหร่ |
| 🎁 หรือ "แถม..." | มีของแถม | ระบุของแถมให้ชัดเจน |
| "ผ่อน X เดือน" | ผ่อนได้ตามเงื่อนไข | เช็กเงื่อนไขก่อนบอกลูกค้า |
| "รวมติดตั้ง" | ราคารวมค่าติดตั้งแล้ว | ระบุขอบเขตที่รวม (ไม่รวมอะไร) |
| "ไม่รวมติดตั้ง" | ต้องชำระค่าติดตั้งเพิ่ม | แจ้งค่าติดตั้งทันที |
| รหัส A / B / C | ระดับ Priority สต็อก [TBD] | [เติมความหมายตามระบบร้าน] |
| สีป้าย (ถ้ามีระบบสี) | [TBD] | [เติมตามระบบป้ายของร้าน] |

## 4.3 รหัสสินค้า — อ่านอย่างไร?

> [TBD — เติมระบบรหัสสินค้าของแสงวิจิตร]

ตัวอย่าง format ที่มักพบ:
```
[แบรนด์ 2–3 ตัว] - [หมวดสินค้า] - [ขนาด/สเปก] - [รุ่นย่อย]
เช่น: MTC-AC-12-INV = Mitsubishi / Air / 12,000 BTU / Inverter
```

**วิธีใช้รหัสในการเช็กสต็อก:**
1. ดูรหัสที่มุมขวาบนของป้าย
2. พิมพ์ในช่องค้นหาของระบบ
3. ถ้าไม่พบ → ค้นด้วยชื่อรุ่น หรือ scan บาร์โค้ดที่ป้าย

## 4.4 ป้ายราคา vs ราคาจริงที่ชำระ

สิ่งที่ลูกค้ามักสับสน — พนักงานต้องอธิบายให้ชัด:

| สถานการณ์ | คำอธิบายที่ถูกต้อง |
|----------|-----------------|
| ราคาป้ายรวมติดตั้ง แต่ลูกค้าไม่ต้องการติดตั้ง | "ราคานี้รวมติดตั้งครับ ถ้าไม่ติดตั้งราคาจะเป็น [TBD]" |
| ราคาป้ายเป็นโปรฯ เดือนนี้เท่านั้น | "โปรนี้ถึงวันที่ [วันหมดอายุ] นะครับ" |
| ลูกค้าเห็นราคาออนไลน์ถูกกว่า | "ราคาออนไลน์ไม่รวมติดตั้งครับ ของเรารวมหมดแล้ว" |
| ราคาผ่อนบนป้ายต่อเดือน | "นี่คืองวดต่อเดือนครับ ราคาเต็มคือ [ราคา] บาทครับ" |

## 4.5 ป้ายที่ต้องระวังเป็นพิเศษ

**❗ ป้ายราคาเก่า / ยังไม่อัปเดต**
- ถ้าเห็นป้ายที่ราคาไม่ตรงกับระบบ → แจ้งหัวหน้าสาขาทันที
- ห้ามบอกราคาตามป้ายเก่าถ้าระบบราคาต่างกัน → ใช้ราคาในระบบเสมอ

**❗ ป้ายโปรโมชั่นหมดอายุแล้ว**
- เช็กวันหมดอายุบนป้ายทุกเช้า (เป็นส่วนหนึ่งของ Checklist เปิดสาขา)
- ป้ายหมดอายุ → แจ้งหัวหน้าเพื่อเปลี่ยนทันที ห้ามปล่อยทิ้งไว้

**❗ ป้าย "สินค้าตัวโชว์" (Display Unit)**
- ราคาต่างจากสินค้าใหม่ — แจ้งลูกค้าก่อนเสมอ
- มักมีรอยขีดข่วนหรือบรรจุภัณฑ์ไม่ครบ — ตรวจก่อนขาย
