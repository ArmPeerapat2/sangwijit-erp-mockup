# หมวด 1: รู้จักแสงวิจิตร (Know the Store)

---

## 1.1 จุดขายของร้านแสงวิจิตร (Why Buy Here?)

พนักงานต้องจำและพูดได้คล่อง:

| จุดขาย | คำอธิบายให้ลูกค้า |
|--------|-----------------|
| **ศูนย์บริการในเครือ** | "ซื้อที่นี่ มีศูนย์ซ่อมเองเลยครับ ไม่ต้องส่งไกล" |
| **ครอบคลุม 11 จังหวัดอีสาน** | "เราเป็นตัวแทนหลักภาคอีสาน สินค้าแท้ 100% ตรงจากบริษัท" |
| **ผ่อนได้ผ่านบริษัทในเครือ** | "ผ่อนกับเราเองครับ ไม่ผ่านไฟแนนซ์นอก อนุมัติไวกว่า" |
| **มีสต็อกพร้อมส่ง** | "มีสินค้าพร้อมส่งวันนี้เลยครับ ไม่ต้องรอ" |
| **บริการติดตั้ง** | "มีช่างติดตั้งของเราเองครับ ไม่ต้องหาช่างเอง" |

## 1.2 SOP และขั้นตอนสำคัญ

### การเบิกสินค้าให้ลูกค้า
1. ลูกค้าตกลงซื้อ → พนักงานบันทึกออเดอร์ในระบบ
2. ตรวจสต็อกในระบบก่อน **ห้ามบอกลูกค้าว่ามีของโดยไม่เช็ก**
3. มีของ → แจ้งลูกค้ารับสินค้าได้ หรือนัดส่ง
4. ไม่มีของ → แจ้งหัวหน้าสาขาเพื่อสั่งเพิ่ม → แจ้งลูกค้าล่วงหน้า

### การนัดติดตั้ง (สินค้าที่ต้องติดตั้ง เช่น แอร์)
1. รับออเดอร์ + ชำระเงิน
2. **นัดติดตั้งภายใน 3–5 วันทำการ** (แจ้งลูกค้าชัดเจน)
3. ส่งข้อมูลให้ทีมช่าง: ชื่อ / ที่อยู่ / เบอร์ / รุ่นสินค้า / วันเวลา
4. ยืนยัน SMS / LINE กับลูกค้า 1 วันก่อนติดตั้ง
5. หลังติดตั้ง → โทรติดตาม ถามความพึงพอใจภายใน 24 ชม.

### อุปกรณ์มาตรฐานที่แถมกับแอร์
- **ที่แถมเสมอ:** รีโมท + ถ่าน + คู่มือ + ท่อน้ำทิ้ง (ตามมาตรฐาน)
- **ที่ต้องถาม:** ขาแขวน / ท่อแอร์เพิ่ม / สายไฟเพิ่ม (แล้วแต่สภาพหน้างาน)
- **ที่ลูกค้าต้องจัดเตรียมเอง:** ผนังเจาะได้ / ระยะห่างจากฝ้า / ปลั๊กไฟตรงจุด

> ⚠️ แจ้งลูกค้าเรื่องอุปกรณ์เพิ่มเติม **ก่อนวันติดตั้ง** เสมอ เพื่อป้องกันข้อพิพาท

## 1.3 ข้อจำกัดที่พนักงานต้องรู้ (Rules & Limits)

### การลดราคา / ส่วนลด
| สิ่งที่ทำได้ | สิ่งที่ทำไม่ได้ |
|------------|---------------|
| ลดได้ **ไม่เกิน 3%** จากราคาป้าย (ไม่ต้องขออนุมัติ) | ลดเกิน 3% โดยไม่ให้หัวหน้าอนุมัติ |
| เสนอของแถมตามโปรโมชั่นร้าน | ให้ของแถมนอกโปรโมชั่นโดยพลการ |
| บอกลูกค้าว่า "ขอถามหัวหน้าก่อนนะครับ" | ตอบว่าลดได้ก่อนขออนุมัติ |

**บทพูดเมื่อลูกค้าขอลดเกินกรอบ:**
> "ขอโทษนะครับ ราคานี้ผมให้ส่วนลดสูงสุดแล้วครับ ถ้าจะลดเพิ่มต้องรบกวนให้หัวหน้าพิจารณาให้นะครับ รอสักครู่ได้เลยครับ"

### สิ่งที่พนักงานทำไม่ได้เด็ดขาด
- ❌ บอกราคาที่ไม่มีในระบบโดยไม่เช็กก่อน
- ❌ สัญญากับลูกค้าเรื่องโปรโมชั่นที่ยังไม่ยืนยัน
- ❌ รับเงินสดโดยไม่ออก receipt
- ❌ ยืนยันวันส่ง/ติดตั้งโดยไม่ประสานทีมก่อน

## 1.4 โปรโมชั่นบัตรเครดิต

> ⚠️ โปรโมชั่นบัตรเปลี่ยนตามช่วงเวลา — **ต้องเช็กป้ายโปรโมชั่นหน้าเคาน์เตอร์ทุกวัน**

**รูปแบบที่มักพบ:**
- ผ่อน 0% นาน X เดือน (กรุงศรี / กสิกร / SCB)
- แลกคะแนนสะสม
- คืนเงิน X% เมื่อชำระผ่านบัตร

**สิ่งที่พนักงานต้องทำเมื่อลูกค้าถามโปรบัตร:**
1. ดูป้ายโปรโมชั่นปัจจุบัน หรือถามแคชเชียร์
2. แจ้งเงื่อนไขให้ครบ: บัตรอะไร / ผ่อนกี่เดือน / ขั้นต่ำเท่าไหร่
3. ไม่แน่ใจ → "รอสักครู่ ผมเช็กให้เลยนะครับ" อย่าเดา
