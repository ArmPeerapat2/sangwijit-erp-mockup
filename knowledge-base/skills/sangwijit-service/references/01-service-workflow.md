# หมวด 1: รู้จักแสงวิจิตร — ระบบงานและขั้นตอนการทำงาน

---

## 1.1 ภาพรวมศูนย์บริการแสงวิจิตร

**ประเภทงานซ่อมที่รับ:**
- งานในประกัน (Warranty Repair) — ไม่เก็บค่าใช้จ่ายลูกค้า
- งานนอกประกัน (Out-of-Warranty) — เก็บค่าแรง + ค่าอะไหล่
- งานติดตั้ง (Installation) — แอร์ / เครื่องซักผ้า
- งาน PM (Preventive Maintenance) — ล้างแอร์ / เช็คระบบ

**ช่องทางรับงาน:**
- ลูกค้าเดินเข้าสาขา
- โทรศัพท์นัดช่างออกซ่อมบ้าน
- ส่งต่อจากพนักงานขายสาขา
- ระบบ WeService [TBD — รอเอกสารระบบ]

## 1.3 SOP ขั้นตอนการทำงานช่าง (ภาพรวม)

```
รับงาน → ประเมิน → แจ้งลูกค้า → ซ่อม → QC → ส่งคืน → ปิดงาน
```

### ขั้นตอน 1: รับงานและเปิด Job Order

```
1. รับสินค้าจากลูกค้า หรือรับ Job จากระบบ WeService
2. ตรวจสอบข้อมูลเบื้องต้น:
   □ ชื่อ-นามสกุลและเบอร์โทรลูกค้า
   □ รุ่นสินค้า + Serial Number
   □ วันที่ซื้อ (สำคัญมาก — ใช้ตรวจสอบประกัน)
   □ อาการที่ลูกค้าแจ้ง (บันทึกตามที่ลูกค้าบอก ไม่แปลความ)
3. ถ่ายรูปสภาพสินค้าก่อนซ่อม (ทุกมุม ครบ 4 ด้าน)
4. เปิด Job Order ในระบบ WeService [TBD]
5. แจกใบรับซ่อมให้ลูกค้า (ระบุเลข Job + วันคาดว่าจะเสร็จ)
```

### ขั้นตอน 2: ประเมินและวินิจฉัย

```
1. ตรวจสอบสถานะประกัน:
   □ ยังอยู่ในประกันหรือไม่? (ดูเงื่อนไขใน 02-warranty-conditions.md)
   □ มีร่องรอยที่ทำให้ void warranty หรือไม่?

2. วินิจฉัยอาการ:
   □ ทดสอบตามขั้นตอน Diagnostic (ดู 05-repair-techniques.md)
   □ บันทึกสาเหตุที่แท้จริง

3. ประเมินค่าใช้จ่าย:
   □ งานในประกัน → ไม่มีค่าใช้จ่ายลูกค้า
   □ งานนอกประกัน → ประเมิน ค่าแรง + ค่าอะไหล่
   □ จัดทำใบเสนอราคา (กรณีนอกประกันที่มีค่าใช้จ่ายสูง)
```

### ขั้นตอน 3: แจ้งลูกค้าก่อนซ่อม

```
สิ่งที่ต้องแจ้งลูกค้าก่อนเริ่มซ่อมเสมอ:
  □ สถานะประกัน (ในหรือนอก)
  □ สาเหตุที่วินิจฉัยได้
  □ ค่าใช้จ่ายโดยประมาณ (ถ้านอกประกัน)
  □ ระยะเวลาคาดว่าจะเสร็จ
  □ ต้องรอสั่งอะไหล่หรือไม่?

กรณีนอกประกัน:
  → ต้องได้รับการอนุมัติจากลูกค้าก่อนเริ่มซ่อมทุกครั้ง
  → ถ้าลูกค้าไม่อนุมัติ → คืนสินค้าโดยไม่เก็บค่าใช้จ่าย
    (ยกเว้นค่าประเมิน ถ้ามีนโยบายเก็บ [TBD])

บทพูดแจ้งลูกค้า (นอกประกัน):
"ตรวจสอบแล้วพบว่า [อาการ] เกิดจาก [สาเหตุ] ครับ
ค่าซ่อมประมาณ [ราคา] บาท รวมค่าแรงและอะไหล่
คาดว่าเสร็จภายใน [วัน] ครับ ตกลงดำเนินการได้เลยไหมครับ?"
```

### ขั้นตอน 4: ซ่อม

```
1. เบิกอะไหล่ตามที่ประเมิน (ดู 04-parts-management.md)
2. ซ่อมตามขั้นตอนเทคนิค (ดู 05-repair-techniques.md)
3. บันทึกอะไหล่ที่ใช้จริงในระบบ WeService [TBD]
4. ถ่ายรูประหว่างซ่อม (อะไหล่เก่าที่เปลี่ยน + สภาพหลังซ่อม)
```

### ขั้นตอน 5: QC ก่อนส่งคืน

```
Checklist QC (ทำทุกงานก่อนส่งคืนลูกค้า):
  □ ทดสอบฟังก์ชั่นหลักครบทุกอย่าง
  □ อาการที่ลูกค้าแจ้งหายแล้ว
  □ ไม่มีรอยขีดข่วนหรือความเสียหายเพิ่มเติม
  □ อะไหล่เก่าเก็บไว้ให้ลูกค้าดู (กรณีนอกประกัน)
  □ ทำความสะอาดสินค้าก่อนส่งคืน
```

### ขั้นตอน 6: ส่งคืนและปิดงาน

```
1. ให้ลูกค้าทดสอบสินค้าต่อหน้า
2. อธิบายสิ่งที่ซ่อมและแนะนำการดูแลรักษา
3. เก็บค่าบริการ (กรณีนอกประกัน)
4. ออกใบเสร็จ / ใบรับรองการซ่อม
5. แจ้ง "ประกันหลังซ่อม" ให้ลูกค้าทราบ [TBD — กี่วัน?]
6. ปิดงานในระบบ WeService [TBD]
7. ลูกค้าเซ็นรับสินค้า
```

## 1.4 SOP งานออกซ่อมบ้าน (On-site)

```
เพิ่มเติมจาก SOP ปกติ:

ก่อนออกงาน:
  □ ยืนยันที่อยู่และเวลานัด
  □ เตรียมอุปกรณ์และอะไหล่คาดว่าต้องใช้
  □ แจ้งหัวหน้าก่อนออกงาน
  □ บันทึกเวลาออกและเวลากลับในระบบ [TBD]

ระหว่างงาน:
  □ โทรแจ้งลูกค้าก่อนถึง 30 นาที
  □ ถ่ายรูปก่อนเริ่มงานทุกครั้ง
  □ ห้ามใช้อุปกรณ์ในบ้านลูกค้าโดยไม่ขอ

หลังงาน:
  □ เก็บเศษวัสดุและทำความสะอาดจุดที่ทำงาน
  □ ลูกค้าเซ็นรับงาน
  □ รายงานผลกลับในระบบทันที
```

## 1.5 การสื่อสารกับลูกค้า — หลักการ

```
DO:
  ✅ บอกสถานะงานทุกครั้งที่มีความคืบหน้า
  ✅ ถ้าต้องรอนานกว่าที่แจ้ง → โทรแจ้งก่อนครบกำหนดเสมอ
  ✅ พูดภาษาที่ลูกค้าเข้าใจ ไม่ใช้ศัพท์เทคนิคโดยไม่อธิบาย
  ✅ ถ้าซ่อมไม่หาย → แจ้งตรงๆ + เสนอทางเลือก

DON'T:
  ❌ อย่าสัญญาว่าเสร็จแน่ถ้ายังไม่แน่ใจ
  ❌ อย่าบอกราคาคร่าวๆ โดยไม่ตรวจ
  ❌ อย่าปล่อยให้ลูกค้ารอโดยไม่มีข้อมูล
  ❌ อย่าโต้เถียงกับลูกค้าโดยตรง → ส่งต่อหัวหน้าทันที

Escalation:
  ลูกค้าไม่พอใจ / ร้องเรียน → แจ้งหัวหน้าทันที ไม่แก้เองคนเดียว
```
