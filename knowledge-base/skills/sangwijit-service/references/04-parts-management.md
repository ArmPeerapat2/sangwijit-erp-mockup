# หมวด 4: รู้จักอะไหล่ — การเบิก ตรวจสอบ และดูพาร์ทนัมเบอร์

---

## 4.1 ระบบการเบิกอะไหล่

### ขั้นตอนการเบิกอะไหล่

```
1. วินิจฉัยอาการและระบุอะไหล่ที่ต้องการ
2. ตรวจสอบพาร์ทนัมเบอร์ที่ถูกต้อง (ดูข้อ 4.3)
3. ตรวจสอบสต็อกในระบบ WeService [TBD]
4. ยื่นใบเบิกอะไหล่ (กรอกครบทุกช่อง):
   □ เลข Job Order
   □ รุ่นสินค้า + Serial Number
   □ พาร์ทนัมเบอร์ + ชื่ออะไหล่
   □ จำนวน
   □ ในประกัน / นอกประกัน
5. รับอะไหล่ + ตรวจสภาพก่อนนำไปใช้
6. บันทึกอะไหล่ที่ใช้จริงในระบบหลังซ่อมเสร็จ
```

### กรณีไม่มีอะไหล่ในสต็อก

```
→ แจ้งหัวหน้าเพื่อสั่งซื้อ
→ แจ้งลูกค้าทันทีพร้อมระยะเวลาโดยประมาณ
→ บันทึกสถานะ "รออะไหล่" ในระบบ WeService [TBD]
→ ติดตามสถานะการสั่งซื้อ และอัปเดตลูกค้าทุก [TBD] วัน
```

---

## 4.2 การตรวจสอบอะไหล่เสีย (Fault Diagnosis)

### หลักการ: ตรวจทีละส่วน ไม่เดา

```
ขั้นตอนพื้นฐานการตรวจ:
  1. ตรวจสอบด้วยสายตาก่อน (Visual Inspection)
  2. ตรวจสอบด้วย Multimeter (ค่าความต้านทาน / ไฟฟ้า)
  3. ทดสอบสลับกับอะไหล่ที่รู้ว่าดี (Swap Test)
  4. ตรวจสอบจาก Error Code (ถ้าสินค้ามีระบบแสดง error)
```

### การตรวจด้วยสายตา (สิ่งที่ต้องมองหา)

```
ชิ้นส่วนไฟฟ้า:
  □ รอยไหม้ / ควัน / กลิ่นไหม้
  □ Capacitor บวม / ระเบิด
  □ Relay สกปรก / หน้าสัมผัสไหม้
  □ ฟิวส์ขาด (สายไส้ขาด)
  □ PCB บัดกรีหลุด / รอยแตก

ชิ้นส่วนกล (Mechanical):
  □ สายพาน หลุด / แตก / ลื่น
  □ แบริ่ง ดัง / ฝืด
  □ วาล์ว น้ำรั่ว / อุดตัน
  □ Gasket ขาด / แข็งกรอบ
  □ ใบพัด แตก / ไม่สมดุล
```

### การวัดด้วย Multimeter

```
ค่าที่ต้องรู้:
  Resistance (โอห์ม) — ตรวจ Coil / Heater / Thermistor
  Continuity — ตรวจสายไฟขาด
  Voltage (โวลต์) — ตรวจไฟจ่ายปกติไหม
  Capacitance — ตรวจ Capacitor (ต้องใช้มิเตอร์ที่รองรับ)

⚠️ ปิดไฟฟ้าทุกครั้งก่อนตรวจ Resistance/Continuity
   เปิดไฟฟ้าเฉพาะเมื่อต้องตรวจ Voltage เท่านั้น
```

## 4.3 การดูพาร์ทนัมเบอร์ (Part Number)

### แหล่งข้อมูลพาร์ทนัมเบอร์ (เรียงตามความน่าเชื่อถือ)

```
1. Service Manual ของรุ่นนั้นๆ (แม่นที่สุด)
   → ขอจากหัวหน้า หรือดาวน์โหลดจากเว็บแบรนด์

2. ป้ายบนตัวอะไหล่เดิม (ถ้ายังอ่านได้)
   → ถ่ายรูปก่อนถอดทุกครั้ง

3. ระบบค้นหาอะไหล่ของแบรนด์ [TBD — รายการ URL/App]
   → ค้นด้วย Model Number + ชื่อชิ้นส่วน

4. เพื่อนช่างหรือหัวหน้าที่เคยซ่อมรุ่นเดียวกัน
```

### วิธีอ่านพาร์ทนัมเบอร์

```
พาร์ทนัมเบอร์มักประกอบด้วย:
  [รหัสแบรนด์] - [รหัสชิ้นส่วน] - [เวอร์ชั่น/Revision]

ตัวอย่าง (สมมติ):
  LG:      MJY62268110 = Compressor part
  Samsung: DA97-13418A = Refrigerator component
  Panasonic: CWA73C4428 = PCB Assembly

⚠️ พาร์ทนัมเบอร์เดียวกัน อาจใช้กับหลายรุ่น
   และรุ่นเดียวกันอาจมีหลายเวอร์ชั่น → ตรวจให้ตรงก่อนสั่ง
```

### สิ่งที่ต้องระบุเมื่อสั่งอะไหล่

```
ข้อมูลที่ต้องมีครบ:
  □ Model Number ของสินค้า (เช่น LG-GN-B432SQCB)
  □ Serial Number (อยู่บนป้ายด้านหลัง/ด้านข้างสินค้า)
  □ พาร์ทนัมเบอร์ที่แน่ชัด
  □ จำนวนที่ต้องการ
  □ เลข Job Order ที่ใช้

ถ้าไม่แน่ใจพาร์ทนัมเบอร์:
  → อย่าเดา → ถามหัวหน้าหรือส่ง Serial Number ให้แบรนด์ช่วยหา
```

## 4.4 การตรวจสภาพอะไหล่ก่อนใช้

```
รับอะไหล่มาแล้ว ตรวจก่อนติดตั้งเสมอ:

  □ พาร์ทนัมเบอร์ตรงกับที่สั่งหรือไม่?
  □ สภาพภายนอก — ไม่แตก ไม่บิ่น ไม่มีรอยไหม้
  □ ขนาดและรูปร่างตรงกับของเดิมหรือไม่?
  □ สำหรับ Capacitor: ตรวจค่า Capacitance ก่อนใส่
  □ สำหรับ PCB: ตรวจสายต่อและ connector ครบไหม?

ถ้าอะไหล่ไม่ตรงหรือชำรุด:
  → แจ้งคลังทันที อย่าใช้
  → บันทึกและขอเปลี่ยนใหม่
```

---

## 4.5 การจัดเก็บอะไหล่

```
กฎการจัดเก็บ:
  □ เก็บในกล่องหรือถุงที่ป้องกัน Static (ESD)
    โดยเฉพาะ PCB และชิ้นส่วนอิเล็กทรอนิกส์
  □ ติดป้ายกำกับ: พาร์ทนัมเบอร์ + ชื่อ + วันที่รับ
  □ แยกอะไหล่ดี / อะไหล่เสีย / อะไหล่รอตรวจสอบ
    ออกจากกันชัดเจน
  □ อะไหล่เสียที่ถอดออก เก็บไว้ให้ลูกค้าดูหรือส่งคืนแบรนด์
    ห้ามทิ้งก่อนได้รับอนุมัติ
```
