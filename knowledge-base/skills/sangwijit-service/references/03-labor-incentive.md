## 3.1 โครงสร้างรายได้ช่าง

```
รายได้ช่างประกอบด้วย:
  1. เงินเดือนพื้นฐาน (Base Salary)
  2. ค่า Job / ค่าแรงต่องาน (Job Incentive)
  3. ค่าเบี้ยขยัน / ค่าเดินทาง (ถ้ามี)
  4. Bonus ตามผลงาน (ถ้ามี)
```

## 3.4 หลักการคิดค่าแรงที่ถูกต้อง

```
สิ่งที่รวมในค่าแรง:
  ✅ ค่าแรงงานช่าง
  ✅ ค่าน้ำยาและวัสดุสิ้นเปลือง (ที่ไม่ใช่อะไหล่หลัก)
  ✅ ค่าเดินทาง (กรณีออกซ่อมบ้าน)

สิ่งที่คิดแยก (ไม่รวมในค่าแรง):
  📦 ค่าอะไหล่ (คิดตามราคาจริง)
  🧪 น้ำยาแอร์ (คิดตามปริมาณที่ใช้)
```

### กฎ: ห้ามประเมินราคาก่อนตรวจสอบจริง

```
❌ ห้ามบอกราคาคร่าวๆ ทางโทรศัพท์โดยไม่เห็นสินค้า
✅ ใช้ประโยคนี้แทน:
   "ต้องดูสินค้าก่อนครับถึงจะบอกราคาได้ชัดเจน
   แต่โดยทั่วไป [ประเภทงานนี้] อยู่ที่ประมาณ
   [ช่วงราคากว้างๆ] ครับ"
```
