# หมวด 2: เงื่อนไขการรับประกัน — ในประกัน vs นอกประกัน

---

## 2.1 หลักการตรวจสอบประกัน

**3 สิ่งที่ต้องตรวจก่อนตัดสินใจทุกครั้ง:**

```
1. วันที่ซื้อ + ระยะประกัน = ยังอยู่ในช่วงหรือไม่?
2. มีหลักฐานการซื้อหรือไม่? (ใบเสร็จ / ใบรับประกัน)
3. อาการและสภาพสินค้า → เข้าเงื่อนไขประกันหรือไม่?
```

## 2.3 เงื่อนไข "งานในประกัน" (Warranty Repair)

งานจะถือว่า **อยู่ในประกัน** ต้องครบทุกข้อ:

```
✅ ข้อ 1: ยังอยู่ในระยะเวลาประกัน
✅ ข้อ 2: มีหลักฐานการซื้อ (ใบเสร็จ หรือ ใบรับประกัน หรือ
          บันทึกการซื้อในระบบแสงวิจิตร)
✅ ข้อ 3: อาการเกิดจากความบกพร่องของสินค้า (ไม่ใช่การใช้งานผิดวิธี)
✅ ข้อ 4: ไม่มีสภาพที่ทำให้ประกันเป็นโมฆะ (ดูข้อ 2.4)
```

**ถ้าครบทุกข้อ:**
- ลูกค้าไม่เสียค่าใช้จ่าย (ค่าแรง + ค่าอะไหล่)
- แจ้งบริษัทแม่/แบรนด์เพื่อเบิกค่าซ่อม [TBD — ระบบเบิกแต่ละแบรนด์]

## 2.4 เงื่อนไข Void Warranty (ประกันเป็นโมฆะ)

งานจะถือว่า **นอกประกัน** ถ้าพบสภาพเหล่านี้:

```
❌ ความเสียหายจากอุบัติเหตุ
   เช่น: ตก / ชน / ไฟไหม้ / น้ำท่วม

❌ ความเสียหายจากการใช้งานผิดวิธี
   เช่น: ใช้ไฟฟ้าผิดโวลต์ / ใส่ของเกินขนาด (เครื่องซักผ้า)

❌ ซ่อมหรือดัดแปลงโดยช่างที่ไม่ได้รับอนุญาต
   สังเกต: มีรอยแกะที่ไม่ใช่ศูนย์ / สายไฟต่อเพิ่มเติม

❌ สติ๊กเกอร์ประกันถูกแกะหรือเสียหาย
   สังเกต: hologram seal ขาด / ถูกลอกออก

❌ Serial Number ถูกแก้ไขหรือลบออก

❌ ความเสียหายจากภัยธรรมชาติ (ฟ้าผ่า)
   → บางกรณีมีประกันภัยครอบคลุม ให้ตรวจสอบ

❌ ใช้งานผิดประเภท เช่น ใช้เครื่องใช้ภายในบ้านเป็นเชิงพาณิชย์
```

**เมื่อพบ Void Warranty:**
```
1. ถ่ายรูปหลักฐานทุกจุดที่พบ
2. แจ้งลูกค้าอย่างสุภาพ พร้อมแสดงรูป
3. เสนอราคาซ่อมนอกประกัน
4. บันทึกในระบบว่า "Void Warranty เหตุผล: [ระบุ]"
5. ถ้าลูกค้าไม่เห็นด้วย → ส่งต่อหัวหน้าทันที ไม่เถียงเอง
```

## 2.5 งานนอกประกัน (Out-of-Warranty)

**ขั้นตอนเพิ่มเติมสำหรับงานนอกประกัน:**

```
1. แจ้งลูกค้าก่อนว่า "นอกประกัน"
2. ประเมินราคา: ค่าแรง + ค่าอะไหล่
3. รอการอนุมัติจากลูกค้า (วาจาหรือลายลักษณ์อักษร)
4. ดำเนินการซ่อม
5. เก็บค่าบริการตามที่ตกลง
```

**กรณีลูกค้าไม่อนุมัติราคา:**
```
→ คืนสินค้าในสภาพเดิม
→ เก็บค่าประเมิน [TBD — มีหรือไม่? เท่าไหร่?]
→ บันทึกในระบบว่า "ลูกค้าไม่อนุมัติ — ไม่ซ่อม"
```

## 2.6 กรณีพิเศษที่ต้องขอความเห็นหัวหน้า

```
ส่งต่อหัวหน้าทันที เมื่อ:
  □ ลูกค้าไม่เห็นด้วยกับการ void warranty
  □ ไม่แน่ใจว่าอาการอยู่ในประกันหรือไม่
  □ ค่าซ่อมสูงกว่าราคาสินค้า (แนะนำซื้อใหม่แทน)
  □ สินค้าหายระหว่างรับซ่อม (ต้องแจ้งทันที)
  □ ลูกค้า claim ว่าเคยซ่อมแล้วแต่ยังเสียซ้ำ
     → ตรวจสอบประวัติการซ่อมใน WeService [TBD]
```
