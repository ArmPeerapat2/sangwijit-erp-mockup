# หมวด 5: รู้จักสินค้า — เทคนิคการซ่อมและ Diagnostic

> หลักการ: วินิจฉัยให้ได้สาเหตุที่แท้จริงก่อนเสมอ — ไม่เปลี่ยนอะไหล่โดยเดา

---

## 5.1 แอร์ (Air Conditioner)

### อาการพบบ่อย → สาเหตุ → วิธีตรวจ

**อาการ: แอร์ไม่เย็น / เย็นน้อย**

```
สาเหตุที่พบบ่อย (เรียงจากง่ายไปยาก):
  1. ฟิลเตอร์อุดตัน
     ตรวจ: ดูด้วยสายตา
     แก้:  ล้างฟิลเตอร์

  2. น้ำยาแอร์รั่วหรือน้อย
     ตรวจ: วัดแรงดัน Low/High side ด้วย Manifold Gauge
             Low side ต่ำกว่าปกติ (ปกติ ~65-75 psi ที่ 25°C)
     แก้:  หาจุดรั่ว → เติมน้ำยา (ถ้าในประกันต้องรายงานแบรนด์)

  3. Capacitor เสื่อม (คอมเพรสเซอร์หรือมอเตอร์พัดลมไม่สตาร์ท)
     ตรวจ: ตรวจค่า Capacitance เทียบกับค่าที่ระบุบนตัว Capacitor
             ค่าต่ำกว่า 80% ของค่าที่ระบุ = เสื่อม
     แก้:  เปลี่ยน Capacitor

  4. คอมเพรสเซอร์เสีย
     ตรวจ: ตรวจค่า Ohm ขดลวด (Winding) ระหว่าง C-S, C-R, S-R
             ถ้า Short to Ground หรือ Open Winding = เสีย
     แก้:  เปลี่ยนคอมเพรสเซอร์

  5. PCB Control Board เสีย
     ตรวจ: ตรวจสอบ Error Code + Visual Inspection บน PCB
     แก้:  เปลี่ยน PCB
```

**อาการ: แอร์ไม่ติด / ไม่ทำงาน**

```
  1. ไฟไม่เข้าตัวแอร์
     ตรวจ: วัดไฟที่ปลั๊กและที่ PCB
     แก้:  ตรวจสายไฟ / ฟิวส์ / เบรกเกอร์

  2. Remote เสีย / แบตหมด
     ตรวจ: ลองกดปุ่มที่ตัวเครื่อง
     แก้:  เปลี่ยนแบตหรือ Remote

  3. Thermistor เสีย (ป้องกันโอเวอร์โหลด)
     ตรวจ: ตรวจค่าความต้านทาน Thermistor เทียบกับตาราง
     แก้:  เปลี่ยน Thermistor

  4. PCB เสีย
     ตรวจ: Error Code
     แก้:  เปลี่ยน PCB
```

**อาการ: แอร์มีน้ำหยด (ด้านใน)**

```
  1. ท่อระบายน้ำอุดตัน (พบบ่อยที่สุด)
     ตรวจ: เป่าลมหรือดูดท่อระบายน้ำ
     แก้:  ล้างท่อระบาย

  2. ติดตั้งไม่ได้ระดับ (ด้านในสูงกว่าด้านนอก)
     ตรวจ: ใช้ระดับน้ำตรวจ
     แก้:  ปรับระดับการติดตั้ง

  3. น้ำยาน้อยเกินไป (Evaporator แข็งตัว)
     ตรวจ: ดูว่า Evaporator เป็นน้ำแข็งหรือไม่
     แก้:  เติมน้ำยา + ตรวจหารั่ว
```

### ขั้นตอน Diagnostic แอร์ (Standard Flow)

```
1. รับข้อมูลอาการจากลูกค้า
2. ตรวจ Error Code (ถ้ามี) → ดู Service Manual
3. ตรวจ Visual Inspection: คอมเพรสเซอร์ / PCB / สายไฟ
4. เปิดเครื่อง → วัดไฟที่ PCB
5. ตรวจ Capacitor
6. วัดแรงดันน้ำยา (ถ้าอาการเกี่ยวกับความเย็น)
7. ตรวจ Thermistor ทุกตัว
8. ตรวจคอมเพรสเซอร์ (ถ้ายังหาสาเหตุไม่ได้)
```

## 5.2 ตู้เย็น (Refrigerator)

### อาการพบบ่อย → สาเหตุ → วิธีตรวจ

**อาการ: ตู้เย็นไม่เย็น / เย็นน้อย**

```
  1. ขดลวดด้านหลัง (Condenser Coil) ฝุ่นเกาะหนา
     ตรวจ: ดูสภาพขดลวดด้านหลัง
     แก้:  ทำความสะอาดขดลวด

  2. น้ำแข็งเกาะที่ Evaporator (Frost Buildup)
     ตรวจ: เปิดช่องแช่แข็ง ดูว่ามีน้ำแข็งหนาผิดปกติ
     แก้:  Defrost (ละลายน้ำแข็ง) + ตรวจระบบ Defrost

  3. Thermostat เสีย
     ตรวจ: ตรวจการทำงานของ Thermostat
     แก้:  เปลี่ยน Thermostat

  4. ประตูยางเสื่อม (ลมเย็นรั่ว)
     ตรวจ: ทดสอบด้วยกระดาษ A4 (หนีบประตู ดึงออก)
             ถ้าหลุดง่าย = ยางเสื่อม
     แก้:  เปลี่ยน Door Seal/Gasket

  5. น้ำยาตู้เย็นรั่ว
     ตรวจ: ตรวจด้วย Leak Detector
     แก้:  ซ่อมรอยรั่ว + เติมน้ำยา
```

**อาการ: ตู้เย็นมีเสียงดังผิดปกติ**

```
  1. ไม่ได้วางระดับ
     ตรวจ: ใช้ระดับน้ำ
     แก้:  ปรับขาตู้เย็น

  2. ของในตู้เย็นสัมผัสกัน
     แก้:  จัดของให้ไม่แตะขอบหรือพัดลม

  3. Evaporator Fan เสียง (แบริ่งเสื่อม)
     ตรวจ: ฟังทิศทางเสียง
     แก้:  เปลี่ยน Fan Motor

  4. Compressor เสียง (ผิดปกติ)
     ตรวจ: ฟังเสียงที่คอมเพรสเซอร์
     แก้:  เปลี่ยนคอมเพรสเซอร์ (ราคาสูง แนะนำให้ลูกค้าพิจารณาซื้อใหม่ถ้าเครื่องเก่ามาก)
```

## 5.3 เครื่องซักผ้า (Washing Machine)

### อาการพบบ่อย → สาเหตุ → วิธีตรวจ

**อาการ: เครื่องไม่ปั่น / ปั่นแล้วหยุด**

```
  1. ฝาปิดไม่สนิท / Door Lock เสีย
     ตรวจ: ตรวจ Door Lock Switch
     แก้:  เปลี่ยน Door Lock Assembly

  2. Motor เสีย (Top Load)
     ตรวจ: ตรวจ Carbon Brush (ถ้ามี)
             ตรวจค่าความต้านทาน Winding ของมอเตอร์
     แก้:  เปลี่ยน Carbon Brush หรือ Motor

  3. สายพานหลุด/ขาด (Top Load บางรุ่น)
     ตรวจ: เปิดฝาล่าง ดูสายพาน
     แก้:  เปลี่ยนสายพาน

  4. PCB Control เสีย
     ตรวจ: Error Code
     แก้:  เปลี่ยน PCB
```

**อาการ: เครื่องน้ำไม่เข้า**

```
  1. ก๊อกน้ำปิดอยู่
     ตรวจ: ดูก๊อกน้ำต้นทาง (ลูกค้ามักลืม)
     แก้:  เปิดก๊อก

  2. ฟิลเตอร์สายน้ำอุดตัน
     ตรวจ: ถอดสายน้ำ ดูฟิลเตอร์ตาข่าย
     แก้:  ล้างฟิลเตอร์

  3. Water Inlet Valve เสีย
     ตรวจ: ตรวจ Solenoid Valve ด้วย Multimeter
     แก้:  เปลี่ยน Inlet Valve
```

**อาการ: เครื่องระบายน้ำไม่ออก**

```
  1. ท่อระบายน้ำพับหรืออุดตัน
     ตรวจ: ดูสภาพท่อ
     แก้:  จัดท่อหรือล้างท่อ

  2. Drain Pump เสีย
     ตรวจ: ฟังเสียง Pump ทำงานหรือไม่ / ตรวจไฟที่เข้า Pump
     แก้:  เปลี่ยน Drain Pump

  3. Filter ระบายน้ำอุดตัน
     ตรวจ: เปิด Filter ที่ด้านล่างหน้าเครื่อง
     แก้:  ล้าง Filter
```

## 5.4 ทีวี (Television)

### อาการพบบ่อย → สาเหตุ → วิธีตรวจ

**อาการ: ทีวีไม่ติด / Standby ค้าง**

```
  1. Power Supply เสีย
     ตรวจ: วัดแรงดันไฟออกจาก Power Supply Board
     แก้:  เปลี่ยน Capacitor บน PSU หรือเปลี่ยน PSU Board

  2. Backlight เสีย (จอดำแต่มีเสียง)
     ตรวจ: ส่องไฟฉายที่จอ — ถ้าเห็นภาพ = Backlight เสีย
     แก้:  เปลี่ยน LED Backlight Strip

  3. Main Board เสีย
     ตรวจ: ถ้าไฟ Backlight ปกติแต่ไม่มีภาพ
     แก้:  เปลี่ยน Main Board
```

**อาการ: ภาพผิดปกติ (เส้น / สีผิด / ครึ่งจอ)**

```
  → มักเป็น Panel (T-Con Board หรือ Panel เสีย)
  ตรวจ: ตรวจสายแพระหว่าง T-Con กับ Panel
         ถ้าสายปกติ → T-Con หรือ Panel เสีย
  แก้:  เปลี่ยน T-Con Board (ถูกกว่า) หรือ Panel (แพง)

  ⚠️ ถ้าต้องเปลี่ยน Panel → แจ้งลูกค้าราคาก่อนเสมอ
     เพราะบางครั้งแพงกว่าซื้อทีวีใหม่
```

## 5.5 หลักการทั่วไปที่ช่างต้องจำ

```
กฎ 1: ถ่ายรูปก่อนแกะ / ก่อนถอดสายใดๆ
       → ป้องกันลืมตำแหน่งการต่อสาย

กฎ 2: ตรวจง่ายก่อนยากเสมอ
       (ฟิลเตอร์ → Capacitor → Motor → PCB)

กฎ 3: ถ้าไม่รู้ว่าสาเหตุคืออะไร → หยุด ถามหัวหน้า
       ดีกว่าเปลี่ยนอะไหล่ผิดตัว

กฎ 4: Error Code คือเพื่อน — อ่านก่อนทุกครั้ง
       ดู Service Manual ของรุ่นนั้นๆ

กฎ 5: ทดสอบให้ครบก่อนคืนลูกค้า
       ซ่อมอาการหนึ่งแล้วต้องตรวจว่าไม่มีอาการอื่นตามมา
```
