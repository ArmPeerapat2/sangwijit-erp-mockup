# Master Document Register — กลุ่มแสงวิจิตร

## รหัสเอกสาร Format

```
[Entity]-[Dept]-[DocType]-[NN]-[Rev]
```

### Entity Codes
| รหัส | บริษัท |
|------|--------|
| SWT | แสงวิจิตรเทรดดิ้ง |
| SWE | แสงวิจิตรการไฟฟ้า |
| WPS | WePowerSupply |
| VMN | วีมันนี่ (Read Only) |

### Department Codes
| รหัส | แผนก |
|------|------|
| RET | ค้าปลีก |
| WHS | ค้าส่ง |
| ONL | ออนไลน์ |
| EXP | ส่งออก |
| ACC | บัญชี |
| SVC | ศูนย์บริการ |
| WH  | คลังสินค้า |
| DLV | จัดส่ง |
| HR  | บุคคล |
| PUR | จัดซื้อ |
| CRD | สินเชื่อ (VMN) |

### Document Type Codes
| รหัส | ประเภท |
|------|--------|
| JD  | Job Description |
| KPI | KPI Framework |
| SOP | Standard Operating Procedure |
| CHK | Checklist |
| F   | Form (แบบฟอร์ม) |
| POL | Policy |
| MAN | Manual / คู่มือ |
| REP | Report Template |

### NN (Running Number)
- 2 หลักเสมอ: 01, 02 … 09, 10, 11 …
- นับแยกตาม Entity + Dept + DocType
- ห้ามใช้ running number เดียวกันข้ามนิติบุคคล

### Rev
- R00 = Draft ครั้งแรก
- R01, R02 … = แก้ไขครั้งที่ 1, 2 …
- เมื่อข้อมูล TBD ครบแล้ว → ออก R01

## กฎการอัปเดต Register

1. **ทุกครั้งที่ออกเอกสารใหม่** → เพิ่มแถวใน xlsx
2. **ทุกครั้งที่ Rev เปลี่ยน** → อัปเดต Rev + วันที่ในแถวเดิม
3. **สีพื้นหลัง** แต่ละ Layer ต่างกัน (กำหนดใน xlsx template)
4. **ไม่มีรหัสซ้ำ** ในตารางทั้งหมด
