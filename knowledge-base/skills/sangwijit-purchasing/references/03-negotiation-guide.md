# หลักการเจรจา Trade Agreement กับห้าง

> บทเรียนจากเอกสารเจรจาจริง (Do Home 2022/2565)
> ที่ Supplier (TCL) ต่อรองสำเร็จในหลายจุด

---

## หลักคิดก่อนเจรจา

```
ห้างมีอำนาจต่อรองสูงกว่า แต่ไม่ได้ทุกอย่าง
จุดที่ต่อรองได้มักเป็น:
  - % Marketing Fee (ห้างมักขอสูงกว่าที่ยอมรับ)
  - Display/Clearance Fee (เจรจาตามประเภทสินค้า)
  - New Store Opening Fee (ถ้าเราไม่ได้ประโยชน์)
  - DC Fee (ถ้าเราส่งตรงสาขาได้)

จุดที่ต่อรองยาก:
  - Rebate % หลัก (ห้างยึดแน่น)
  - Payment Term
  - Non-move Policy
```

---

## กลยุทธ์เจรจา 5 ขั้น

### ขั้น 1: เตรียมข้อมูลก่อนเจรจา

```
ต้องรู้ก่อน:
  □ ยอดขายจริงปีที่แล้วในห้างนั้น
  □ ต้นทุนสินค้าที่จะส่ง
  □ True Margin หลังหักค่าใช้จ่ายปีที่แล้ว
  □ ห้างคู่แข่งให้เงื่อนไขอะไร (benchmark)
  □ เป้ายอดที่วางแผนปีนี้
  □ จุดที่รับไม่ได้ (Red Line) ของเรา
```

### ขั้น 2: อ่าน Agreement ให้ครบก่อนนั่งโต๊ะ

```
Checklist ก่อนเจรจา:
  □ รวม % ทุกรายการแล้วเท่าไหร่?
  □ มีรายการที่เพิ่มจากปีที่แล้วไหม?
  □ Penalty อะไรที่เราเคยโดนบ้าง?
  □ เงื่อนไขไหนที่เราทำไม่ได้จริงๆ?
  □ ห้างเปิดสาขาใหม่กี่แห่งปีนี้?
```

### ขั้น 3: ระบุจุดที่ขอต่อรอง (ไม่เกิน 3–4 จุด)

```
กฎ: อย่าขอต่อรองทุกจุด — จะดูไม่จริงจัง
เลือกเฉพาะจุดที่กระทบต้นทุนมากที่สุด

ตัวอย่างจากการเจรจา Do Home 2022 จริง:
  ✓ Marketing Fee: ห้างขอ 3% → Supplier ขอ 2% → ตกลง 2%
  ✓ Display Fee: ห้างขอ 50% → Supplier ขอ DTV 20%, UHD 30% → ตกลงตามที่ขอ
  ✗ Rebate Step: ยอมรับตามที่ห้างกำหนด
  ✗ New Store Opening: ยอมรับ 2%
```

### ขั้น 4: เสนอทางเลือกแทนการปฏิเสธ

```
แทนที่จะบอก "ลด Marketing Fee ได้ไหม?"
→ บอก "เราขอ invest instore โดยตรง 2% แทนการจ่ายเป็น fee ได้ไหม?
  เพราะเราควบคุมคุณภาพกิจกรรมได้ดีกว่า และห้างก็ได้ประโยชน์เท่ากัน"

แทนที่จะบอก "DC Fee แพงเกินไป"
→ บอก "ขอส่งตรงสาขาแทนผ่าน DC ได้ไหม? เราบริหาร logistics เองได้
  ห้างไม่ต้องจัดการหลังบ้านเพิ่ม"
```

### ขั้น 5: จดบันทึกสิ่งที่ตกลงกันก่อนเซ็น

```
หลังเจรจาปากเปล่า → ส่ง email สรุป ให้อีกฝ่าย reply confirm
(เช่น email จาก Do Home 2022 ที่เขียนว่า "OK agree with your plan")
แล้วนำไปแก้ agreement ก่อนเซ็นจริง
```

## จุดเจรจาเฉพาะรายห้าง

### Home Hub
- **จุดหลัก:** Non-move policy เข้มแข็ง — ขอให้ห้างช่วยโปรโมทสินค้า slow-moving ก่อนนับ 90 วัน
- **DC Fee:** ถ้าไม่ผ่าน DC = ไม่มี fee — พยายามส่งตรงสาขาเสมอ
- **Lead Time:** กำหนด lead time ที่ทำได้จริง อย่าให้ห้างบีบจนเกินไป

### Global House
- **DC Fee 5%:** ขอส่งตรงสาขาถ้าเป็นไปได้
- **Software Fee 9,600 บาท:** เล็กน้อยแต่ถ้าเป็น Supplier รายเล็กกระทบได้
- **เอกสาร deadline เข้มงวด:** ตั้ง reminder ภายในองค์กรให้ส่งทันวันที่ 3

### Makro
- **ยอดสูงมาก:** ถ้ายอดไม่ถึง tier ล่าง = ไม่ได้ rebate — วางแผน หรือขอ tier ที่ realistic
- **Joint DC 700,000 บาท Fixed:** คุ้มถ้ายอด > 30–40 MB (กว่า 5% %)
- **Anniversary Discount:** แจ้งล่วงหน้าก่อนเดือนครบรอบสาขา

### Do Home
- **Marketing Fee:** ต่อรองจาก 3% → 2% ได้ (มีหลักฐานสำเร็จ)
- **Display Fee:** ต่อรองตามประเภท (DTV/Smart vs UHD ต่างกัน)
- **ขอ invest instore แทนจ่าย fee** — ห้างยอมรับได้ถ้า Supplier ทำเองได้จริง

## Red Lines (สิ่งที่ไม่ควรยอมรับ)

```
1. รวม % ทั้งหมดเกิน 15% ของยอดขาย → ต้นทุนอาจกินกำไรทั้งหมด
2. Non-move 90 วัน แต่ไม่มีช่วงเวลาโปรโมทก่อน → ขอให้แจ้งล่วงหน้า 30 วัน
3. Lead Time ที่ทำไม่ได้จริง → จะโดน penalty ตลอด
4. Rebate tier สูงเกินจริง → ทำ false target = เสียเงินโดยไม่ได้ประโยชน์
5. PC Penalty สูงมากโดยไม่มีขั้นตอน cure → ขอให้มี grace period ก่อน fine
```
