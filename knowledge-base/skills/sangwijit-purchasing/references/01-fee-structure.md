# ค่าใช้จ่ายทุกประเภทในการส่งสินค้าให้ห้าง

## ภาพรวม: รายการค่าใช้จ่ายที่ห้างเรียกเก็บจาก Supplier

ข้อมูลสกัดจาก 5 agreement จริง: **Home Hub, Global House, Makro, Do Home, Agreement ตัวอย่าง**

---

## 1. Rebate / ส่วนลดประจำปี (Yearly Rebate)

ค่าใช้จ่ายหลักและสูงที่สุด — มี 2 รูปแบบ:

### รูปแบบ A: อัตราคงที่ (Fixed Rate)
```
คิดจากยอดซื้อทั้งปี นับจากบาทแรก
เช่น: 1% ของยอดซื้อทั้งหมด
ง่ายต่อการคำนวณ แต่ไม่มี incentive เพิ่มยอด
```

### รูปแบบ B: Step/Tier (ขั้นบันได)
```
ยอดซื้อถึง Tier → ได้ rebate % ที่กำหนด
**คำนวณจากยอดรวมตั้งแต่บาทแรก** (ไม่ใช่เฉพาะส่วนที่เกิน)

ตัวอย่างจาก Do Home 2565:
  Step 1: ยอดซื้อแรก → ส่วนลด 2%
  Step 2: 45–50 MB → 2%
  Step 3: 50–55 MB → 2.5%
  Step 4: ≥55 MB → 3%

ตัวอย่างจาก Global House 2566 (TCL AV):
  6–10 MB → 1%
  >10 MB  → 2%

ตัวอย่างจาก Makro 2019:
  Step 1: ~150 MB → 4.5%
  Step 2: ~175 MB → 4.75%
  Step 3: ≥175 MB → 5%
```

> ⚠️ กฎสำคัญ: ถ้า Rebate เป็น Step **คำนวณจากบาทแรก** หมายความว่า
> ถ้าเกิน threshold บนสุด จะย้อนไปคิด % ใหม่กับยอดทั้งหมด — ผลต่างใหญ่มาก

**วิธีเจรจา:**
- ขอ Step ที่ threshold ต่ำสุดสูงกว่าความเป็นจริงเล็กน้อย (ป้องกัน over-commit)
- ถ้าห้างให้ Fixed Rate → ขอลด % ลง
- ถ้าห้างให้ Step → เจรจาให้ threshold แต่ละขั้น realistic กับยอดขายจริง

## 2. Marketing Fee / ค่าสนับสนุนการตลาด

```
คิดจากยอดสั่งซื้อ (ยอดรับสินค้าจริง หัก C/N คืนสินค้า ไม่รวม VAT)
อัตราทั่วไป: 1–3% ของยอดซื้อ

จากเอกสารจริง:
  Home Hub:    2% (รายเดือน/ไตรมาส/ปี)
  Global House: 1% (รายปี) — แยกเอกสารแนบ
  Do Home:     2% (แต่ห้างขอ 3% — ต่อรองได้)
  Makro:       ใช้ชื่อ "Catalog Mail" 3% + B2B E-Commerce 0.5%
```

**จุดที่เจรจาได้:**
- อัตรา % (ลองขอลด)
- รูปแบบการจ่าย: รายเดือน vs รายปี (รายปีดีกว่าสำหรับ Supplier — เงินสดคงอยู่นานกว่า)
- วิธีการชำระ: CN (ใบลดหนี้) ดีกว่าจ่ายเป็นเช็ค — เพราะหักจากยอดสินค้าแทนจ่ายเพิ่ม

---

## 3. DC Fee / ค่าบริการศูนย์กระจายสินค้า

```
เรียกเก็บเฉพาะสินค้าที่ผ่าน Distribution Center (DC)
(สินค้าที่ส่งตรงสาขา = ไม่มีค่านี้)

อัตราจากเอกสารจริง:
  Global House: 5% ของมูลค่าสินค้าก่อน VAT (รายเดือน)
  Do Home:      5% (รายเดือน)
  Home Hub:     มี — % TBD ตาม agreement ปีนั้น
  Makro:        เรียกว่า "Joint Distribution" 700,000 บาท/ปี (Fixed)
```

**จุดที่เจรจาได้:**
- ขอส่งตรงสาขาแทนผ่าน DC → หลีกเลี่ยง DC Fee ได้
- ถ้าจำเป็นต้องผ่าน DC → เจรจา % ให้ต่ำลง หรือขอ Cap (จ่ายไม่เกิน X บาท/เดือน)
- Global House มี Service Level Target 95% — ถ้าทำได้อาจต่อรองลด fee

## 4. Transportation Fee / ค่าขนส่ง

```
รูปแบบที่ห้างกำหนด:
  A) Supplier ขนส่งฟรีถึง DC เอง
  B) Supplier ขนส่งฟรีถึงแต่ละสาขา
  C) ห้างจัดขนส่งให้ แต่ Supplier จ่าย % (บางห้าง 3% เช่น Home Hub)
  D) Supplier จ้าง 3PL เอง จ่ายต้นทางทั้งหมด

อัตราจากเอกสารจริง:
  Home Hub: 3% ถ้าใช้ 3PL ตามที่ Home Hub กำหนด
```

**จุดที่เจรจาได้:**
- เลือกส่งตรงสาขาเองแทนผ่าน DC → ประหยัดทั้ง DC Fee และ Transport Fee
- ถ้าต้องจ่าย % → ขอ Cap ไม่เกิน X บาท/เดือน

## 5. PC/SPE Fee / ค่าบริหารจัดการพนักงานขาย

```
กรณีมี PC (Product Consultant) / พนักงาน Nominee ประจำห้าง:

  Home Hub: ส่ง PC ไม่ทันใน 15 วัน → ปรับ 1,500 บาท/วัน/คน
  Global House (SPE): ผู้ค้าสนับสนุน [TBD] บาท/แผนก
  Do Home: PC Missing = 600 บาท ต่อคนต่อวัน
  Makro: ค่าจัดการ PC Replenishment 0.25%/เดือน
```

**จุดที่เจรจาได้:**
- ขอลด Penalty rate ถ้าส่ง PC ล่าช้า (เหตุสุดวิสัย)
- กำหนด lead time ที่ realistic ก่อนเซ็น (อย่าให้ 15 วันถ้าทำไม่ได้)

```
เรียกเก็บเฉพาะสาขาที่เปิดใหม่ในช่วง 1 เดือนแรก

อัตราจากเอกสารจริง:
  Home Hub: [TBD %] จากยอดใบสั่งซื้อ
  Makro:    80,000 บาท/สาขา (บวกอีก 2.5%)
            + 25,000 บาท Anniversary/สาขา/ปี
```

**ข้อสังเกต:** ห้างที่ขยายสาขาเร็ว (เช่น Global House) → เงื่อนไขนี้กระทบต้นทุนมาก

## สูตรคำนวณ True Margin

```
สมมติ: ราคาขายห้าง = 100 บาท, ต้นทุนสินค้า = 70 บาท

รายการหัก:
  Rebate:        3%  = 3.00 บาท
  Marketing Fee: 2%  = 2.00 บาท
  DC Fee:        5%  = 5.00 บาท
  Transport:     0%  = 0.00 บาท (ส่งเอง)
  PC Fee:        0.25% = 0.25 บาท
  รวมค่าห้าง:   10.25 บาท

Gross Profit = 100 − 70 = 30 บาท
True Profit  = 30 − 10.25 = 19.75 บาท
True Margin  = 19.75 / 100 = 19.75%

(จากที่คิดว่าได้ 30% จริงๆ ได้แค่ 19.75%)
```

> เมื่อมีตัวเลขจริง → แทนค่าและคำนวณได้ทันที
