# Mindset: Dealer vs Modern Trade — ทำไมถึงต่างกัน

> เนื้อหาจาก Saeng Wijit Internal Training Series: Purchasing 101
> "จากการซื้อของถูก สู่การบริหาร 'เงินต่อเงิน'"

---

## The Great Retail Paradox — ปริศนาค้าปลีก

```
คำถาม: ทำไมห้างซื้อของแพงกว่าเรา แต่ขายได้ถูกกว่าเรา?
คำถาม: ทำไมห้างขายตัดราคาแล้วยังทำกำไร แต่ดีลเลอร์ขายตัดราคาแล้วเจ็บตัว?

คำตอบ: สิ่งที่คุณเห็นบนป้ายราคา ไม่ใช่สิ่งเดียวกับที่ห้างเห็น
```

---

## โมเดลภูเขาน้ำแข็ง: สิ่งที่ซ่อนอยู่ใต้ "ราคาซื้อ"

```
ที่เห็น (เหนือน้ำ):
  ราคาหน้าบิล (Invoice Price)
  ส่วนลดหน้าบิล / ราคาถูกที่สุด

ที่ซ่อน (ใต้น้ำ) — นี่คือที่มาของกำไรห้างจริงๆ:
  Credit Terms (60–90 วัน) = เงินทุนหมุนเวียนฟรี
  Marketing Support (งบการตลาด/ค่าหัวเชลฟ์)
  Logistics Fees (ค่ากระจายสินค้า)
  Penalties (ค่าปรับของตาย/สินค้าค้างสต็อก)
```

**บทเรียนหลัก:** ห้างไม่ได้ทำกำไรจากส่วนต่างราคาซื้อ-ขายเป็นหลัก แต่ทำกำไรจาก **โครงสร้างที่ซ่อนอยู่ใต้น้ำ**

---

## DC Strategy: ห้างเปลี่ยน "ต้นทุน" ให้เป็น "กำไร"

```
วิธีเก่า (Supplier Delivery):
  Supplier ส่งของเอง 10,000 สาขา = เจ็บค่าขนส่ง

วิธีใหม่ (Mall DC Strategy):
  ห้างตั้ง DC แล้ว "คิดเงิน" Supplier
  Factory → DC → สาขา
  ผล: ค่าขนส่งไม่ใช่รายจ่ายของห้าง แต่เป็น "รายได้"
```

> "ทุกบาทในการส่ง ห้างคิดเงินกับ Supplier หมดเลย"

---

## Mindset เจ้าของที่ดิน: พื้นที่คือเงิน

```
ห้างไม่ได้ขายแค่สินค้า — ห้างขาย "โอกาสในการขาย"

สิ่งที่ Supplier ต้องจ่ายเพื่อได้โอกาสนั้น:
  ค่าเช่าเชลฟ์ (Shelf Rent) = วางสินค้าระดับสายตา = จ่ายเพิ่ม
  ค่าโปรโมท (Promo Fees) = อยากแจกสแตมป์ก็จ่ายมา
  ค่าธรรมเนียมสาขา (Branch Fees) = อยากลงสาขาใกล้มหาวิทยาลัย = จ่ายพิเศษ
```

---

## จากผู้ซื้อ เป็น "ผู้คุมกฎ"

| | Dealer Thinking (เก่า) | Mall Thinking (ใหม่) |
|--|----------------------|---------------------|
| บทบาท | ฉันทำงาน แล้วรอให้ Supplier มาตรวจ/อนุมัติ | ฉันวางกติกา ถ้า Supplier ทำผิดสัญญา... โดนปรับ |
| Supplier | เป็นเจ้านาย | เป็นคู่ค้าที่ต้องปฏิบัติตามกติกา |
| ความรับผิดชอบ | ร้านค้าติดตามการขายเอง | กำหนด Act Plan ประกอบการจ่าย |
| เมื่อของขายไม่ออก | ขอส่วนลดเพิ่ม | Supplier รับผิดชอบ Non-move |

## เกมกระแสเงินสด (Cash Gap)

```
Day 1:  ลูกค้าซื้อสินค้า → ห้างได้เงินสดทันที
Day 60–90: ห้างจึงจ่ายเงินให้ Supplier (Credit Term)

Cash Gap = ห้างถือเงินสดไว้หมุนเวียนฟรี 2–3 เดือน
"ของขายหมดแล้ว แต่ยังไม่จ่ายเงิน Supplier"
```

---

## เงินต่อเงิน (Money Making Money)

```
เงินที่กองอยู่ (Floating Cash)
    ↓
ปล่อยกู้ / ลงทุน (Lending/Investing)
    ↓
ดอกเบี้ย / กำไร (Interest/Profit)

ตัวอย่าง: 7-11 ใช้เงินหมุนเวียนไปสร้าง TrueMoney หรือซื้อกิจการอื่น

สรุป: กำไรจากการขายของอาจน้อย
      แต่กำไรจากการหมุนเงินนั้นมหาศาล
```

---

## Move or Die: กฎเหล็กของสต็อก (Mall Stock Rules)

```
Mall Stock = บังคับเคลียร์ของตาย

Credit Limit: ของต้องขายหมดก่อน Credit Term จะครบกำหนด
Aging:        เกิน 30 วัน = เคลียร์ / เกิน 45 วัน = คืน
Responsibility: ถ้าขายไม่ออก → ปัญหาของ Supplier (ไม่ใช่ห้าง)

เปรียบเทียบ:
  Dealer Stock = เชียร์ขายของตาย (ห้างไม่รับผิดชอบ)
  Mall Stock   = บังคับเคลียร์ของตาย (ห้างกำหนด timeline)
```

## ตารางเปรียบเทียบ Dealer vs Modern Trade (Saengwichit Context)

### มิติ 1: การสั่งซื้อและเงื่อนไข

| หัวข้อ | Dealer | Modern Trade |
|--------|--------|-------------|
| **การคิดต้นทุน** | ต้นทุน + กำไร + Package/Promo | จากราคาขาย คิดเป็น % ซื้อเป็น One Price |
| **การเปิดเผยข้อมูล** | ความลับของร้าน จัดการเองทั้งหมด | เปิดเผยข้อมูลการแข่งขัน Sales ทำการบ้านมาเสนอ |
| **การชำระเงิน** | ชำระตาม Due วัน | ต้องขายหมดก่อน Due ชำระ |
| **Due ชำระ** | 30–60 วัน | 45–75 วัน แต่มีเงื่อนไข/Act Plan ประกอบ |
| **การจัดส่ง** | ส่งให้ตามสาขา มีขั้นต่ำ | ส่งฟรีทุกสาขา — ถ้าไม่ส่งฟรีต้องมี GP + ส่ง DC |
| **การรับสินค้า** | ตามรอบหรือ Run Rate | ห้ามสินค้าขาดสต็อก / ส่งไม่ตรงวัน = มีค่ารับ |
| **สินค้าโชว์** | มีส่วนลด ≥ [TBD]% | ลดขั้นต่ำ 10–15% / แอร์ใช้ Mockup เคลียร์ง่ายขึ้น |
| **พื้นที่โชว์** | ตามที่ตกลง | จำกัด — มีค่าเปิด SKU ครั้งแรก |
| **เปิดสาขาใหม่** | ส่วนลดตัวโชว์ | งบสนับสนุน / ราคาพิเศษ / เครดิตพิเศษ ≥ 50,000–100,000 บาท |
| **ค่ากิจกรรมการตลาด** | ไม่มีหรือน้อยมาก | สนับสนุนการตลาด + ค่าร่วมโฆษณา |
| **ค่า MA/Data Sharing** | ไม่มี | ~0.5% หรือ Fixed Cost |
| **ค่า E-Commerce** | ไม่มี | ~0.5% ถ้าเพิ่มช่องทางออนไลน์ |
| **PC/Promoter** | ร้านรับผิดชอบสินค้าเอง หรือมี PC แทน | บริษัทรับผิดชอบถ้าติดสต็อก — ไม่มี PC = โดน GP ต่อวัน |

### มิติ 2: ราคาและ Rebate

| หัวข้อ | Dealer | Modern Trade |
|--------|--------|-------------|
| **Rebate** | ตามเป้าหมาย ไม่ถึงไม่ได้ | สิ่งที่ต้องได้ = กำไรส่วนต่างของห้าง (เรียกเก็บแน่นอน) |
| **Rebate ไม่ผูกเป้า** | ไม่มี | จ่ายเป็นรายไตรมาสหรือปี / ซื้อเข้า หรือ Mkt Fee |
| **โปรโมชั่น Sell-Out** | ร้านติดตามการขายเอง | Act Plan → หน้าร้านกำหนดราคาขาย + Focus ติดตาม |
| **การเพิ่ม SKU** | เจ้าของตัดสินใจเอง | กำหนดเงื่อนไขชัดเจนก่อน |
| **Aging** | แจ้งขอ budget เคลียร์ราคา | มีขั้นตอนเป็นขั้นบันได (90 วัน → 120 วัน) |
| **เคลม/ซ่อม** | แล้วแต่ตกลง | ต้องเคลียร์ภายใน [TBD] วัน |
| **ค่าปรับล่าช้า** | ไม่มีหรือน้อย | ~5% ถ้าส่งสินค้าช้า |

### มิติ 3: การวางแผนสินค้า

| หัวข้อ | Dealer | Modern Trade |
|--------|--------|-------------|
| **การสั่งซื้อ** | Sales นำเสนอ ร้านตัดสินใจสั่ง | Sales ประสานงานและขออนุมัติจัดซื้อ |
| **การวางแผน** | เจ้าของสั่งตาม Run Rate | Sales วางแผน จัดซื้อมีหน้าที่อนุมัติ |
| **การตัดสินใจ** | Aging เป็นหลัก | GP / Demand / Aging / Take Lot ตัดสินใจร่วมกัน |
| **สินค้าติดสต็อก** | ขอ budget ทำโปรโมชั่น | 90 วัน → โปรโมชั่น / 120 วัน → รับกลับหรือเปลี่ยน |

## คำศัพท์เทคนิค: มันคือเงินก้อนเดียวกัน

```
CN (Credit Note)    = ใบลดหนี้/คืนของ
MOU / Rebate        = เงินรางวัลเป้าขาย (บังคับต้องได้)
Mkt Support         = งบส่งเสริมการขาย

ทั้ง 3 อย่างนี้ ห้างถือเป็น "ของตาย" ที่ต้องได้
ไม่ใช่ "ของแถม" จาก Supplier
```

---

## ศัพท์ Sell-In vs Sell-Out vs Sell-Through

```
Sell-In (ซื้อเข้า):
  ยอดที่ห้างสั่งซื้อจาก Supplier
  ได้ส่วนลดทันทีตอนซื้อ
  Supplier นับยอดตรงนี้

Sell-Out (ขายออก):
  ยอดที่ห้างขายได้จริงให้ end customer
  ต้องขายให้ได้ก่อน ถึงจะได้เงินคืน (เสี่ยงกว่า)
  หลายแบรนด์ใช้ระบบนี้เพื่อผูก Supplier

Sell-Through (Samsung ใช้):
  ยอดขายให้ร้านค้าส่ง (ไม่ใช่ end customer)
```

## หลักการ: เมื่อของขายไม่ออก อย่าเพิ่งจ่ายเงินแก้ปัญหา

```
ลำดับการแก้ปัญหาที่ถูกต้อง:
  1. Visibility: ลูกค้าเห็นของไหม?
  2. Display: แกะกล่องโชว์หรือยัง?
  3. Price Tag: ป้ายราคาถูกต้อง/ดึงดูดไหม?
  4. Commission: ทางเลือกสุดท้าย (Last Resort)

"การอัดฉีด 'รายตัว' คือทางเลือกสุดท้าย ไม่ใช่ทางเลือกแรก"
```

## บทสรุป: อย่าเป็นแค่ "คนสั่งของ"

```
Dealer Thinking (Before):
  เซลยัดเยียด → เราแบกสต็อก

Mall Thinking (After):
  ดู Data → ต่อรอง → กำหนดจุดรับผิดชอบ
  "ถ้าพี่ช่วยสั่งตัวนี้ แล้วขายไม่ออก คุณรับผิดชอบยังไง?"

หลักการ:
  อย่าซื้อถูกที่สุดแล้วจมสต็อก
  ต้องบริหารสต็อก ลาสต็อกให้หมุนเวียนและปลอดภัย
  ต้องแม่น: คำนวณต้นทุน/กำไรให้ถูกก่อนรับปาก
  เริ่มต้นที่ 'วิธีคิด' แล้ว 'กำไร' จะตามมาเอง
```
