## VAT Golden Rule — กฎทองที่ห้ามผิดพลาด

> **Golden Rule: อย่าเอา VAT มารวมก่อนคำนวณส่วนลด**

### วิธีที่ผิด (แต่คนชอบใช้)

```
ตัวอย่าง: Base Price 120 บาท, VAT 7%, Discount 20%

❌ วิธีผิด:
  Step 1: 120 + 7% = 128.4 (Price inc. VAT)
  Step 2: 128.4 − 20% = 102.72

ทำไมผิด: คุณกำลังเอาส่วนลดไปหักออกจาก VAT
          ซึ่งสรรพากรไม่ยอมรับ
ผล: คิดว่าต้นทุน 102.72 แต่จริงๆ ต้นทุนสูงกว่านั้น
```

### วิธีที่ถูกต้อง

```
✅ วิธีถูก:
  Base Price: 120
  VAT (7% of 120): +8.4
  Discount (20% of 120): −24.0
  ต้นทุนจริง: 120 + 8.4 − 24 = 104.4

ต้นทุนจริง (104.4) − ต้นทุนที่คิดผิด (102.72) = หายไป 1.68 บาท!
ถ้าขาย 104 บาท คิดว่ากำไร แต่จริงๆ ขาดทุน
```

### กฎจำง่าย

```
ส่วนลด (%) คิดจาก Base Price เสมอ
VAT คิดจาก Base Price เสมอ
สองอย่างนี้คำนวณแยกกัน แล้วค่อยรวม

สูตร: ต้นทุนจริง = Base × (1 + VAT%) × (1 − Discount%)
ตัวอย่าง: 120 × 1.07 × 0.80 = 102.72 ❌ (ยังผิด!)

สูตรที่ถูก: ต้นทุนจริง = Base × (1 − Discount%) + Base × VAT%
           = 120 × 0.80 + 120 × 0.07
           = 96 + 8.4 = 104.4 ✅
```

> ⚠️ เซลมักจะสอนวิธีคิดที่ "ผิด" เพื่อให้ราคาดูถูกลง — ระวังด้วย

## ภาพลวงตากำไร 5%

```
สถานการณ์: คุณคิดว่าได้กำไร 5% แต่จริงๆ อาจขาดทุน

เหตุผล:
  การคิดกำไร (Markup) ต้องคิดจากต้นทุนที่ถอด VAT แล้วเท่านั้น
  ถ้าตั้งราคาผิดตั้งแต่ต้น → ยิ่งขาย ยิ่งเจ็บตัว

ตรวจสอบ:
  □ ต้นทุนที่ใช้คิดราคาขายถอด VAT ออกแล้วหรือยัง?
  □ ส่วนลดคิดจาก Base Price หรือ Price inc. VAT?
  □ Rebate และค่าห้างทุกรายการรวมในต้นทุนแล้วหรือยัง?
```

## True Margin — ต้นทุนจริงหลังหักค่าห้างทั้งหมด

### สูตร

```
True Margin = ราคาขาย − ต้นทุนสินค้า (ex-VAT) − ค่าใช้จ่ายห้างทั้งหมด

ค่าใช้จ่ายห้างที่ต้องนับครบ:
  Rebate:              [%] ของยอดขาย
  Marketing Fee:       [%] ของยอดซื้อ
  DC Fee:              [%] ของยอดสินค้า (ถ้าผ่าน DC)
  Transportation:      [%] หรือบาทคงที่
  PC/SPE Fee:          บาทต่อวัน/เดือน
  New Store Opening:   บาทต่อสาขา ÷ ยอดขาย
  Software/EDI:        บาทคงที่/ปี ÷ ยอดขาย
  Penalty (ประมาณ):    จากประวัติที่ผ่านมา
```

### ตัวอย่างการคำนวณ

```
สมมติ:
  ราคาขายห้าง:     10,000 บาท (ex-VAT)
  ต้นทุนสินค้า:     7,500 บาท (65% margin ดิบ = 25%)

รายการหักค่าห้าง:
  Rebate 2.5%:      250 บาท
  Marketing Fee 2%: 200 บาท
  DC Fee 5%:        500 บาท
  Transport:        0 (ส่งเอง)
  PC Fee:           50 บาท/เดือน → ÷ ยอด = ~30 บาท
  รวมค่าห้าง:      980 บาท (9.8% ของราคาขาย)

Gross Profit:  10,000 − 7,500 = 2,500 บาท (25%)
True Profit:   2,500 − 980   = 1,520 บาท (15.2%)

ที่คิดว่าได้ 25% จริงๆ ได้แค่ 15.2%
```

## PSI & MOS — เครื่องมือตัดสินใจสั่งซื้อ

### PSI (Production Sales Inventory)

```
PSI = ระบบติดตาม 3 มิติพร้อมกัน:
  P (Production/Purchase): แผนการสั่งซื้อ/ผลิต
  S (Sales):               ยอดขายจริงและแผน
  I (Inventory):           สต็อกคงเหลือ

ทำไมต้องดู PSI ก่อนสั่ง:
  ป้องกันสั่งเกิน ทั้งที่ขายไม่ออก
  ทำให้เห็นว่า gap ระหว่างซื้อกับขายอยู่ที่ไหน
  เป็นข้อมูลสำหรับคุยกับห้างอย่างมีน้ำหนัก
```

### MOS (Month of Stock)

```
สูตร: MOS = สต็อกคงเหลือ ÷ ยอดขายเฉลี่ยต่อเดือน

ตัวอย่าง:
  สต็อกคงเหลือ:      200 ชิ้น
  ขายเฉลี่ย/เดือน:    80 ชิ้น
  MOS = 200 ÷ 80 = 2.5 เดือน

เกณฑ์ตัดสินใจ:
  MOS < 1 เดือน  → เสี่ยงสินค้าขาด — พิจารณาสั่งเพิ่ม
  MOS 1–2 เดือน → Healthy Zone — สั่งได้ตามปกติ
  MOS > 2 เดือน → ⚠️ WARNING — หยุดสั่งทันที!
  MOS > 3 เดือน → 🚨 DANGER — ต้องเคลียร์สต็อกก่อน
```

> **กฎเหล็ก: ถ้า MOS สูงเกิน 2 เดือน = หยุดสั่งทันที**
> ไม่ว่าโปรโมชั่นจะดีแค่ไหน ไม่ว่า Sales จะ push แค่ไหน

### การใช้ MOS คุยกับห้าง/Sales

```
สถานการณ์: Sales ขอให้สั่งสินค้า Take Lot ราคาพิเศษ

ก่อนตอบ → เช็ค MOS ก่อนเสมอ:

ถ้า MOS < 1 → "ได้เลย ตอนนี้สต็อกใกล้หมด Take Lot คุ้มมาก"
ถ้า MOS 1–2 → "ดูตัวเลขก่อน ถ้าราคาดีพอ พิจารณาได้"
ถ้า MOS > 2 → "ขอโทษ ตอนนี้ MOS เรา [X] เดือน
               ต้องเคลียร์สต็อกเก่าก่อน ถึงจะพิจารณาได้
               ช่วยเสนอแผนระบายสต็อกเก่าให้ก่อนได้ไหม?"
```

## Sell-In vs Sell-Out: อย่าให้ห้างจับเสือมือเปล่า

```
กับดัก Sell-In:
  ห้างสั่งเยอะ (Sell-In สูง) แต่ขายให้ลูกค้าไม่ได้ (Sell-Out ต่ำ)
  ผล: สต็อกค้างที่ห้าง → ห้างบังคับให้ Supplier รับกลับ
  Supplier แบกสต็อกสองชั้น: ที่ตัวเอง + ที่ห้าง

วิธีป้องกัน:
  Track ทั้ง Sell-In AND Sell-Out
  ถ้า Sell-Out ต่ำ → หยุด Sell-In ทันที แม้ห้างจะขอ
  เพราะ MOS ที่ห้าง = MOS ที่เราต้องรับผิดชอบในอนาคต
```

## Checklist ก่อนตัดสินใจสั่งซื้อทุกครั้ง

```
□ MOS ปัจจุบันคือเท่าไหร่?
  → ถ้า > 2 เดือน → หยุด ไม่ต้องอ่านข้อต่อไป

□ True Margin หลังหักค่าห้างทั้งหมดคือเท่าไหร่?
  → ถ้า < [TBD %] → เจรจาใหม่หรือปฏิเสธ

□ VAT คำนวณถูกวิธีแล้วหรือยัง?
  → ส่วนลดคิดจาก Base Price เท่านั้น

□ Sell-Out ที่ห้างนี้เป็นอย่างไร?
  → ถ้า Sell-Out ต่ำ กว่า Sell-In → อย่าเพิ่มสต็อก

□ มีเงื่อนไข Non-move / Penalty อะไรในสัญญา?
  → ถ้ารับสต็อกแล้วขายไม่ออก ผลที่ตามมาคืออะไร?
```
