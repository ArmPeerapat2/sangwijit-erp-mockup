# บริหารความเสี่ยง: Non-move / Penalty / PC / Claim

---

## 1. สินค้า Non-move / Slow-moving

### สัญญาณเตือนที่ต้องจับตา
```
  30 วัน: ยอดขาย < 30% ของที่คาด → เริ่มวางแผนกระตุ้น
  60 วัน: ยอดขาย < 50% → เริ่มโปรโมทจริง + แจ้งทีมขาย
  90 วัน: ห้างมักเรียกเก็บค่าสนับสนุนโปร (Home Hub)
  120 วัน: ห้างมักบังคับรับคืนหรือแลกสินค้า
```

### แนวทางจัดการก่อนถึง 90 วัน
1. ประสาน Brand Rep ห้าง → ขอ slot โปรโมชั่นพิเศษ
2. ลด price tag ชั่วคราว (ถ้าทำได้ภายในกรอบ agreement)
3. เพิ่ม PC ชั่วคราวหน้าสินค้านั้นๆ
4. ขอย้ายตำแหน่งวางสินค้าให้เด่นขึ้น
5. ทำ bundle กับสินค้าขายดี (เช่น ซื้อแอร์แถม remote holder)

### ถ้าถึง 90 วันแล้ว (Home Hub model)
```
ห้างเรียกเก็บ:
  □ ค่าสนับสนุนโปรฯ [TBD %] ต่อ SKU
  □ จ่ายภายใน 2 เดือนนับจากวัน CN ในระบบ
  ⚠️ ถ้าเกินกำหนด → ห้างระงับการจ่ายค่าสินค้า

แนวทาง:
  → จ่าย CN ทันที อย่าให้ค้างเกิน 2 เดือน
  → ถ้าทำโปรแล้วยังเหลือ 30 วัน → ห้างบังคับรับคืน
  → รับคืนแล้ว → นำไประบายที่ช่องทางอื่น (ค้าส่ง/ออนไลน์)
```

## 2. Lead Time Penalty

### วิธีป้องกัน
```
ก่อนเซ็น agreement:
  □ ตรวจสอบ lead time จริงกับ supplier ต้นน้ำ
  □ ขอ buffer 2–3 วันเพิ่มจาก lead time จริง
  □ ระบุว่า penalty ใช้เมื่อไหร่ (นับจาก PO confirmed หรือ order date?)

ระหว่างปี:
  □ Track PO ทุกใบ — วันรับ vs วันกำหนดส่ง
  □ ถ้าจะล่าช้า → แจ้งห้างล่วงหน้าก่อน deadline เสมอ
  □ บางห้างให้ขยายเวลาได้ถ้าแจ้งก่อน (แต่ไม่ได้ถ้าแจ้งหลัง)
```

---

## 3. Over Order / Mistake Order

### วิธีป้องกัน
```
ก่อนส่งของ:
  □ ตรวจ PO ทุกใบก่อน pick สินค้า
  □ ตรวจรุ่น + จำนวน + ห้องกระจาย
  □ ถ้า PO ผิด → แจ้งห้างทันที ก่อนส่งของ
  □ ไม่ส่งของเกิน PO แม้ห้างจะขอเพิ่มทางโทรศัพท์ — ต้องมี PO ใหม่เสมอ
```

## 4. PC/Nominee Management

### ข้อกำหนดที่พบบ่อย
```
  Home Hub: ส่ง PC ภายใน 15 วันหลังเซ็นสัญญา
            ถ้าไม่ทัน = 1,500 บาท/วัน/คน
  Do Home:  PC ขาดงาน = 600 บาท/วัน/คน
  Global House: ผู้ค้าสนับสนุนค่าจัด SPE ตามที่ระบุ
```

### แนวทางบริหาร PC ให้ไม่โดน penalty
```
1. ทำ Roster ล่วงหน้า 1 เดือน — รู้ว่าวันไหนขาด
2. มี PC สำรอง (ลิสต์คนที่โทรได้ทันที)
3. ถ้า PC ลาป่วยฉุกเฉิน → แจ้ง Floor Manager ห้างทันที พร้อมเอกสาร
4. บางห้างยอมรับ "PC งานนอกสาขา" ถ้ามีหนังสือรับรอง — เจรจาล่วงหน้า
5. Track record การขาดงานรายสาขา — PC ที่ขาดบ่อยต้องเปลี่ยน
```

## 5. Claim / Returns จากการขนส่ง

```
Home Hub: ผู้ค้าต้องรับสินค้าเสียหายจากขนส่งคืนทั้งหมด
          + รับผิดชอบค่าขนส่งที่เกิดขึ้น
          ถ้าไม่มารับสินค้าจาก DC ใน 7 วัน = 2,000 บาท/วัน/บิล

แนวทาง:
  □ ถ่ายรูปสินค้าก่อนส่งทุกครั้ง (หลักฐาน)
  □ ให้ลูกค้าเซ็นรับสภาพสินค้าที่หน้าร้าน
  □ ถ้าห้างแจ้ง claim → ไปรับทันที อย่าปล่อยเกิน 5 วัน
  □ Claim ที่เกิดจากขนส่งของห้างเอง → ยกเว้น (ต้องมีหลักฐาน)
```

## 7. Checklist รายเดือนสำหรับทีมจัดซื้อ/ขาย

```
ต้นเดือน:
  □ ตรวจสต็อกสินค้าในแต่ละห้าง — รายการที่ขายช้า
  □ ตรวจ PC Roster เดือนนี้ — มีวันที่ขาดไหม?
  □ เช็ค deadline เอกสารห้างที่ต้องส่งเดือนนี้

กลางเดือน:
  □ ติดตาม PO ที่รอส่ง — ทันกำหนดไหม?
  □ ตรวจ Non-move list — ใกล้ 60 วันรายการไหน?

ปลายเดือน:
  □ รวบรวมยอดขายแต่ละห้าง vs เป้า Rebate tier
  □ ส่งเอกสาร WHT ให้ Global House (ถ้ามีรายการเดือนนี้)
  □ สรุป claim/return ที่เกิดขึ้น
```
