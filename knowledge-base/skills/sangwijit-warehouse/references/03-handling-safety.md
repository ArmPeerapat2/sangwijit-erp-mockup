# การยกและเคลื่อนย้ายสินค้า / ความปลอดภัย

---

## หลักการ: ปลอดภัยก่อน เร็วทีหลัง

```
สินค้าเสียหาย = ต้นทุนของบริษัท
พนักงานบาดเจ็บ = ใหญ่กว่าสินค้าเสียหาย

ถ้าไม่แน่ใจว่ายกได้ปลอดภัยหรือไม่ → หยุด → ขอความช่วยเหลือ
```

---

## น้ำหนักและอุปกรณ์ที่ต้องใช้

| สินค้า | น้ำหนักโดยประมาณ | อุปกรณ์ที่ต้องใช้ |
|--------|----------------|-----------------|
| แอร์ Indoor | 8–15 กก. | 2 คน หรือ hand truck |
| แอร์ Outdoor | 25–50 กก. | Hand truck + 2 คน |
| ตู้เย็น 1 ประตู | 30–45 กก. | Hand truck + 2 คน |
| ตู้เย็น 2 ประตู | 55–90 กก. | Appliance dolly + 2 คน |
| เครื่องซักผ้า | 45–85 กก. | Appliance dolly + 2 คน |
| ทีวี (≤50") | 10–20 กก. | 2 คน (จับขอบกล่อง) |
| สินค้าเล็ก | < 10 กก. | 1 คน |

> **กฎ:** สินค้า > 20 กก. ห้ามยกคนเดียว

## เทคนิคการยกที่ถูกต้อง

### การยกด้วยมือ (สินค้าเบา < 20 กก.)

```
ท่าที่ถูก:
  1. ยืนใกล้สินค้า เท้าห่างกันเท่าไหล่
  2. ย่อเข่าลง (ไม่ก้มหลัง)
  3. จับสินค้าให้มั่น สองมือ
  4. ลุกขึ้นด้วยแรงขา (ไม่ใช่หลัง)
  5. สินค้าชิดลำตัว ไม่แขนยื่น
  6. หมุนด้วยเท้า ไม่บิดเอว

❌ ห้าม:
  → ก้มหลังยก (หลังส่วนล่างบาดเจ็บ)
  → บิดตัวขณะถือของหนัก
  → ยกเกินความสามารถคนเดียว
```

### การใช้ Hand Truck / Appliance Dolly

```
Hand Truck (รถเข็นตัว L):
  1. เข็นมาชิดสินค้า เอียง 45°
  2. สอดแผ่นเหล็กล่างใต้กล่อง
  3. เอนรถเข็นพิงสินค้า
  4. ใช้สายรัด (ถ้ามี) รัดกล่องกับรถ
  5. เข็นโดยเอนรถมาทางตัวเอง

Appliance Dolly (รถเข็นหมุนได้):
  ใช้สำหรับสินค้าหนักพิเศษ (ตู้เย็น/ซักผ้า)
  ต้องผ่านการฝึกก่อนใช้งาน
  [TBD: ขั้นตอนการใช้รถเฉพาะของคลัง]
```

## การเคลื่อนย้ายสินค้าขนาดใหญ่ (2 คน)

```
คน A (ด้านหน้า/นำทาง):
  → มองเส้นทาง แจ้งอุปสรรค
  → เดินถอยหลัง ระวังขั้นบันได/ขอบ

คน B (ด้านหลัง/ดัน):
  → ออกแรงหลัก
  → ฟังสัญญาณจาก A

สัญญาณที่ต้องตกลงกันก่อน:
  "พร้อม" = ทั้งคู่พร้อม
  "วาง" = วางพร้อมกัน
  "หยุด" = หยุดทันที
  "ซ้าย/ขวา" = เลี้ยว

⚠️ ห้ามพูดเรื่องอื่นระหว่างยกของหนัก
```

## ข้อห้ามในคลัง (Safety Rules)

```
ห้ามเด็ดขาด:
  ❌ วิ่งในคลัง
  ❌ กองสินค้าสูงเกิน 1.8 เมตร (ยกเว้นมีชั้นวาง)
  ❌ ทิ้งกล่องเปล่า / ลังไม้ กลางทางเดิน
  ❌ ปิดกั้นทางออกฉุกเฉิน
  ❌ เล่นโทรศัพท์ระหว่างยกของ
  ❌ ยกคนเดียวเกิน 20 กก.
  ❌ วางสินค้าบนพื้นที่มีน้ำ

ต้องทำ:
  ✅ สวมรองเท้าหัวเหล็ก (ถ้ามี)
  ✅ เดินในเส้นทางที่กำหนด
  ✅ รายงานพื้นลื่น / ของหล่น / ไฟดับทันที
  ✅ ปิดประตูคลังเมื่อไม่ได้ใช้งาน
```

## การเคลื่อนย้ายสินค้า Display

```
สินค้า Display ต้องระวังพิเศษ:
  → มีรอยขีดข่วนแล้ว — ห้ามทำให้มากขึ้น
  → ยังมีมูลค่าอยู่ แต่ต่ำกว่าสินค้าใหม่
  → ต้องติดป้าย "Display Unit" ชัดเจนตลอดเวลา
  → บันทึก S/N และสภาพก่อนย้ายทุกครั้ง
  → ถ่ายรูปก่อนและหลังย้ายทุกครั้ง
```

## การจัดการเมื่อสินค้าเสียหายในคลัง

```
ถ้าสินค้าเสียหายระหว่างจัดเก็บ/เคลื่อนย้าย:
  1. หยุดทำงาน อย่าปิดบัง
  2. ถ่ายรูปทันที
  3. แจ้งหัวหน้าคลังทันที
  4. กรอกแบบฟอร์มรายงานสินค้าเสียหาย [TBD]
  5. ย้ายสินค้าเสียหายไปโซน E (พักรอ)
  6. รอการตัดสินใจจากหัวหน้าว่าซ่อมหรือตัดจำหน่าย

⚠️ การซ่อนสินค้าเสียหาย = ความผิดทางวินัยร้ายแรง
```
