# การโอน / การเบิก / การย้ายระหว่างคลัง

---

## หลักการ: ทุกการเคลื่อนย้ายต้องมีเอกสาร

```
ห้ามเคลื่อนย้ายสินค้าออกจากคลังโดยไม่มีเอกสาร
แม้จะย้ายแค่ข้ามห้องหรือข้ามสาขา
เหตุผล: ถ้าไม่บันทึก → ระบบผิด → นับสต็อกไม่ตรง → หาสาเหตุไม่ได้
```

---

## ประเภทการเคลื่อนย้ายสินค้า

```
1. โอนระหว่างคลัง (Inter-Warehouse Transfer)
   คลังใหญ่ → สาขา หรือ สาขา → สาขา

2. เบิกใช้ภายใน (Internal Requisition)
   เบิกสำหรับใช้ในองค์กร เช่น ติดตั้งในออฟฟิศ

3. จ่ายขายให้ลูกค้า (Sales Delivery)
   ออกสินค้าตาม Sales Order

4. ส่งซ่อม / ส่งคืน Vendor (Return to Vendor)
   สินค้าชำรุด / Non-move ที่ตกลงส่งคืน
```

---

## SOP 1: โอนสินค้าจากคลังใหญ่ไปสาขา

```
ผู้ขอ (สาขา):
  1. ตรวจสอบสต็อกที่สาขาก่อน (อย่าขอถ้ายังมีพอ)
  2. สร้างใบขอโอนในระบบ [Hero/Dynamics — TBD]
     ระบุ: รุ่น / จำนวน / S/N (ถ้ารู้) / สาขาปลายทาง
  3. ส่งให้หัวหน้าสาขาอนุมัติ

คลังใหญ่ (ผู้จ่าย):
  4. รับใบขอ ตรวจสต็อกว่ามีพอ
  5. เลือกสินค้าตาม FIFO (ของเก่าออกก่อน)
  6. สแกน S/N ทุกชิ้น → บันทึกในระบบ
  7. ออก Transfer Order / ใบโอนสินค้า
  8. บรรจุหีบห่อให้ปลอดภัย + ติดป้ายปลายทาง
  9. ส่งพร้อมเอกสารครบ

สาขา (ผู้รับ):
  10. รับสินค้า ตรวจนับ ตรวจสภาพ
  11. สแกน S/N ยืนยันตรงกับเอกสาร
  12. ยืนยันรับในระบบ (ปิด Transfer Order)
  13. ถ้ามี Discrepancy → แจ้งคลังใหญ่ทันที (ไม่เกิน 24 ชม.)
```

## SOP 2: โอนสินค้าระหว่างสาขา

```
ต้องได้รับอนุมัติจาก: หัวหน้าคลังใหญ่ [TBD]
เหตุผลที่โอนได้: สาขา A สต็อกล้น / สาขา B ขาด

ขั้นตอน:
  1. สาขา B ขอโอนในระบบ → ระบุเหตุผล
  2. หัวหน้าคลังอนุมัติ
  3. สาขา A จ่ายออก → บันทึก S/N + ออกเอกสาร
  4. รถขนส่ง/พนักงานรับ → ไม่ให้วางไว้กลางทาง
  5. สาขา B รับและยืนยันในระบบ

⚠️ Consignment Model:
  เมื่อสินค้าโอนจาก SWT ไป SWE ทุกสาขา
  → ยอดสต็อก SWT ลด / ยอด Consignment SWE เพิ่ม
  → SWE รับผิดชอบสินค้านั้นทันทีที่ยืนยันรับ
```

## SOP 3: เบิกสินค้าออกขาย (Sales Delivery)

```
เงื่อนไขก่อนจ่ายออก:
  □ มี Sales Order / Invoice ที่ชำระแล้วหรืออนุมัติสินเชื่อแล้ว
  □ ห้ามจ่ายสินค้าออกก่อนได้รับ Payment (เว้นแต่มีอนุมัติ)
  □ ตรวจว่า S/N ที่จ่ายตรงกับที่บันทึกใน SO

ขั้นตอน:
  1. รับ Picking List จากระบบหรือพนักงานขาย
  2. เลือกสินค้าตาม FIFO
  3. สแกน S/N ทุกชิ้น → บันทึก Delivery ในระบบ
  4. ออกใบส่งสินค้า (Delivery Note)
  5. ให้ลูกค้า / พนักงานส่ง เซ็นรับ
  6. คืนสำเนาเซ็นแล้วให้คลัง เก็บไว้อ้างอิง

ห้ามจ่ายออก:
  □ สินค้าที่อยู่ใน Status "พักรอ/ค้างตรวจ"
  □ Display ที่ไม่มีการอนุมัติขาย
  □ สินค้าที่ S/N ไม่ตรงกับระบบ
```

## SOP 4: ส่งซ่อม / ส่งคืน Vendor

```
กรณีส่งซ่อม (ศูนย์บริการ):
  1. ออกใบส่งซ่อม ระบุ S/N + อาการ + วันที่ส่ง
  2. บันทึกในระบบ Status = "ระหว่างซ่อม"
  3. รับกลับเมื่อซ่อมเสร็จ + ตรวจสภาพ + อัปเดตระบบ
  4. ถ้าซ่อมไม่ได้ → รายงานหัวหน้า + บันทึก "ตัดจำหน่าย"

กรณีส่งคืน Vendor (Non-move / ชำรุด):
  1. ได้รับอนุมัติจาก: จัดซื้อ + หัวหน้าคลัง
  2. ออกใบส่งคืน (Return to Vendor / RTV) ในระบบ
  3. บรรจุหีบห่อ + ถ่ายรูปก่อนส่ง
  4. ส่งพร้อมเอกสาร RTV
  5. รอ Credit Note จาก Vendor (ประสาน AP + จัดซื้อ)
  6. ปิด RTV ในระบบเมื่อได้รับ CN
```

## SOP 5: รับสินค้าคืนจากลูกค้า (Sales Return)

```
เงื่อนไขรับคืน:
  □ ได้รับอนุมัติจากหัวหน้าสาขา / ผู้จัดการ
  □ มีเหตุผลที่ยอมรับได้ (ชำรุด / ผิดรุ่น / ผิดสี)
  □ อยู่ภายในระยะเวลา [TBD: กี่วัน]

ขั้นตอน:
  1. ถ่ายรูปสภาพสินค้าที่รับคืน
  2. ออกใบรับคืน + ลายเซ็นลูกค้า
  3. ตรวจ S/N ตรงกับที่ขายออกไปหรือไม่
  4. บันทึก Sales Return ในระบบ
  5. ตัดสินใจสภาพ:
     ดีปกติ → เข้า Stock ปกติ
     มีรอย/ใช้แล้ว → เข้า Display Stock
     ชำรุด → โซน E รอการตัดสินใจ
  6. ออก Credit Note ให้ลูกค้า (ผ่านแคชเชียร์/บัญชี)
```

## เอกสารที่ต้องมีในทุกการเคลื่อนย้าย

| ประเภท | เอกสารที่ต้องมี |
|--------|---------------|
| โอนระหว่างคลัง | Transfer Order + ใบโอนสินค้า + ลายเซ็นรับ |
| จ่ายขาย | Sales Order / Invoice + Delivery Note + ลายเซ็นรับ |
| ส่งซ่อม | ใบส่งซ่อม + S/N + อาการ |
| ส่งคืน Vendor | RTV Order + ใบส่งคืน + ถ่ายรูป |
| รับคืนจากลูกค้า | ใบรับคืน + ลายเซ็นลูกค้า + ถ่ายรูป |

> ⚠️ ไม่มีเอกสาร = ไม่เคลื่อนย้าย — ไม่มีข้อยกเว้น
