# การรับสินค้า (Goods Receiving)

---

## หลักการ: ตรวจก่อนเซ็น — เซ็นแล้วรับผิดชอบ

```
ห้ามเซ็นรับสินค้าโดยไม่ตรวจ
ถ้าเซ็นแล้ว = รับผิดชอบความเสียหายทั้งหมด
แม้จะพบทีหลังก็อ้างว่าเสียหายตอนขนส่งไม่ได้
```

---

## SOP รับสินค้าจาก Vendor / รถขนส่ง

### ขั้นตอน 1: เตรียมก่อนรถมาถึง
```
□ ตรวจ PO ในระบบว่ามีการสั่งซื้อจริง
□ รู้จำนวนและรายการที่ต้องรับ
□ เตรียมพื้นที่รับสินค้าให้โล่ง
□ เตรียมอุปกรณ์: hand truck / รถยก / กรรไกร
```

### ขั้นตอน 2: ตรวจสภาพกล่องก่อนขนลง
```
ดูจากบนรถก่อน — ถ้าเห็นสิ่งเหล่านี้ → ถ่ายรูปทันที:
  □ กล่องบุบ / ยุบ / เจาะทะลุ
  □ กล่องเปียก / มีรอยน้ำ
  □ กล่องเอียงผิดทิศทาง (ลูกศร "This Side Up" คว่ำ)
  □ เทปกาวปิดไม่สนิทหรือถูกแกะแล้วปิดใหม่
  □ จำนวนกล่องไม่ตรงกับเอกสาร

ถ่ายรูปทุกกล่องที่มีปัญหาก่อนลงจากรถ
```

### ขั้นตอน 3: ตรวจนับจำนวน
```
นับพร้อมคนขับ / พนักงานส่ง:
  □ นับจำนวนกล่องตรงกับใบส่งของหรือไม่?
  □ รุ่นสินค้าตรงกับ PO หรือไม่?
  □ ถ้าไม่ตรง → บันทึกส่วนต่างก่อนเซ็น

ห้าม: เซ็นรับของก่อนนับ แม้คนขับจะรีบ
```

### ขั้นตอน 4: ตรวจสภาพสินค้าในกล่อง (Spot Check)
```
เปิดตรวจทุกกล่องที่มีรอยเสียหายภายนอก
สุ่มตรวจกล่องปกติ 10–20%

สิ่งที่ตรวจในกล่อง:
  □ สินค้าครบตามที่ระบุในกล่อง
  □ Serial Number อยู่บนตัวสินค้า (ไม่ถูกลอก)
  □ ไม่มีรอยขีดข่วน / บุบ / แตก
  □ อุปกรณ์มาตรฐานครบ (รีโมท / สาย / คู่มือ)
  □ ฉลากรับประกันไม่ถูกแกะ (hologram seal สมบูรณ์)
```

### ขั้นตอน 5: บันทึกและเซ็นรับ
```
กรณีสินค้าปกติ:
  → เซ็นรับและลงรับในระบบ [Hero/Dynamics — TBD]
  → ออก GRN (Goods Received Note)

กรณีพบความเสียหาย:
  → บันทึกรายการเสียหายในใบส่งของ พร้อมลายเซ็นคนขับ
  → ถ่ายรูปทุกรายการ
  → แจ้ง Vendor/บริษัทขนส่งทันที (ภายใน 24 ชม.)
  → แจ้งหัวหน้าคลังและฝ่ายจัดซื้อ
  → บันทึก Discrepancy ในระบบ

กรณีไม่ยอมให้ตรวจ / คนขับรีบมาก:
  → เขียนหมายเหตุในใบส่งของ: "รับโดยไม่ได้ตรวจสภาพ"
  → ถ่ายรูปทุกกล่อง
  → ตรวจทันทีหลังลงจากรถ
```

## การบันทึก Serial Number ตอนรับสินค้า

```
สินค้าที่ต้องบันทึก S/N ทุกชิ้น:
  ✅ แอร์ (indoor + outdoor แยกกัน)
  ✅ ตู้เย็น
  ✅ เครื่องซักผ้า
  ✅ ทีวี
  ✅ สินค้าที่ราคา ≥ [TBD] บาท

วิธีบันทึก S/N:
  1. หา S/N บนกล่องก่อน (มักอยู่ข้างกล่องหรือด้านล่าง)
  2. ถ้ากล่องไม่มี → เปิดกล่องหาบนตัวสินค้า
  3. บันทึกในระบบ [Hero/Dynamics — TBD] ทันที
  4. ไม่บันทึกในระบบ = ห้ามนำสินค้าเข้าคลัง

⚠️ S/N ต้องตรงกับตัวสินค้าที่อยู่จริง
   ห้ามบันทึก S/N จากกล่องโดยไม่ตรวจตัวสินค้า
```

---

## รับสินค้าพิเศษ

### แอร์ (มี 2 ชิ้น: Indoor + Outdoor)
```
□ ตรวจทั้ง 2 กล่องพร้อมกัน
□ ตรวจว่า S/N Indoor และ Outdoor เป็นคู่กันตามที่ระบุ
□ ถ้า S/N ไม่คู่กัน → แจ้ง Vendor ทันที ห้ามรับเข้าระบบ
□ เก็บ Indoor และ Outdoor ไว้ด้วยกัน (ป้ายระบุคู่)
```

### สินค้าขนาดใหญ่ (ตู้เย็น 2 ประตู / เครื่องซักผ้า Front Load)
```
□ ใช้อุปกรณ์ยกเสมอ — ห้ามยกด้วยมือเปล่า
□ ตรวจขาตั้งไม่บิ่น / ประตูไม่บิดเบี้ยว
□ ทดสอบเปิดประตูได้สะดวก (ก่อนเก็บเข้าคลัง)
```

### อะไหล่และอุปกรณ์เล็ก
```
□ นับชิ้นต่อถุง/กล่อง ต้องตรงตาม Invoice
□ เก็บในพื้นที่อะไหล่แยกจากสินค้าทั่วไป
□ ติดป้ายรหัสอะไหล่ทันที
```

## Checklist รับสินค้า (ใช้ทุกครั้ง)

```
ก่อนรถมาถึง:
  □ ตรวจ PO ในระบบ
  □ เตรียมพื้นที่และอุปกรณ์

ระหว่างรับ:
  □ ถ่ายรูปกล่องเสียหาย (ก่อนลง)
  □ นับจำนวนตรงกับใบส่ง
  □ ตรวจสภาพกล่อง 100%
  □ Spot check สินค้าในกล่อง 10–20%
  □ บันทึก S/N สินค้าที่กำหนด

หลังรับ:
  □ เซ็นใบส่งของ (พร้อมหมายเหตุถ้ามีปัญหา)
  □ บันทึก GRN ในระบบ
  □ แจ้งหัวหน้าถ้ามีรายการผิดปกติ
  □ จัดวางสินค้าใหม่ก่อนทำอย่างอื่น (ห้ามทิ้งกลางทาง)
```
