# ผังคลัง / FIFO / การเก็บสินค้า / การดู S/N

---

## หลักการ: "ของเก่าออกก่อน" (FIFO — First In, First Out)

```
สินค้าที่รับเข้าก่อน ต้องออกก่อนเสมอ
เหตุผล:
  → ป้องกันสินค้าเสื่อมสภาพ / ล้าสมัย
  → ป้องกัน MOS สูงโดยไม่รู้ตัว
  → ถ้าสินค้าเก่าอยู่ด้านใน คนหยิบจะหยิบของใหม่ออกไปก่อน

วิธีปฏิบัติ:
  → รับสินค้าใหม่เข้า → วางด้านหลัง
  → ออกสินค้าจาก → ด้านหน้าเสมอ
  → ทุกครั้งที่เติมสต็อก → ดัน/เลื่อนของเก่าไปด้านหน้าก่อน
```

## ผังคลังและการแบ่งโซน

### โครงสร้างโซนหลัก (ปรับตามขนาดจริงของแต่ละคลัง)

```
โซน A — สินค้าขนาดใหญ่ (แอร์ / ตู้เย็น / ซักผ้า)
  → ต้องใช้อุปกรณ์ยก
  → จัดเรียงตั้งตรง ไม่ซ้อนกัน (เว้นแต่กล่องแข็งแรงพอ)
  → เว้นทางเดินระหว่างแถว ≥ 80 ซม.

โซน B — สินค้าขนาดกลาง (ทีวี / เครื่องปั่น / พัดลม)
  → ซ้อนได้ตามคำแนะนำบนกล่อง
  → เรียงตามรุ่น + ขนาด

โซน C — สินค้าขนาดเล็ก (หม้อ / เตา / เครื่องสำอางผม)
  → ใส่ชั้นวาง (Rack)
  → จัดเรียงตามหมวด + แบรนด์

โซน D — สินค้า Display / โชว์รูม
  → แยกชัดเจนจากสินค้าพร้อมขาย
  → ป้ายชัดว่า "DISPLAY — ไม่จำหน่าย" หรือ "โชว์รูม"
  → บันทึก S/N ทุกชิ้น + วันที่เริ่มใช้โชว์

โซน E — สินค้าพักรอ / ค้างตรวจ / มีปัญหา
  → แยกออกจากสินค้าปกติเด็ดขาด
  → ป้ายสีแดง ระบุเหตุผล + วันที่
  → ห้ามจ่ายออกก่อนได้รับการแก้ไข

โซน F — อะไหล่ / อุปกรณ์เสริม
  → Rack แยก พร้อมป้ายรหัสอะไหล่
```

## การเก็บสินค้าแต่ละหมวด

### แอร์ (Air Conditioner)
```
ข้อห้ามสำคัญ:
  ❌ ห้ามวางนอน — ต้องตั้งตรงเสมอ
  ❌ ห้ามวาง outdoor unit หงาย (คอมเพรสเซอร์เสียหาย)
  ❌ ห้ามวางในพื้นที่ที่มีน้ำขัง / ชื้นแฉะ

การจัดเก็บ:
  □ ตั้งตรง ลูกศร "This Side Up" ชี้ขึ้น
  □ Indoor + Outdoor วางด้วยกัน ป้ายระบุคู่
  □ แถวละ 1 ชิ้น ไม่ซ้อนกัน (ยกเว้นกล่องแข็งแรงตาม spec)
  □ เว้นระยะห่างจากผนัง ≥ 10 ซม.
```

### ตู้เย็น
```
  □ ตั้งตรงเสมอ — ห้ามวางนอน
  □ ถ้าจำเป็นต้องวางนอน → ให้ตั้งทิ้งไว้ ≥ 4 ชั่วโมงก่อนเสียบไฟ
  □ ห้ามซ้อนทับกัน
  □ หมุนประตูไปด้านที่เข้าถึงได้สะดวก
```

### เครื่องซักผ้า
```
  □ Front Load: ห้ามวางนอน
  □ Top Load: วางตั้งตรง ไม่ต้องระวังพิเศษ
  □ ทั้งคู่: ห้ามกดทับจากด้านบน
```

### ทีวี
```
  □ เก็บในกล่องเสมอ
  □ ห้ามวางนอน (จอแตกง่าย)
  □ ซ้อนได้ตาม spec บนกล่อง (ดูน้ำหนักกด max)
  □ ห้ามกดทับ — เก็บในแนวตั้ง
```

### สินค้าขนาดเล็ก (หม้อ / เตา / เครื่องสำอางผม)
```
  □ วางบน Rack — ไม่วางบนพื้น
  □ แบ่งชั้นตามหมวด: หม้อ/เตาร่วมกัน, ของใช้ส่วนตัวแยก
  □ ไม่กองสูงเกิน 1.5 เมตร (ความปลอดภัยและมองเห็นได้)
```

### อะไหล่
```
  □ แยก Rack เฉพาะ — ห้ามปนกับสินค้าทั่วไป
  □ ป้ายรหัส Part Number ทุกรายการ
  □ อะไหล่เสีย แยกออกจากอะไหล่ดี (ป้ายสีแดง)
```

## การดู Serial Number (S/N) และ Model Number

### ตำแหน่ง S/N แต่ละสินค้า

```
แอร์ Indoor:  ข้างซ้ายของตัวเครื่อง (ด้านล่าง)
แอร์ Outdoor: ด้านข้างตัวเครื่อง หรือด้านหลัง
ตู้เย็น:      ด้านในตัวเครื่อง (เปิดประตูดู) หรือด้านข้างกล่อง
เครื่องซักผ้า:ด้านหลัง หรือด้านในฝากระบะ
ทีวี:         ด้านหลัง ใต้ขาตั้ง หรือข้างกล่อง
เครื่องเล็ก:  ด้านล่างตัวเครื่อง หรือบนกล่อง

⚠️ S/N บนกล่อง vs S/N บนตัวสินค้า ต้องตรงกันเสมอ
   ถ้าไม่ตรง → แจ้งหัวหน้าทันที อย่าบันทึกในระบบ
```

### การอ่าน Model Number

```
ตัวอย่างการอ่าน (แต่ละแบรนด์ต่างกัน):

LG: F2514NTSR
  F = Front Load / 2514 = ขนาด 15 กก. / NTS = คุณสมบัติ

Samsung: WW80J5410GW
  WW = Washing Machine / 80 = 8 กก. / J5 = series
```

## การเรียงสินค้าเพื่อนับ (Pre-Count Arrangement)

```
ก่อนนับสต็อก → จัดสินค้าให้พร้อม:

1. รวมสินค้ารุ่นเดียวกันไว้ที่เดียว
   → อย่าให้สินค้ารุ่นเดียวกันกระจายหลายจุด

2. หันกล่องด้านที่มี S/N ออกด้านนอก
   → ช่วยให้นับและสแกนได้เร็ว

3. แยกสินค้าปกติออกจากสินค้าพักรอ/ค้างตรวจ
   → อย่าให้ปน

4. นับสินค้าในกล่องและออกกล่องแยกกัน
   → บันทึกแยกรายการ

5. Display / โชว์รูม นับแยก ไม่รวมกับสต็อก
```
