# ความรับผิดชอบสินค้าและการดูแลแต่ละหมวด

---

## หลักการ: "ของที่อยู่ในความดูแลของคุณ คือความรับผิดชอบของคุณ"

```
ทุกคนในคลังต้องรู้ว่า:
  → ตัวเองดูแลโซนหรือหมวดไหน
  → ถ้าสินค้าในโซนนั้นหาย/เสียหาย → ต้องอธิบายได้
  → ไม่รู้ว่าเกิดอะไรขึ้น = ไม่ได้ดูแลพอ
```

---

## การแบ่งความรับผิดชอบ

### คลังใหญ่ (HQ)

```
หัวหน้าคลัง:
  → รับผิดชอบสต็อกทั้งหมดของ SWT
  → อนุมัติการโอนสินค้าออกทุกรายการ
  → รายงาน Variance ให้บัญชีและผู้บริหาร
  → ดูแลระบบและกระบวนการคลัง

พนักงานคลัง [TBD จำนวน]:
  → รับผิดชอบโซนที่ได้รับมอบหมาย
  → บันทึกการเข้า-ออกของสินค้าในโซนตัวเอง
  → รายงานความผิดปกติทันที
```

### คลังย่อย (สาขา SWE)

```
หัวหน้าสาขา / ผู้รับผิดชอบคลังสาขา:
  → รับผิดชอบสต็อก Consignment จาก SWT ทั้งหมด
  → ถ้าสินค้าหาย = SWE ต้องจ่ายคืน SWT ตามราคาทุน
  → ตรวจนับสต็อกประจำวันก่อนเปิดสาขา

⚠️ กฎ Consignment ที่ต้องจำ:
  SWE ไม่ได้เป็นเจ้าของสินค้า (ทางบัญชี) แต่รับผิดชอบสินค้าจริง
  ถ้าสินค้าหาย → SWE จ่าย SWT ราคา [TBD: ราคาทุน หรือราคาขาย?]
```

## การดูแลสินค้าแต่ละหมวด

### แอร์ (สินค้ามูลค่าสูงสุด)
```
ความเสี่ยงหลัก: ราคาสูง / S/N สลับ / Outdoor หาย

การดูแล:
  □ นับรายสัปดาห์ (ไม่รอรายเดือน)
  □ ตรวจ S/N คู่ Indoor-Outdoor ทุกครั้งที่เคลื่อนย้าย
  □ ถ่ายรูป Indoor + Outdoor + S/N พร้อมกัน ไว้เป็นหลักฐาน
  □ ห้ามออกจากคลังถ้า S/N ไม่ครบคู่
  □ Display Mockup: บันทึกแยก ตรวจทุกสัปดาห์
```

### ตู้เย็น / เครื่องซักผ้า
```
ความเสี่ยงหลัก: เสียหายระหว่างเคลื่อนย้าย / สต็อกค้าง High Season

การดูแล:
  □ ตรวจสภาพกล่องทุกเดือน (กล่องชื้น / บุบ → แจ้งทันที)
  □ FIFO เข้มงวด — ดูวันที่รับบนกล่อง
  □ ระหว่าง High Season (มี.ค.–พ.ค.) ตรวจถี่ขึ้น
```

### ทีวี
```
ความเสี่ยงหลัก: จอแตกจากการจัดเก็บผิด / กล่องบุบ

การดูแล:
  □ ตรวจว่ากล่องตั้งตรง ไม่มีน้ำหนักกดทับ
  □ ไม่วางใกล้ขอบชั้นหรือพื้นที่เสี่ยงล้ม
  □ Display ทีวีต้องติดป้าย serial ที่เห็นชัด
```

### สินค้าขนาดเล็ก (Long Tail SKU)
```
ความเสี่ยงหลัก: สูญหายง่าย / นับยาก / ปะปนกัน

การดูแล:
  □ เก็บบน Rack ไม่วางบนพื้น
  □ แต่ละ SKU มีป้ายรหัสชัดเจน
  □ นับรายสัปดาห์ (เพราะหยิบบ่อย)
  □ สินค้าที่ขายดี (Fast Moving) ดูเผื่อสต็อกก่อน
```

### Display / โชว์รูม
```
ความเสี่ยงหลัก: ถูกหยิบออกโดยไม่บันทึก / สภาพเสื่อมโดยไม่รู้

การดูแล:
  □ ติดป้าย "Display" ชัดเจนทุกชิ้น ตลอดเวลา
  □ บันทึก S/N + วันที่เริ่มโชว์ + สภาพ A/B/C
  □ ตรวจนับรายสัปดาห์ (พร้อมถ่ายรูป)
  □ ถ้าจะขาย Display → ต้องแจ้งหัวหน้า + อัปเดตราคาป้าย
  □ ห้ามพนักงานนำ Display ออกโดยไม่มีเอกสาร
```

## กรณีสินค้าหายหรือเสียหาย — ขั้นตอน

```
พบว่าสินค้าหาย:
  1. ตรวจสอบก่อนว่าอยู่ผิดโซนหรือไม่
  2. ตรวจ S/N ว่า scan หรือบันทึกผิดหรือไม่
  3. ตรวจประวัติการเบิก-จ่ายในระบบ
  4. ถ้ายืนยันว่าหายจริง → แจ้งหัวหน้าคลังทันที
  5. หัวหน้าคลังแจ้งบัญชีและผู้บริหาร
  6. กรอกแบบฟอร์มรายงานสินค้าสูญหาย [TBD]
  7. ดำเนินการตามนโยบายบริษัท [TBD]

⚠️ ห้ามปิดบัง — การซ่อนข้อมูลสินค้าหายเป็นความผิดร้ายแรง
   ยิ่งรายงานเร็ว ยิ่งแก้ไขได้มากกว่า
```
