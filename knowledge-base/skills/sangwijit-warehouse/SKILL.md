# Sangwijit Warehouse Skill — คลังสินค้า

## โครงสร้างคลัง

```
คลังใหญ่ (HQ/สำนักงานใหญ่ สกลนคร)
  → สต็อกหลัก รุ่นขายดี รุ่นถูก
  → จ่ายสินค้าให้สาขาและลูกค้าค้าส่ง

คลังย่อย (6 สาขา SWE)
  → สต็อกหน้าร้าน + สินค้า Display
  → รับจากคลังใหญ่ผ่าน Consignment
  → ถ้าสต็อกหาย SWE รับผิดชอบจ่ายคืน SWT
```
