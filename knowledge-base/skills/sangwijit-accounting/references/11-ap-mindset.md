# เจ้าหนี้ — Mindset ผู้ตรวจสอบ ไม่ใช่แค่ผู้จ่ายเงิน

> หลักคิด: AP ไม่ใช่แค่ "กดจ่าย"
> ทุกการจ่ายเงินต้องผ่านการตรวจสอบ 3 ชั้น
> และต้องรู้ว่า Vendor ค้างอะไรกับเราก่อนจ่ายทุกครั้ง

---

## บทบาทของเจ้าหนี้ในแสงวิจิตร

```
ชั้นที่ 1 — ตรวจสอบเอกสาร (Document Verification)
  ตรวจก่อนว่าเอกสารถูกต้องครบถ้วน

ชั้นที่ 2 — กระทบยอด (Reconciliation)
  Invoice ตรงกับสินค้าที่รับจริงหรือไม่?
  มีสินค้าฝาก (Consignment) ที่ยังไม่ถึงมือเราหรือไม่?

ชั้นที่ 3 — ตรวจรายการค้าง (Vendor Obligation Check)
  ก่อนจ่าย → ถามจัดซื้อว่า Vendor ค้างอะไรกับเราไหม?
  มีรายการที่หักได้ไหม?
```

---

## ชั้นที่ 1: ตรวจสอบเอกสาร

### เอกสารที่ต้องครบก่อน AP จ่ายเงิน

```
ชุดเอกสารมาตรฐาน (3-Way Match):
  □ ใบสั่งซื้อ PO (Purchase Order) จากแสงวิจิตร
  □ ใบรับสินค้า GRN (Goods Received Note) จากคลัง
  □ ใบกำกับภาษี Tax Invoice จาก Vendor

เงื่อนไข 3-Way Match:
  PO qty = GRN qty = Invoice qty → จ่ายได้
  มีส่วนไหนไม่ตรง → หยุด → สอบถามก่อน

การตรวจ Tax Invoice:
  □ ชื่อ/ที่อยู่/เลขผู้เสียภาษีของแสงวิจิตรถูกต้อง?
  □ ชื่อสินค้า จำนวน ราคาต่อหน่วยตรงกับ PO?
  □ วันที่ Invoice ไม่เกินวันที่ส่งสินค้า?
  □ เลข Invoice ไม่ซ้ำกับที่เคยจ่ายไปแล้ว?
  □ VAT คำนวณถูกต้อง? (ดูกฎ VAT Golden Rule ใน 04-tax.md)
```

### กรณีที่ต้องหยุดและสอบถาม

```
🛑 หยุดจ่ายทันที เมื่อ:
  □ Invoice ราคาสูงกว่า PO โดยไม่มีการ approve
  □ สินค้าในระบบยังไม่ถึง (GRN ยังไม่ออก)
  □ Invoice ซ้ำกับที่จ่ายไปแล้ว
  □ Vendor อยู่ใน Blacklist หรือมีข้อพิพาทค้างอยู่
  □ มี Credit Note ค้างที่ต้องหักก่อน (รับข้อมูลจากจัดซื้อ)
```

## ชั้นที่ 2: กระทบยอด Invoice vs สินค้าจริง

### Scenario ที่พบใน แสงวิจิตร

**Case A: สินค้าปกติ (SWT ซื้อจาก Vendor)**
```
  PO → สั่งซื้อ 100 ชิ้น
  GRN → รับจริง 98 ชิ้น (2 ชิ้นเสียหายระหว่างขนส่ง)
  Invoice → Vendor เรียกเก็บ 100 ชิ้น

  AP ต้องทำ:
    → จ่ายเฉพาะ 98 ชิ้น
    → แจ้ง Vendor ออก Credit Note 2 ชิ้น
    → บันทึก Credit Note รอรับ ใน Vendor Register
```

**Case B: สินค้าฝาก Consignment (SWE)**
```
  Vendor ส่งสินค้า 50 ชิ้น ให้ SWE ฝากขาย
  SWE ขายได้ 30 ชิ้น
  Vendor วางบิล Invoice 50 ชิ้น

  AP ต้องทำ:
    → ตรวจสอบ Consignment Report จากจัดซื้อ
    → จ่ายเฉพาะ 30 ชิ้นที่ขายไปแล้ว
    → อีก 20 ชิ้นยังฝากอยู่ → ยังไม่จ่าย
    → ถ้าสินค้าหาย → SWE รับผิดชอบจ่ายคืน SWT/Vendor
```

**Case C: Invoice วางบิลก่อนสินค้ามาถึง**
```
  Vendor ส่ง Invoice วันที่ 1
  สินค้ามาถึงจริงวันที่ 5

  AP ต้องทำ:
    → ไม่บันทึก Invoice ก่อนสินค้ามาถึง
    → รอ GRN ก่อน แล้วค่อยบันทึกและ schedule จ่าย
    → บันทึกเป็น Accrued Payable (ถ้าปิดบัญชีก่อนสินค้าถึง)
```

## ชั้นที่ 3: ตรวจรายการค้าง Vendor ก่อนจ่าย

### กระบวนการ Pre-Payment Check

```
ก่อนทุกการจ่ายเงิน → ถามจัดซื้อ:
  "Vendor [ชื่อ] — มีรายการค้างที่หักได้ไหม?"

จัดซื้อจะแจ้ง:
  - Rebate ที่ Due แล้ว: [TBD] บาท
  - Credit Note ที่ค้าง: [TBD] บาท
  - Non-move ที่ตกลงเคลียร์: [TBD] บาท
  รวมหักได้: [TBD] บาท

AP คำนวณ:
  ยอดที่ต้องจ่าย = Invoice รวม − รายการค้างที่หักได้
  ออก Debit Note ให้ Vendor (ถ้าใช้วิธีหักยอด)
  หรือรอ CN จาก Vendor ก่อนจ่าย (ถ้า Vendor ต้องออก CN ก่อน)
```

## เข้าใจโครงสร้างราคาและผลประโยชน์

### สิ่งที่ AP ต้องเข้าใจเกี่ยวกับราคาสินค้า

```
ราคาที่ Vendor เรียกเก็บ ≠ ต้นทุนจริงของแสงวิจิตร

ต้นทุนจริง = ราคา Invoice
             − Front Discount (ถ้ามีในเงื่อนไข)
             − Rebate ที่จะได้รับ (คำนวณ accrual)
             − Marketing Support (ถ้า offset กับสินค้า)

ทำไม AP ต้องรู้เรื่องนี้:
  → เพื่อ reconcile ว่าสิ่งที่จ่ายไปสมเหตุสมผลกับสัญญา
  → เพื่อตรวจสอบว่า Rebate ที่ได้รับมาถูกต้องหรือไม่
  → เพื่อ flag ถ้า Vendor เรียกเก็บเกินกว่าที่ตกลง

หลัก VAT Golden Rule (ห้ามลืม):
  ส่วนลดและ Rebate คำนวณจาก Base Price เสมอ
  ไม่ใช่จากราคารวม VAT
  (ดูรายละเอียดใน 04-tax.md และ sangwijit-purchasing skill)
```

## AP Workflow สมบูรณ์ (Flow รวม 3 ชั้น)

```
รับ Invoice จาก Vendor
        ↓
[ชั้น 1] ตรวจเอกสาร
  PO + GRN + Invoice ตรงกัน?
  Tax Invoice ถูกต้องครบ?
        ↓ ผ่าน
[ชั้น 2] กระทบยอด
  สินค้าฝากตรงกับที่ขายจริงหรือไม่?
  สินค้าครบตาม PO หรือไม่?
        ↓ ผ่าน
[ชั้น 3] ตรวจรายการค้าง
  ถามจัดซื้อ: มียอดค้างหักได้ไหม?
        ↓
คำนวณยอดจ่ายสุทธิ
        ↓
ขออนุมัติจ่าย [TBD: ใคร อนุมัติวงเงินเท่าไหร่]
        ↓
โอนเงิน / ออกเช็ค
        ↓
บันทึกบัญชีและอัปเดต Vendor Register
```

## ตัวอย่างบทสนทนาระหว่าง AP และจัดซื้อ

```
AP: "รอบจ่ายสัปดาห์นี้มี Invoice ของ [Vendor A] 3 ใบ
     รวม 450,000 บาท จะจ่ายเต็มยอดได้เลยไหม?"

จัดซื้อ: "รอก่อนนะ [Vendor A] ค้าง Rebate Q2 อยู่ 25,000 บาท
          ครบกำหนดจ่ายเดือนนี้แล้ว และยังมี CN สินค้าชำรุด
          อีก 8,000 บาทที่ยังไม่ได้รับ รวมหักได้ 33,000 บาท"

AP: "โอเค งั้นจ่าย 417,000 บาท และออก Debit Note
     หรือรอ CN จาก [Vendor A] ก่อนดี?"

จัดซื้อ: "[Vendor A] ตกลงจะออก CN ภายใน 7 วัน
          รอ CN ก่อนแล้วค่อยจ่ายเต็มยอดดีกว่า"
```
