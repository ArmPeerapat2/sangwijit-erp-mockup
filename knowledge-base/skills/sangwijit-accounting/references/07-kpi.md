# KPI ทีมบัญชี — ตัวชี้วัดผลงานรายตำแหน่ง

---

## หลักการออกแบบ KPI บัญชี

```
KPI บัญชีต้องวัด 3 มิติ:
  1. Accuracy (ความถูกต้อง) — ไม่มีข้อผิดพลาด
  2. Timeliness (ความทันเวลา) — ส่งตรง Deadline
  3. Completeness (ความครบถ้วน) — ไม่มีรายการตกหล่น
```

## KPI ภาพรวมแผนกบัญชี (Department KPI)

```
วัดทั้งแผนกโดยผู้จัดการบัญชี:

Accuracy Rate:
  = จำนวนรายการที่ถูกต้อง / จำนวนรายการทั้งหมด × 100
  เป้า: ≥ 99.5%

On-time Submission Rate:
  = จำนวนรายงาน/เอกสารที่ส่งตรงเวลา / ทั้งหมด × 100
  เป้า: 100%

Audit Finding:
  จำนวน Material Finding จาก Internal/External Audit
  เป้า: 0 (Critical) / ≤ [TBD] (Minor)

Staff Development:
  ชั่วโมงฝึกอบรมเฉลี่ยต่อคน
  เป้า: ≥ [TBD] ชั่วโมง/ปี
```
