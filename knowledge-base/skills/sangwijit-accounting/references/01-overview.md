# 01: ภาพรวม — โครงสร้างบัญชี 4 นิติบุคคล และ Flow เงิน

---

## 1.1 ทำไมต้องมี 4 นิติบุคคล?

กลุ่มแสงวิจิตรแบ่งเป็น 4 บริษัทที่มีรูปแบบธุรกิจและภาษีต่างกัน
**การบัญชีต้องแยกชัดเจนทุกรายการ — ห้ามปนกัน**

| รหัส | บริษัท | รูปแบบรายได้ | VAT | หมายเหตุ |
|------|--------|-------------|-----|---------|
| **SWT** | แสงวิจิตรเทรดดิ้ง | ขายส่ง + Rebate | 7% | Holding + Master Franchise |
| **SWE** | แสงวิจิตรการไฟฟ้า | Commission 10–15% จาก SWT | 7% | รับสินค้า Consignment จาก SWT |
| **VMN** | หจก.วีมันนี่ | ดอกเบี้ยสินเชื่อ | อาจได้รับยกเว้น | **Read Only — ไม่ดำเนินการในระบบนี้** |
| **WPS** | หจก.WePowerSupply | ส่งออก Laos + VAT Refund | VAT 0% | รายได้หลัก = VAT 0% Refund |

---

## 1.2 ความสัมพันธ์ทางการเงินระหว่าง SWT ↔ SWE

```
SWT ส่งสินค้า → SWE (Consignment — ไม่ใช่ขาย)
SWE ขายสินค้าให้ลูกค้า → เก็บเงินในนาม SWE
SWE ส่ง Commission 10–15% คืน SWT เป็นรายได้ SWT

ผลต่อบัญชี:
  SWT: รับรู้รายได้เมื่อ SWE ส่ง Commission (ไม่ใช่เมื่อ SWE ขาย)
  SWE: รับรู้รายได้จาก Commission ที่ได้รับ
  สต็อก: ในบัญชี SWT เป็นเจ้าของ แต่ SWE รับผิดชอบทางกายภาพ
```

> ⚠️ สต็อกหาย = SWE ชำระ SWT — ต้องบันทึกแยกจากการขายปกติ

---

## 1.3 WPS — รายได้จาก VAT 0% Refund

```
WPS ส่งสินค้าออก Laos → ออกใบกำกับภาษี VAT 0%
→ WPS ยื่นขอคืนภาษีซื้อ (Input VAT) ที่จ่ายตอนซื้อสินค้า
→ รายได้จริงของ WPS = VAT ที่ได้คืน ไม่ใช่กำไรจากสินค้า (margin ~1%)

ผลต่อบัญชี:
  ต้องแยกรายการ VAT 0% ออกจากธุรกรรมปกติชัดเจน
  ใบกำกับภาษีต้องระบุ VAT 0% และมีเอกสารส่งออกครบ
  การยื่นขอคืน VAT ต้องทำตามกำหนดเวลา
```

## 1.4 โครงสร้างทีมบัญชี

```
ผู้จัดการบัญชี (Accounting Manager)
  ├── AP Officer — เจ้าหนี้ + ชำระเงิน
  ├── AR Officer — ลูกหนี้ + รับชำระ
  ├── GL Officer — บัญชีแยกประเภท + ปิดบัญชี
  ├── Tax Officer — VAT + ภาษีหัก ณ ที่จ่าย + ภงด.
  └── Finance Officer — การเงิน + ธนาคาร + Cash Flow
```

> บางตำแหน่งอาจทำหลายหน้าที่ — ดูการมอบหมายงานจริงจากผู้จัดการ

## 1.5 Flow เงินของกลุ่มแสงวิจิตร (ภาพรวม)

```
รายรับ:
  SWT ← Commission จาก SWE
  SWT ← ชำระค่าสินค้าจากลูกค้าค้าส่ง (11 จังหวัด)
  SWT ← Rebate จาก Brand/Supplier
  SWE ← Commission 10–15% (รับรู้รายได้)
  WPS ← ชำระค่าสินค้าจาก Laos + VAT Refund

รายจ่าย:
  SWT → ชำระค่าสินค้าให้ Brand/Supplier (AP)
  SWT/SWE → เงินเดือนพนักงาน
  SWT/SWE → ค่าใช้จ่ายดำเนินงาน (ค่าเช่า / ไฟ / น้ำ)
  SWT → ค่าขนส่ง / โลจิสติกส์

การโอนเงินระหว่างนิติบุคคล:
  → ต้องมีเอกสารประกอบทุกครั้ง
  → บันทึกเป็น Intercompany Transaction
  → ต้องตัดรายการระหว่างกันเมื่อทำ Consolidation
```

## 1.6 ปฏิทินงานบัญชี (Monthly Calendar)

| ช่วงเวลา | งานที่ต้องทำ | ผู้รับผิดชอบ |
|---------|------------|------------|
| วันที่ 1–5 | รวบรวมเอกสารรายการเดือนก่อน | ทุกตำแหน่ง |
| วันที่ 1–7 | ยื่น VAT (ภพ.30) + ภาษีหัก ณ ที่จ่าย | Tax |
| วันที่ 7–10 | กระทบยอดธนาคาร (Bank Reconciliation) | Finance |
| วันที่ 7–15 | ปิดบัญชีเดือนก่อน | GL |
| วันที่ 10–15 | ส่งรายงานผู้บริหาร | ผจก.บัญชี |
| ตลอดเดือน | AP: ตรวจสอบ Invoice / จ่ายเงิน | AP |
| ตลอดเดือน | AR: ติดตามหนี้ / รับชำระ | AR |
| สิ้นเดือน | Cutoff date เอกสาร | ทุกตำแหน่ง |

> **Cutoff date:** เอกสารที่เกิดขึ้นในเดือนนี้ ต้องบันทึกในเดือนนี้เท่านั้น
> ห้ามบันทึกข้ามเดือนโดยไม่ได้รับอนุมัติ

## 1.7 หลักการพื้นฐานที่ทีมบัญชีต้องรู้

```
1. แยกนิติบุคคลทุกรายการ — ห้ามปนกัน
2. เอกสารต้องครบก่อนบันทึก — ไม่บันทึกโดยไม่มีหลักฐาน
3. Double-Entry เสมอ — ทุกรายการมี Dr. และ Cr.
4. Cutoff ต้องเคร่งครัด — รายการเดือนไหน บันทึกเดือนนั้น
5. Bank Rec ทุกบัญชีทุกเดือน — ก่อนปิดบัญชี
6. VAT Golden Rule — คิดจาก Base Price ก่อน VAT เสมอ
   (อย่าคิดส่วนลดจากราคาที่รวม VAT แล้ว)
7. ข้อสงสัยใดๆ → ถามผู้จัดการก่อนบันทึก
```
