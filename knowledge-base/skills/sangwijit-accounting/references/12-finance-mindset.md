# การเงิน — Mindset ผู้ควบคุมกระแสเงิน

> หลักคิด: การเงินคือ "ประตูสุดท้าย"
> ทุกบาทที่เข้าและออกต้องมีเหตุผล มีเอกสาร และตรวจสอบได้
> ไม่มีเงินโยกโดยพลการ — ทุกการเคลื่อนไหวต้องบันทึก

---

## บทบาทของการเงินในแสงวิจิตร

```
ด้านรับ (Inflow Control):
  ตรวจสอบว่าเงินที่เข้ามาตรงกับสิ่งที่ควรได้รับ
  ไม่มีเงินเข้าโดยไม่รู้ที่มา

ด้านจ่าย (Outflow Control):
  ทุกการจ่ายต้องมี AP อนุมัติก่อน
  ตรวจสอบว่าจ่ายถูกบัญชี ถูกจำนวน ถูกนิติบุคคล

ด้านบริหาร (Cash Management):
  รู้ยอดเงินในทุกบัญชีตลอดเวลา
  โยกเงินระหว่างบัญชีเมื่อจำเป็น — แต่ต้องมีเหตุผลและเอกสาร
  แจ้งผู้บริหารล่วงหน้าถ้า Cash ต่ำกว่า threshold
```

## การกระทบยอดเงินเข้า (Inflow Reconciliation)

### แหล่งเงินเข้าของแสงวิจิตร

```
SWT (ค้าส่ง):
  □ รับชำระจากลูกค้าค้าส่ง (โอน/เช็ค)
  □ Rebate รับจาก Vendor/แบรนด์
  □ VAT Refund (ถ้ามีกิจกรรมส่งออก)

SWE (ค้าปลีก):
  □ รับเงินสดจากสาขา (Daily Cash Report)
  □ รับผ่านบัตรเครดิต (Card Settlement)
  □ รับโอนจากลูกค้า
  □ รับจาก VMN (เช่าซื้อที่อนุมัติแล้ว)

WPS (ส่งออก):
  □ รับชำระจากลูกค้าลาว (THB/LAK)
  □ VAT Refund จากสรรพากร (สำคัญมาก — ดู 04-tax.md)
```

### กระบวนการตรวจสอบเงินเข้า

```
ทุกวัน:
  1. เปิด Internet Banking / Mobile Banking ทุกบัญชี
  2. บันทึกรายการเข้าทุกรายการ:
     □ ระบุที่มา (ลูกค้า/Vendor Rebate/VAT Refund/อื่นๆ)
     □ ระบุ Entity (SWT/SWE/WPS)
     □ ระบุ Invoice ที่ match
  3. รายการที่ระบุที่มาไม่ได้ → Hold ไว้ก่อน → สอบถามทันที
  4. Update Cash Position Report

สิ่งที่ต้อง Flag ทันที:
  🚨 เงินเข้าผิดบัญชี (เช่น ลูกค้า SWT โอนมาบัญชี SWE)
  🚨 เงินเข้าผิดจำนวน (มากหรือน้อยกว่า Invoice)
  🚨 เงินเข้าโดยไม่มี Reference ใดๆ
```

## การตรวจสอบความเคลื่อนไหว (Movement Monitoring)

### Pattern ที่ปกติ vs ผิดปกติ

```
ปกติ:
  ✅ เงินเข้าตรงกับ Invoice ที่ AR ติดตาม
  ✅ เงินออกตรงกับ Payment Schedule จาก AP
  ✅ โยกเงินระหว่างบัญชีของ Entity เดียวกัน (มีเหตุผล)

ผิดปกติ (ต้องสอบถาม/รายงาน):
  ⚠️ เงินออกไม่ตรงกับ Payment Schedule
  ⚠️ โยกเงินระหว่าง Entity โดยไม่มีเอกสาร Intercompany
  ⚠️ เงินออกไปบัญชีที่ไม่ใช่ Vendor ที่ลงทะเบียนไว้
  ⚠️ รายการ Debit/Credit ที่ยอดกลม (เช่น 100,000 พอดี) 
     โดยไม่มีเอกสาร → ต้องตรวจสอบ
  🚨 เงินออกโดยไม่มีอนุมัติจาก AP
```

## การโยกเงินระหว่างบัญชี (Intercompany Transfer)

### กฎเหล็ก

```
ห้ามโยกเงินระหว่างนิติบุคคลโดย:
  □ ไม่มีเหตุผลทางธุรกิจที่ชัดเจน
  □ ไม่มีเอกสาร Intercompany รองรับ
  □ ไม่ได้รับอนุมัติจากผู้มีอำนาจ [TBD]

กรณีที่โยกได้:
  SWT → SWE: ค่า Commission / ชำระสินค้า Consignment
  SWT → WPS: ทุน/สินค้าส่งออก
  ต้องมี: Intercompany Invoice + อนุมัติ + บันทึกบัญชีทั้งสองฝ่าย
```

### ขั้นตอนโยกเงินที่ถูกต้อง

```
1. ได้รับคำขอจาก GL หรือผู้บริหาร + เอกสาร Intercompany
2. ตรวจสอบว่ายอดถูกต้องและมีอนุมัติ
3. โอนเงิน
4. บันทึกในระบบ:
   ฝ่ายโอน (เช่น SWT):
     Dr. ลูกหนี้ระหว่างกัน (SWE)    xxx
         Cr. เงินฝากธนาคาร                xxx
   ฝ่ายรับ (เช่น SWE):
     Dr. เงินฝากธนาคาร              xxx
         Cr. เจ้าหนี้ระหว่างกัน (SWT)     xxx
5. ส่ง Confirmation ให้ GL reconcile
```

## Cash Position Report (รายงานรายวัน)

```
รายงานที่การเงินต้องส่งผู้บริหารทุกเช้า:

วันที่: _______  เวลา: _______

CASH POSITION:
  SWT - [ธนาคาร A]:     ___,___ บาท
  SWT - [ธนาคาร B]:     ___,___ บาท
  SWE - [ธนาคาร C]:     ___,___ บาท
  WPS - [ธนาคาร D]:     ___,___ บาท
  รวม Cash & Bank:       ___,___ บาท

รับวันนี้ (คาดการณ์):   + ___,___ บาท
จ่ายวันนี้ (คาดการณ์):  - ___,___ บาท
Net:                     ___,___ บาท

รายการน่าสนใจ:
  [ระบุถ้ามีรายการผิดปกติ หรือ Cash ใกล้ต่ำกว่า threshold]

⚠️ Alert ถ้า Cash รวมต่ำกว่า [TBD] บาท → แจ้งผู้บริหารทันที
```

## Checklist การเงินรายวัน / รายสัปดาห์

```
ทุกวัน:
  □ เปิดดูยอดธนาคารทุกบัญชี
  □ Match เงินเข้ากับ Invoice / AR
  □ ตรวจรายการผิดปกติ
  □ ส่ง Cash Position Report ให้ผู้บริหาร

ทุกสัปดาห์:
  □ อัปเดต Cash Flow Forecast 4 สัปดาห์ข้างหน้า
  □ ตรวจสอบ Outstanding Check ที่ยังไม่ขึ้นเงิน
  □ Reconcile Intercompany Balance

ทุกเดือน:
  □ Bank Reconciliation เสร็จภายใน 5 วันทำการ
  □ Petty Cash Reconcile ทุกจุด
  □ รายงาน Cash Movement Summary ให้ GL ใช้ปิดบัญชี
```
