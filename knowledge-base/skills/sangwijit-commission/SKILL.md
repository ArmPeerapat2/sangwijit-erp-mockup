# Sangwijit Commission System Skill

## หลักการสำคัญ: Commission คือเครื่องมือ Shape พฤติกรรม

> Commission ของแสงวิจิตรไม่ได้จ่ายแค่ "ตามยอดขาย"
> แต่ออกแบบให้พนักงาน **ทำสิ่งที่ถูกต้องโดยอัตโนมัติ** เพราะมันคุ้มค่าทางการเงินสำหรับเขา

---

## โครงสร้าง 4 ชั้น (The Commission Stack)

```
┌─────────────────────────────────────────────────────┐
│  ชั้น 1: เป้าทีม / สาขา / แผนก                    │  ← Gate: ถึงเป้าถึงได้รับ pool
├─────────────────────────────────────────────────────┤
│  ชั้น 2: เป้าหมวดสินค้า / แบรนด์                  │  ← Multiplier: ครบทุกหมวด = สูงขึ้น
├─────────────────────────────────────────────────────┤
│  ชั้น 3: เป้ารายตัวเร่งผลักดัน                    │  ← Bonus: สินค้าพิเศษ = ได้เพิ่ม
├─────────────────────────────────────────────────────┤
│  ชั้น 4: ทักษะการขาย                               │  ← Skill Premium: ทำได้ = ได้พิเศษ
└─────────────────────────────────────────────────────┘
```

อ่านรายละเอียดแต่ละชั้น: `references/01-commission-layers.md`

## หลักการต่างกันตามช่องทาง

| ช่องทาง | Priority หลัก | Commission Base | อ่านเพิ่มเติม |
|--------|-------------|----------------|-------------|
| ค้าปลีก (SWE-RET) | Up-size / ผ่อน / แลกซื้อ | % pool สาขา + บาท/เคส | `references/02-retail-commission.md` |
| ค้าส่ง (SWT-WHS) | ครบแบรนด์ / ครบโซน / ภาพรวมตัวเอง | % ยอดขาย + tier แบรนด์ | `references/03-wholesale-commission.md` |
| ส่งออก (WPS-EXP) | กำไรต่อชิ้น (ไม่ผูกกลุ่มสินค้า) | % กำไร หรือบาท/ชิ้น | `references/04-export-commission.md` |

## คำเตือนในการออกแบบ Commission (Design Principles)

1. **ชั้น 1 ต้องมีเสมอ** — ถ้าไม่มี gate ทีม พนักงานจะโฟกัสแค่ตัวเอง ไม่ช่วยกัน
2. **ชั้น 2 ต้องครอบคลุมทุกแบรนด์** — ไม่งั้นพนักงานจะขายแค่แบรนด์ที่ง่าย
3. **ชั้น 3 ต้องอัปเดตได้** — สินค้าเร่งผลักดันเปลี่ยนทุกเดือน/ไตรมาส
4. **ชั้น 4 ต้องวัดได้จริง** — ถ้าวัดไม่ได้ พนักงานจะไม่เชื่อว่าได้จริง
5. **Commission รวมกันแล้วต้องสมเหตุสมผล** — ไม่มากเกินจนไม่ยั่งยืน ไม่น้อยเกินจนไม่จูงใจ
