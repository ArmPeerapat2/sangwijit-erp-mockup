# Commission ค้าส่ง (SWT-WHS) — หลักการและโครงสร้าง

---

## Priority การขายค้าส่ง

พนักงานค้าส่งที่ดีต้อง:

```
1. ครบทุกแบรนด์   → ไม่ทิ้งแบรนด์ที่ขายยาก
2. ครบทุกโซน      → ไม่โฟกัสแค่จังหวัดใกล้ๆ ที่สะดวก
3. โฟกัสยอดตัวเอง → รู้เป้าตัวเองชัดเจน ไม่รอทีม
```

## โครงสร้าง Commission ค้าส่ง (4 ชั้น)

### ชั้น 1: เป้าแผนก (Department Gate)

```
เป้ารวมแผนกค้าส่ง = [TBD] บาท/เดือน

เงื่อนไข:
  ถึง 100% → pool เต็ม
  90–99%   → [TBD %] pool
  80–89%   → [TBD %] pool
  < 80%    → [TBD] (fixed หรือ 0 ขึ้นกับนโยบาย)
```

### ชั้น 2: เป้าแต่ละแบรนด์ (Brand Coverage Tier)

```
แบรนด์ที่มีเป้า: [TBD — รายชื่อแบรนด์ที่ต้องครอบคลุม]

วิธีคิด:
  แต่ละพนักงานมีเป้าแบรนด์ของตัวเอง (ตาม territory)
  ถึงเป้าแบรนด์ครบทุกตัว → ได้ Tier สูงสุด

ตัวอย่าง Tier:
  ครบ 100% ทุกแบรนด์          → Commission rate [TBD %]
  ครบ 80–99% ทุกแบรนด์        → Commission rate [TBD %]
  มีแบรนด์ใดไม่ถึง 80%        → rate ลดลงตามจำนวนแบรนด์ที่ขาด
```

### ชั้น 3: Push Item Bonus (รายตัว)

```
เหมือนค้าปลีก — อัปเดตต้นเดือน

ประเภท:
  สินค้าติดสต็อกใน warehouse  → [TBD] บาท/ชิ้น
  สินค้ากำไรสูงกว่าปกติ      → [TBD] บาท/ชิ้น หรือ % กำไร
  สินค้า High Season (แอร์)   → [TBD] บาท/ชิ้น (มี.ค.–พ.ค.)
```

### ชั้น 4: Skill Premium ค้าส่ง

```
Zone Coverage (ครบโซน):
  มีออเดอร์จากทุกโซนในเดือนนั้น
  → [TBD] บาท/เดือน (bonus ก้อน)
  หรือ → multiplier เพิ่ม [TBD %]

Brand Balance (ขายครบทุกแบรนด์แบบ balance):
  ไม่มีแบรนด์ใดต่ำกว่า 70% ของเป้า
  → [TBD] บาท

Personal Target Achievement:
  ยอดขายส่วนตัว ≥ 100% เป้า  → [TBD] บาท + rate สูงสุด
  ยอดขายส่วนตัว ≥ 90% เป้า   → [TBD] บาท
```

## ข้อแตกต่างสำคัญ: ค้าส่ง vs ค้าปลีก

| หัวข้อ | ค้าปลีก | ค้าส่ง |
|--------|--------|-------|
| เน้น | จำนวนเคส / up-size | ครบโซน / ครบแบรนด์ |
| Cycle การขาย | รายวัน | รายสัปดาห์ / รายเดือน |
| ลูกค้า | End user | ร้านค้าตัวแทน |
| Installment bonus | สำคัญมาก | ไม่มี (ค้าส่งไม่มีผ่อน) |
| High Season impact | สูง (แอร์ช่วง มี.ค.–พ.ค.) | สูงมาก (stock ต้องพร้อม) |
