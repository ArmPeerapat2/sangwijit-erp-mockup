# หลักการ 4 ชั้น (Commission Layers) — รายละเอียด

---

## ชั้น 1: เป้าทีม / สาขา / แผนก (Team Gate)

### หน้าที่ของชั้นนี้
เป็น **Gate** — ถ้าทีมไม่ถึงเป้า commission pool ไม่เปิด หรือเปิดบางส่วน

### หลักคิด
- บังคับให้พนักงานช่วยกัน ไม่ใช่แข่งกันเอง
- คนขายดีจะช่วยดึงคนที่อ่อนขึ้นมา เพราะกระทบ commission ตัวเอง
- ผู้จัดการสาขามีแรงจูงใจบริหารทีมให้ถึงเป้า

### รูปแบบที่พบบ่อย

| รูปแบบ | วิธีทำงาน | เหมาะกับ |
|--------|---------|---------|
| Full Gate | ทีมไม่ถึง 100% → commission ส่วนนี้ = 0 | ทีมเล็ก ทุกคนมีผล |
| Sliding Gate | ถึง 70% → ได้ 50% pool / ถึง 90% → ได้ 80% / ถึง 100% → ได้ 100% | ทีมใหญ่ ป้องกันหมดหวัง |
| Bonus Gate | commission ปกติได้อยู่แล้ว แต่ถึงเป้าทีม = ได้ bonus เพิ่ม | จูงใจโดยไม่ตัดรายได้ |

## ชั้น 2: เป้าหมวดสินค้า / แบรนด์ (Category/Brand Tier)

### หน้าที่ของชั้นนี้
เป็น **Multiplier** — ยิ่งครบมากหมวด ยิ่งได้ commission สูงขึ้น

### หลักคิด
- ป้องกันพนักงานโฟกัสแค่สินค้าที่ขายง่าย
- บังคับให้ขายครบ portfolio ที่บริษัทต้องการ
- แบรนด์ที่บริษัทต้องการ push → ตั้งเป้าให้สูง → commission สูงตาม

### รูปแบบ Tier

```
ตัวอย่าง (ปรับตามจริง):
  ถึงเป้าครบ 1 แบรนด์   = Tier 1 → ได้ X%
  ถึงเป้าครบ 2 แบรนด์   = Tier 2 → ได้ Y%  (+Z% จาก Tier 1)
  ถึงเป้าครบทุกแบรนด์   = Tier 3 → ได้ W%  (+bonus พิเศษ)
```

## ชั้น 3: เป้ารายตัวเร่งผลักดัน (Push Item Bonus)

### หน้าที่ของชั้นนี้
เป็น **Spot Bonus** — สินค้าบางรุ่นต้องการ push เป็นพิเศษ → ได้ bonus พิเศษเฉพาะตัวนั้น

### เงื่อนไขที่ทำให้สินค้าอยู่ในชั้นนี้

| เงื่อนไข | ตัวอย่าง | วัตถุประสงค์ |
|---------|--------|------------|
| **ติดสต็อก** | สินค้าค้างคลัง > 30 วัน | ระบาย stock ก่อนเสื่อมมูลค่า |
| **ได้ราคา/เงื่อนไขพิเศษ** | supplier ให้ราคาต้นทุนต่ำกว่าปกติ | ขายได้กำไรสูง แบ่งส่วนหนึ่งให้พนักงาน |
| **กำไรสูงกว่าปกติ** | รุ่น exclusive หรือ bundle พิเศษ | จูงใจขายสิ่งที่บริษัทได้กำไรดี |
| **สินค้าโชว์/มีตำหนิ** | display unit, เกรด B | ต้องการระบาย ต้องบอกลูกค้าตรงไหน |
| **สินค้าเกรด B** | กล่องบุบ สินค้า return | ขายได้ต่ำกว่าราคาปกติ ต้องมี incentive |

### รูปแบบ Bonus

```
ตัวอย่าง:
  รุ่น A (ติดสต็อก)  → ขายได้ 1 ตัว = +[TBD] บาท
  รุ่น B (กำไรสูง)   → ขายได้ 1 ตัว = +[TBD] บาท
  สินค้าโชว์         → ขายได้ 1 ชิ้น = +[TBD] บาท (ต้องแจ้งลูกค้าก่อน)
```

### กฎสำคัญ
- รายการสินค้าชั้น 3 **ต้องอัปเดตได้ทุกเดือน** ตาม stock และ campaign
- พนักงานต้องรู้รายการนี้ทุกต้นเดือน → แจ้งผ่าน Line กลุ่มหรือประชุมสาขา
- สินค้าโชว์/เกรด B → **ต้องแจ้งลูกค้าก่อนขายเสมอ** (ไม่ใช่ซ่อน)

## ชั้น 4: ทักษะการขาย (Sales Skill Premium)

### หน้าที่ของชั้นนี้
เป็น **Skill Premium** — reward พนักงานที่ขายได้ **ดีกว่า** พนักงานปกติ ในเชิงคุณภาพ

### ทักษะที่วัดได้ตามช่องทาง

**ค้าปลีก (SWE-RET):**

| ทักษะ | วิธีวัด | Bonus รูปแบบ |
|-------|--------|------------|
| Up-size (ขายรุ่นสูงกว่าที่ลูกค้าถาม) | จำนวนครั้ง หรือ % ยอด up-size | บาท/ครั้ง หรือ % เพิ่ม |
| เพิ่มเคสผ่อน | จำนวน case installment/เดือน | บาท/เคส |
| ทำแลกซื้อ (trade-in) | จำนวน trade-in ที่ทำได้ | บาท/รายการ |
| ขายหลายยี่ห้อในครั้งเดียว | จำนวนออเดอร์ที่มี ≥ 2 แบรนด์ | bonus ต่อออเดอร์ |

**ค้าส่ง (SWT-WHS):**

| ทักษะ | วิธีวัด | Bonus รูปแบบ |
|-------|--------|------------|
| ครอบคลุมเป้าทุกแบรนด์ | % แบรนด์ที่ถึงเป้าจากทั้งหมด | multiplier เพิ่ม |
| ครอบคลุมทุกโซน | จำนวนจังหวัดที่มีออเดอร์ในเดือน | bonus ต่อโซนที่ครบ |
| ยอดรวมตัวเองถึงเป้า | % achievement ส่วนตัว | tier bonus |

**ส่งออก (WPS-EXP):**

| ทักษะ | วิธีวัด | Bonus รูปแบบ |
|-------|--------|------------|
| กำไรต่อชิ้น/ต่อออเดอร์ | gross margin % หรือบาท/ชิ้น | % ของกำไรส่วนเพิ่ม |
| ขายสินค้ากำไรสูง (ไม่จำกัดกลุ่ม) | mix สินค้า vs margin เฉลี่ย | bonus ถ้า margin > threshold |

## Commission Stack รวม — ตัวอย่างการคำนวณ

```
สมมติ: พนักงานขายค้าปลีก เดือนเมษายน

ชั้น 1: ทีมถึงเป้า 95% → unlock pool 80%
         ได้รับ: [pool สาขา] × 50% × 80% = [X] บาท

ชั้น 2: ถึงเป้าครบ 3/4 แบรนด์ → Tier 2
         ได้รับ: [X] × multiplier 1.2 = [Y] บาท

ชั้น 3: ขายสินค้า push 2 ตัว
         ได้รับ: 2 × [bonus/ตัว] = [Z] บาท

ชั้น 4: เคสผ่อน 7 เคส (≥5 = qualify)
         ได้รับ: 7 × 100 บาท = 700 บาท
         up-size 3 ครั้ง
         ได้รับ: 3 × [bonus/ครั้ง] = [W] บาท

รวม commission เดือนนี้ = Y + Z + 700 + W บาท
```

> เมื่อมีตัวเลขจริง → แทนค่าและคำนวณได้เลย
