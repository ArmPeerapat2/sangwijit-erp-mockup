# คู่มือออกแบบ Commission สำหรับผู้บริหาร

---

## เมื่อต้องการออกแบบหรือปรับ Commission ใหม่

ทำตาม 5 ขั้นตอนนี้เสมอ

---

### ขั้น 1: ระบุพฤติกรรมที่ต้องการ

ก่อนคิดตัวเลข → ตอบให้ได้ว่า:

```
"ฉันอยากให้พนักงาน ___ มากขึ้น"
"ฉันอยากให้พนักงานหยุด ___ "
"สิ่งที่เกิดขึ้นตอนนี้ที่ไม่ดีคือ ___"
```

ตัวอย่าง:
- "อยากให้เสนอผ่อนทุกราย ไม่ใช่แค่ที่ลูกค้าถาม"
- "อยากให้ขายแบรนด์ X มากขึ้น เพราะติดสต็อก"
- "อยากให้ไม่โฟกัสแค่ 3 จังหวัดใกล้ๆ"

---

### ขั้น 2: จับคู่พฤติกรรมกับชั้น Commission

| พฤติกรรมที่ต้องการ | ใส่ใน |
|-----------------|------|
| ช่วยทีม / ไม่ปล่อยให้ใครทิ้ง | ชั้น 1 (Team Gate) |
| ขายครบทุกแบรนด์ / ไม่ทิ้งหมวด | ชั้น 2 (Brand Tier) |
| ระบาย stock / push สินค้าพิเศษ | ชั้น 3 (Push Bonus) |
| up-size / ผ่อน / ขยายโซน | ชั้น 4 (Skill Premium) |

---

### ขั้น 3: ตรวจสอบความสมดุล

```
Commission รวมสูงสุดที่พนักงานรับได้ = [TBD] บาท/เดือน
Commission เฉลี่ยที่คาดว่าจะจ่าย   = [TBD] บาท/เดือน
% ของยอดขายที่ใช้จ่าย commission   = [TBD %]

ตรวจ:
  ✅ ถ้าถึงเป้าทุกชั้น commission สมเหตุสมผลกับงานที่ทำ?
  ✅ ถ้าไม่ถึงเป้าชั้น 1 ยังมีแรงจูงใจทำงานต่อ?
  ✅ Commission ชั้น 4 ทำได้จริงโดยไม่ต้องโกง?
```

---

### ขั้น 4: สื่อสารให้พนักงานเข้าใจ

กฎ: พนักงานต้องคำนวณ commission ตัวเองได้ **ในหัว** โดยไม่ต้องใช้ excel

ถ้าซับซ้อนเกินไป → แยกเป็น 2 รอบ: รอบนี้ทำได้ก่อน แล้วค่อยเพิ่มชั้น

---

### ขั้น 5: ทบทวนและปรับ

```
รายเดือน:  อัปเดตรายการชั้น 3 (push items)
รายไตรมาส: ทบทวนว่า commission shape พฤติกรรมได้จริงไหม
รายปี:     ทบทวนโครงสร้างทั้งหมด
```

---

## Checklist ก่อน Launch Commission ใหม่

- [ ] พฤติกรรมที่ต้องการชัดเจน และจับคู่กับชั้น commission ครบแล้ว
- [ ] ตัวเลขทุกชั้นกำหนดแล้ว ไม่มี TBD ที่ยังเปิดอยู่
- [ ] คำนวณ worst case และ best case ของรายได้พนักงานแล้ว
- [ ] พนักงานคำนวณเองได้โดยไม่ต้องอาศัยผู้จัดการ
- [ ] มีกำหนดวันจ่าย และกระบวนการตรวจสอบยอดชัดเจน
- [ ] มีช่องทางให้พนักงานถามหรือโต้แย้งถ้ายอดไม่ตรง

---

## สัญญาณเตือนว่า Commission ออกแบบไม่ดี

🚨 พนักงานโฟกัสแค่สินค้าที่ได้ commission สูง ทิ้งที่เหลือ
→ แก้: เพิ่ม brand tier ชั้น 2 ให้ครอบคลุมกว่าเดิม

🚨 พนักงานไม่ช่วยกัน แข่งขันกันเองมากกว่าแข่งกับเป้า
→ แก้: เพิ่ม weight ของ team gate ชั้น 1

🚨 พนักงานไม่เสนอผ่อน เพราะรู้สึกว่าไม่คุ้ม
→ แก้: เพิ่ม bonus เคสผ่อนชั้น 4 หรือลด barrier (เกณฑ์ qualify)

🚨 สินค้าติดสต็อกไม่ขายออก ทั้งที่มี push bonus
→ แก้: เพิ่ม bonus ชั้น 3 หรือตรวจสอบว่าพนักงานรู้รายการหรือไม่

🚨 พนักงานทำ commission ได้เยอะโดยไม่ต้องพยายาม
→ แก้: เพิ่ม gate ชั้น 1 หรือทบทวนเป้าให้ท้าทายพอ
