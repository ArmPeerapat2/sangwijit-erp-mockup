# Commission ส่งออก (WPS-EXP) — หลักการและโครงสร้าง

---

## Priority การขายส่งออก

ส่งออกมีหลักคิดแตกต่างจาก 2 ช่องทางอื่น **โดยสิ้นเชิง**

```
ค้าปลีก/ค้าส่ง = สนใจ "ยอดขาย" และ "ครบ portfolio"
ส่งออก        = สนใจ "กำไร" เป็นหลัก
```

เหตุผล:
- WPS margin สินค้า ~1% เท่านั้น
- **รายได้หลักจริงๆ = VAT 0% refund** ไม่ใช่ margin สินค้า
- ดังนั้น commission ต้องจูงใจให้ขาย **สินค้าที่กำไรดี** ไม่ใช่แค่ยอดสูง

---

## โครงสร้าง Commission ส่งออก (4 ชั้น)

### ชั้น 1: เป้าปริมาณขั้นต่ำ (Volume Gate)

```
ไม่ใช่เป้ายอดขาย แต่เป็นเป้า "ปริมาณ minimum" เพื่อ qualify VAT refund

Volume Gate = [TBD] บาท/เดือน (หรือ [TBD] ออเดอร์)

ถึง Gate → qualify รับ commission ชั้น 2–4
ไม่ถึง  → รับแค่ fixed salary (ไม่มี performance commission)
```

### ชั้น 2: Margin Tier (แทน Brand Tier)

```
ส่งออกไม่ผูกกับแบรนด์ — ผูกกับ margin แทน

Tier A: Gross Margin ≥ [TBD %] → Commission rate สูงสุด [TBD %]
Tier B: Gross Margin [TBD–TBD %] → Commission rate กลาง [TBD %]
Tier C: Gross Margin < [TBD %] → Commission rate ต่ำ [TBD %]

วิธีวัด Gross Margin:
  = (ราคาขาย − ต้นทุนสินค้า) / ราคาขาย × 100%
  ไม่รวม VAT refund (นับแยกต่างหาก)
```

### ชั้น 3: High-Margin Product Bonus

```
สินค้าที่กำไรสูงกว่า average ของเดือนนั้น
→ [TBD] บาท/ชิ้น หรือ % ของกำไรส่วนที่สูงกว่า average

ไม่จำกัดกลุ่มสินค้า — ขายอะไรก็ได้ถ้ากำไรดี
รายการ update ต้นเดือนเหมือนกัน
```

### ชั้น 4: Skill Premium ส่งออก

```
Mix Improvement (ขายสินค้า margin สูงมากขึ้น):
  Margin เฉลี่ยของเดือน > [TBD %]
  → bonus [TBD] บาท

New Product Introduction:
  ขายสินค้าหมวดใหม่ที่ยังไม่เคยขาย Laos
  → [TBD] บาท/หมวด (จูงใจ expand portfolio)

Volume + Margin Combo:
  ถึง volume gate + margin tier A ในเดือนเดียวกัน
  → bonus พิเศษ [TBD] บาท
```

## โครงสร้างรายได้ WPS ที่พนักงานต้องเข้าใจ

```
รายได้บริษัท WPS มาจาก 2 แหล่ง:

1. Margin สินค้า: ~1%    (เล็กน้อย)
2. VAT 0% refund: สูงกว่า (แหล่งหลัก)

ดังนั้น commission พนักงานต้องสะท้อน:
→ จูงใจให้ขายมาก (ปริมาณ = VAT refund สูง)
→ จูงใจให้ขายกำไรดี (ไม่ลดราคาจนหมด margin)
→ ไม่จำกัดว่าต้องขายสินค้ากลุ่มไหน
```

## ข้อแตกต่างสำคัญ: ส่งออก vs ช่องทางอื่น

| หัวข้อ | ค้าปลีก/ค้าส่ง | ส่งออก |
|--------|-------------|-------|
| Commission base | ยอดขาย | กำไร (margin) |
| ผูกกับ | แบรนด์/หมวด | ไม่ผูก — เน้น margin |
| Gate | เป้าทีม/สาขา | เป้า volume ขั้นต่ำ |
| Installment bonus | มี (ค้าปลีก) | ไม่มี |
| Zone coverage | มี (ค้าส่ง) | ไม่มี (ลาวตลาดเดียว) |
| สินค้าที่เน้น | ตาม push list | กำไรสูง ไม่จำกัดกลุ่ม |
