# Commission ค้าปลีก (SWE-RET) — หลักการและโครงสร้าง

---

## Priority การขายค้าปลีก

พนักงานค้าปลีกที่ดีต้อง **ไม่แค่ขายได้** แต่ต้อง:

```
1. ขาย UP-SIZE    → ลูกค้าอยากได้ 9,000 BTU → ปิดที่ 12,000 BTU
2. เพิ่มเคสผ่อน  → เงินสดทุกราย → เสนอผ่อน 0% ก่อนเสมอ
3. ทำแลกซื้อ     → ลูกค้ามีของเก่า → รับแลกลดราคา
4. ขายหลายแบรนด์ → ไม่ขายแค่แบรนด์โปรด → กระจาย commission pool
```

  - หัวหน้าสาขา: [TBD %] ของ pool
  - พนักงานขายรวม: [TBD %] ของ pool (แบ่งตามสัดส่วนยอดขายแต่ละคน)

เงื่อนไข unlock:
  ≥ 100% เป้าสาขา → pool เต็ม 100%

  80–89%           → pool [TBD %]
  < 80%            → pool [TBD %] หรือ fixed amount

```

  ถึงเป้าครบทุกแบรนด์   → Commission rate = [TBD %] (สูงสุด)
  ถึงเป้า 70–99% แบรนด์  → Commission rate = [TBD %]
  ถึงเป้า < 70% แบรนด์   → Commission rate = [TBD %] (ขั้นต่ำ)

Own Brand Target (Brand Nominee):
  ≥ 90% เป้าแบรนด์ + ≥ 5 เคสผ่อน → qualify รับ 100 บาท/เคสผ่อน
  ≥ 90% เป้าแบรนด์ อย่างเดียว     → qualify รับ 50 บาท/เคสผ่อน
  < 90% เป้าแบรนด์               → ไม่ qualify รับ bonus เคสผ่อน
```

## คำถามที่พนักงานถามบ่อย

**Q: ถ้าทีมไม่ถึงเป้า ฉันขายดีคนเดียวยังได้ commission ไหม?**
A: ได้บางส่วน — ชั้น 1 อาจลดลง แต่ชั้น 3 และ 4 (push bonus, skill) ยังได้ตามที่ทำได้จริง

**Q: เคสผ่อนนับยังไง ถ้าลูกค้าผ่อนไม่ผ่านอนุมัติ?**
A: นับเฉพาะเคสที่อนุมัติผ่านแล้ว ไม่นับเคสที่ไม่ผ่าน

**Q: สินค้าโชว์/เกรด B ต้องทำอะไรก่อนขาย?**
A: แจ้งลูกค้าชัดเจนว่าเป็นสินค้าโชว์หรือมีตำหนิ + ให้ลูกค้าเซ็นรับทราบ
