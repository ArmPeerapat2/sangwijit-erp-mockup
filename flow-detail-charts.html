🟪 เคลม/บริการ — S/N-first → Resolution A-E → Settlement

เมนูเงื่อนไข S/Nไปทางไหน
Aเจอ + ในประกันเคลม/ซ่อมในประกัน — ดึงประวัติซื้อ + vendor + ตารางประกันรายชิ้น
Bเจอ + หมดประกันซ่อมปกติ คิดเงินลูกค้า
Cเจอ + มีงานค้างเปิดงานเดิมต่อ (กันเปิด job ซ้ำ)
Dไม่เจอ S/Nกรอก manual + แนบหลักฐาน → admin ยืนยันก่อน
Eเจอ แต่ซื้อที่อื่นเช็คแบรนด์ → เคลมอะไหล่/ค่าแรงได้ · เปลี่ยนเครื่องใหม่ไม่ได้
⛔ Gate ปิดงาน: ค้างคืนอะไหล่ในประกันแม้ line เดียว → SV-4/SV-7 ปิดงานไม่ได้ (หลักเดียวกับ "ของก่อนเงิน") · อะไหล่ในประกัน = ต้องคืนของเก่าให้ vendor · นอกประกัน (ซื้อ PO) = ไม่ต้องคืน
① เคลมสินค้า (ไม่มีลูกค้า): ของเสียตอนยังเป็นสต๊อกเรา (incoming QC / DOA แกะกล่อง / pre-sale) → อ้างบิลซื้อของเราเอง → CLM → PO-CN (S1-S4) ตรง ไม่ผ่านลูกค้า

TCช่องทางประเภทCODผลส่งขั้นตอน / ผลลัพธ์คาด
TC-1🚚 ทีมเองส่งเฉยๆ–สำเร็จเบิก WH-2 → ส่ง → ลูกค้าเซ็น POD → ปิดงาน
TC-2🚚 ทีมเองส่ง+ติดตั้ง–สำเร็จเบิก → ส่ง → ช่างติดตั้ง+QA → POD → ปิดงาน
TC-3🚚 ทีมเองส่งเฉยๆมีสำเร็จ…POD + รับสด SC-3P → ปิดงาน
TC-4📦 3PLส่งเฉยๆ–สำเร็จเบิก+แพ็ค → carrier+tracking → delivered → ปิดงาน
TC-5📦 3PLส่งเฉยๆมีสำเร็จ…COD เข้ารอบ → กระทบยอด FI-3 → ปิดงาน
TC-6ลูกค้าไม่รับ / ไม่อยู่❌ ยกเลิกยกเลิกงานเลย (ไม่นัดใหม่) · ของคืนคลัง WH-1 · แจ้งขาย SL
TC-7ของเสียหาย / ส่งผิดคืน/เคลมคืนคลัง WH-1 / เปิดเคลม CLM
TC-8🚚 ทีมเองส่งงานซ่อมคืนอาจมีสำเร็จจาก SV-4 ซ่อมเสร็จ → ส่งคืน SV-7 → POD → ปิดงานซ่อม
TC-9📦 3PLส่ง+ติดตั้ง–edge3PL ส่งอย่างเดียว → ช่างเราตามไปติดตั้งแยก (2 เที่ยว) หรือใช้ทีมเองทั้งงาน
ช่องทางส่ง = 1 field branch พฤติกรรม (ไม่แตกหน้า): 🚚 ทีมเอง → POD เซ็นในแอป · COD รับสด SC-3P · ค่าเที่ยว = CM (แยกสูตรจากช่าง) · 📦 3PL (Kerry/Flash/J&T/ปณ.) → POD = delivered/สลิป · COD เข้าเป็นรอบ→FI-3 · ค่าส่งเป็นต้นทุน (ใบวางบิล 3PL → FI-2) · เฟสนี้มี field+tracking+สถานะ — API carrier ต่อจริงเฟสหลัง
⛔ ส่งไม่สำเร็จ = ยกเลิกงานเลย (เคาะ 07-29) ไม่มีการนัดส่งใหม่ · ของกลับคืนคลัง WH-1 แล้วแจ้งฝั่งขาย SL ให้จัดการต่อ (นัดใหม่ = เปิดงานจัดส่งใบใหม่)
