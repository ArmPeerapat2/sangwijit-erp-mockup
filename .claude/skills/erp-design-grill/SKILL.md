# ERP Design Grill (Sangwijit)

เป้าหมาย: ก่อนสร้าง mockup หน้าไหน ให้ grill เจ้าของงาน (Peerapat) ให้ตกผลึกก่อน — ด้วย **ภาษาบ้าน ๆ**, ถาม **use-case ทีละข้อ**, มี **ตัวเลือก + แนะนำ 1 อัน**, แล้วปิดด้วย **blueprint 3 ส่วน + flow links**.

## ปรัชญาที่สกัดจากการตัดสินใจจริง
> **คนถือพวงมาลัย · ระบบเป็นเบรก · เอาของเดิมมาต่อ · เข้มเฉพาะจุดที่เจ็บ (เงิน/ภาษี/ของหาย)**

## ขั้นตอน

### Step 0 — Ground ก่อนถาม (บังคับ)
อ่านให้ครบก่อน grill: `.agents/active.md` (decision ล่าสุด) · spec โมดูล (`sangwijit-portal-skill/modules/<X>.md`) · Flow PDF (`Flow Design/<Module>/`) · หน้าใกล้เคียงที่มีอยู่ (กัน rebuild ของที่ดีอยู่แล้ว). ถ้า spec เคาะไว้แล้ว → **อย่า grill ซ้ำ** ข้ามไป blueprint.

### Step 1 — Grill ผ่าน 9 มิติ (ถามเฉพาะที่ยังไม่ชัด)
ถามทีละข้อ · แต่ละข้อ = 1 use-case (ฉากจริง) + 2-4 ตัวเลือก + แนะนำ 1 · ภาษาง่าย เลี่ยงศัพท์ฝรั่ง (ถ้าใช้ให้แปลกำกับ):

1. **ใช้ของเดิม** (Reuse) — flow/หน้า/ชิ้นส่วนเดิมรับงานนี้ได้ไหม ก่อนสร้างใหม่ *(เช่น สัญญา MA → เข้าค้างมอบหมายเหมือนขอนัด)*
2. **ผูกแน่น/หลวม** (Coupling) — ระบบขับให้เองข้ามหน้า หรืออ้างอิงเฉย ๆ + เตือน · ใครถือการตัดสินใจ
3. **ความเข้ม** (Strictness) — ห้ามผ่าน / เตือนแต่ปิดได้ / ปล่อย — ปรับตามความเสี่ยง (เงิน·ภาษี·ของหาย = เข้ม)
4. **จุดควบคุม** (Control point) — คุมจุดเดียว (ง่าย) หรือหลายจุด · โดยเฉพาะเรื่องเงิน
5. **ระดับความละเอียด** (Granularity) — ทั้งบิล / ต่อบรรทัด / ต่อชิ้น
6. **หลักฐาน** (Evidence) — กรอกเองได้ไหม ต้องแนบอะไรแทนร่องรอยตรวจสอบ (audit)
7. **ความยืดหยุ่น** (Flexibility) — ถ้าหลายกรณีถูกหมด ให้เลือก/สลับได้
8. **แบ่งเฟส** (Phasing) — ตัดของยากไปเฟสหลัง (P2/P3) · ตั้งค่าละเอียดยกไปหน้าตั้งค่า (CF)
9. **เชื่อมสายงาน** (Flow-link) — ครัวรับออเดอร์: ทุกรายการโชว์เอกสารต้นทาง · ระบุ มาจากใบไหน→ต่อใบไหน + ข้ามแผนก

**กฎภาษา (เหล็ก):** ทุกชื่อมิติ/ตัวเลือก/หัวข้อ = **ไทยนำ อังกฤษในวงเล็บ** · ห้ามใช้ศัพท์อังกฤษลอย ๆ (soft/hard/stack/scope...) ต้องแปลไทยเสมอ

### Step 2 — Blueprint 3 ส่วน (confirm ก่อนเขียนโค้ด)
1. **Shared component (reuse):** class/หน้าที่มีแล้ว (swt-patterns.css · sc1/sc2 · doc-chain · saab)
2. **กลุ่มข้อมูล + field:** section มี code กำกับ (X-1.1) · ตาม density SL-4
3. **ส่วนเพิ่ม (logic ใหม่):** JS · gate · การเชื่อม flow

จบด้วยตาราง map "คำถาม → คำตอบ → ผลต่อดีไซน์" แล้วรอ "go".
