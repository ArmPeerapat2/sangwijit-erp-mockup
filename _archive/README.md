## วิธีใช้สารบัญนี้

- **หาไฟล์ที่ถูกแทนที่** → ดูคอลัมน์ "ตอนนี้ใช้อะไรแทน" แล้วเปิดไฟล์นั้นที่โฟลเดอร์หลัก
- **ไฟล์ลงท้ายด้วยวันที่** (เช่น `-2026-06-06.html`) = **สำเนาก่อนแก้ครั้งใหญ่** ตัวจริงชื่อเดิมยังอยู่ที่โฟลเดอร์หลัก ไม่ได้หายไปไหน
- **ไฟล์ไม่มีวันที่** = หน้านั้นถูกยกเลิกทั้งหน้า ไม่มีตัวแทนชื่อเดิม
- ทุกไฟล์อยู่ใน git — ต้องการเวอร์ชันไหนย้อนได้หมด
