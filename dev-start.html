① เริ่มยังไง (Day 0)

3 ขั้นตอน จับต้องได้ทันที

⚠️ อย่าทำตาม "Getting Started" ใน README — มันบอก npm install / npm run dev ซึ่ง ผิด/ล้าสมัย. repo นี้ ไม่มี package.json ไม่มี build system เลย. ทำตามข้างล่างนี้แทน
  1. เปิดดูระบบ: เปิด index.html ในเบราว์เซอร์ตรง ๆ (ดับเบิลคลิกไฟล์ก็ได้) → คลิกไล่ดูทุกหน้า mockup · ไม่ต้องรัน server อะไรทั้งนั้น
  2. แก้ = เปิดไฟล์ HTML แก้ในตัว: แต่ละหน้าคือ *.html เดี่ยว ๆ มี <style> + <script> อยู่ในตัว (ยกเว้นของกลาง swt-*.js/css) · เซฟแล้ว refresh เบราว์เซอร์
  3. Git (สำคัญ): git pull ก่อนเริ่มทุกครั้ง · git commit + push หลังเสร็จทุกครั้ง — repo อยู่บน OneDrive แต่ GitHub คือตัวจริง (เคยมีไฟล์พังเพราะ OneDrive sync ทับ)
💡 Mental model ที่ต้องมีก่อน: Portal นี้เป็น UI layer อย่างเดียว — ไม่มี database ของตัวเอง ไม่ post/คำนวณเลขเอง. การ post / running number / สถานะ เป็นของ BC365 ทั้งหมด. mockup ตอนนี้ยังไม่ต่อ BC จริง (Phase 1)

② ระบบนี้คืออะไร (30 วินาที)
