ภาพเชื่อมหมวด — รายละเอียดต่อหน้าอยู่ในการ์ดหมวดด้านล่าง
1 · ขาย (Order-to-Cash): SL-1→2→3→4 → WH-2 เบิก → SV-6 ส่ง/ติดตั้ง → FI-1 รับเงิน · ลดหนี้ = SL-CN
2 · ซื้อ (Procure-to-Pay): PO-1→4 → WH-1 รับ → PO-6 ตั้งหนี้ → FI-2 จ่าย · ลดหนี้ = PO-CN · ส่งเสริม = PO-2→PO-7
3 · เคลม → ลดหนี้: SV ตัดสินเคลม → SL-Q กลุ่ม CN → SL-CN → FI-1Q ใช้เครดิต (apply/คืนเงิน)
4 · โอนคลัง: WH-3R ขอโอน → WH-3 โอน (owner) → WH-1 รับปลายทาง (In-Transit)

🎬 Use Case — สถานการณ์จริง

แต่ละการ์ด = 1 เรื่องจริง · โซ่หน้าที่ร้อยต่อกัน · คลิกสเต็ปเปิดหน้าจริง

🟦 ขายปกติ + มัดจำ

ลูกค้าตกลงซื้อ วางมัดจำก่อน แล้วเก็บเงินที่เหลือตอนส่งของ (สาย 1 ขาย)
SL-1เสนอราคา → SL-2จองสต็อก → SL-3รับมัดจำ → SL-4ออกบิล → WH-2เบิกส่ง → FI-1รับเงินคงเหลือ
✅ เกณฑ์ตรวจ (A · Given-When-Then)
กำหนดให้ ใบจอง SL-2 รับมัดจำแล้ว 6,290 · ยอดขายรวม 17,430   เมื่อ ออกบิล SL-4   แล้วจะ ยอดสุทธิ = 17,430 − 6,290 (มัดจำ) = 11,140 · เก็บส่วนที่เหลือที่ FI-1 หลังส่งของ (WH-2)
⚠️ ทางพลาด: ยังไม่รับมัดจำ (SL-3) → ออกบิลได้แต่ไม่มียอดหัก · ส่วนลดต้องหักก่อน VAT เสมอ

🟦 ขายเชื่อเกินวงเงิน

ยอดขายเชื่อเกิน Credit Limit → ต้องผ่านอนุมัติก่อนไปต่อ (สาย 1 ขาย · แตกสาขา)
SL-1เสนอราคา → SL-F1อนุมัติวงเงิน → CF-2.6Matrix → SL-4ออกบิล → FI-1รับเงิน
✅ เกณฑ์ตรวจ (A · Given-When-Then)
กำหนดให้ ลูกค้าวงเงิน 500,000 · ใช้ไป 480,000   เมื่อ เปิดบิลเชื่อ 50,000 (เกินวงเงิน 30,000)   แล้วจะ ระบบบล็อกออกบิล → เด้ง SL-F1 ขออนุมัติ → ผ่าน CF-2.6 (Maker ≠ Checker) ก่อน จึงออก SL-4 ได้
⚠️ ทางพลาด: อนุมัติไม่ผ่าน → บิลค้างสถานะ "รออนุมัติ" · ออก SL-4 / รับเงินไม่ได้

🟪 ลูกค้าคืนของ → ลดหนี้ขาย

ของมีปัญหา/คืนหลังออกบิลแล้ว → ออกใบลดหนี้ แล้วเลือก apply หรือคืนเงิน (สาย 3 ลดหนี้)
SL-4บิลที่ออกไปแล้ว → SL-CNใบลดหนี้ → FI-1Qapply / คืนเงิน
✅ เกณฑ์ตรวจ (C · ทางหลัก + ทางแตก)
ทางหลัก: ใบลดหนี้ต้องอ้างบิลต้นทาง (SL-4) เสมอ · ยอด/VAT ที่ลด ระบบคำนวณ (แก้ไม่ได้)
ปลายทาง 1 — หักบิลถัดไป: เครดิตค้างเข้า ledger ลูกหนี้ → ตัดกับบิลหน้า
ปลายทาง 2 — คืนเงิน: โอน/เงินสด → ตั้งจ่ายที่ FI
⚠️ ทางพลาด: ไม่อ้างบิลต้นทาง → ออกใบลดหนี้ไม่ได้ (บังคับอ้างอิง)

🟧 จัดซื้อเข้าคลัง → จ่ายเจ้าหนี้

ขอซื้อ → สั่งซื้อ → รับของเข้าคลัง → วางบิล → ตั้งหนี้ → จ่าย (สาย 2 ซื้อ)
PO-1ขอซื้อ → PO-4สั่งซื้อ → WH-1รับของ → PO-3วางบิล → PO-6ตั้งหนี้ → FI-2จ่าย
✅ เกณฑ์ตรวจ (A · 3-Way Match)
กำหนดให้ PO-4 สั่ง 100 ชิ้น @ ราคาตกลง   เมื่อ รับของ WH-1 + วางบิล vendor   แล้วจะ จับคู่ 3 ทาง (PO = ใบรับ = ใบวางบิล) ผ่าน → ตั้งหนี้ PO-6 · ยึดราคา PO เสมอ
⚠️ ทางพลาด: รับเกินจำนวน PO / ราคาใบวางบิล ≠ PO → ระบบบล็อก (ส่วนต่างแก้ที่ PO หรือออก PO-CN)

🟧 ส่งเสริมการขายจาก Vendor

ทำข้อตกลงกับ vendor → วัดยอดจริง → เคลมมาหักลดหนี้ฝั่งซื้อ (สาย 2 ซื้อ · ส่งเสริม)
PO-2ข้อตกลง → PO-7ยอดได้จริง → PO-CNลดหนี้ซื้อ / หัก PO-6net AP
✅ เกณฑ์ตรวจ (A · Given-When-Then)
กำหนดให้ ข้อตกลง PO-2 กับ vendor มีเป้ายอดซื้อ   เมื่อ PO-7 วัดยอดจริงถึงเป้า   แล้วจะ เคลมได้ → ออก PO-CN หักลดหนี้ฝั่งซื้อ (net ที่ PO-6)
⚠️ ทางพลาด: ยอดซื้อจริงไม่ถึงเป้า → เคลมไม่ได้ (rebate = 0) · เคลมต้องผูกข้อตกลง PO-2

🟩 สาขาขอโอนของข้ามคลัง

ปลายทางขาดของ → ขอโอน → ต้นทางโอนออก → ปลายทางรับ (In-Transit ระหว่างทาง · สาย 4 โอน)
WH-3Rขอโอน (pull) → WH-3โอนออก → WH-1รับปลายทาง
✅ เกณฑ์ตรวจ (A · In-Transit)
กำหนดให้ ปลายทางขาดของ ขอโอน WH-3R   เมื่อ ต้นทางโอนออก WH-3   แล้วจะ ตัดสต็อกต้นทางทันที · ของอยู่สถานะ In-Transit · เข้าสต็อกปลายทางเมื่อ WH-1 รับ
⚠️ ทางพลาด: ปลายทางยังไม่รับ → ของค้าง In-Transit (ไม่นับเป็นสต็อกปลายทาง · ไม่หายจากระบบ)

🟩 ขายเกินสต๊อก → เกลี่ยของอัตโนมัติ (Waterfall) · ดู flowchart →

1 บรรทัดขายที่คลังจ่ายมีไม่พอ → แตกได้ถึง 3 ใบขอ ตามลำดับ เบิก→โอน→ซื้อ · ทุกใบอ้างใบขายเดียวกัน (สาย 6 คลัง · waterfall)

✅ เกณฑ์ตรวจ (C · ทางแตกตามลำดับ · ทุกใบอ้างใบขายเดียวกัน)
ทางหลัก: 1 บรรทัดขาย คลังจ่ายมีไม่พอ → เกลี่ยตามลำดับ (ไม่ข้ามขั้น)

⚠️ ทางพลาด: ยอดรวม 3 ใบ ≠ ยอดขาย → ไม่ครบ/เกิน · ทุกใบต้องอ้าง SL ใบเดียวกัน

กำหนดให้ มีงานคลังเข้าหลายทิศ (รับ/เบิก/นับ)   เมื่อ เปิดคิว WH-Q   แล้วจะ ตั๋วจัดกลุ่มตามงาน · คลิกตั๋ว → เปิดฟอร์มทำจริง (WH-1/WH-2/WH-4) · คิวแค่รวบ+นำทาง ไม่ทำรายการเอง
⚠️ ทางพลาด: ทำรายการที่ฟอร์มแล้วคิวไม่อัปเดต → ตั๋วค้างซ้ำ (คิวต้อง sync สถานะจากเอกสารจริง)

🟪 งานซ่อมในประกัน → เคลม Vendor

ลูกค้าส่งเครื่องซ่อม อยู่ในประกัน → ค่าใช้จ่ายเรียกคืนจาก vendor ปลายทางเป็นลดหนี้ซื้อ (สาย 7 บริการ)

✅ เกณฑ์ตรวจ (A · Given-When-Then)

⚠️ ทางพลาด: นอกประกัน → ลูกค้าจ่ายเอง (ไม่เข้า CLM/PO-CN) · เบิกอะไหล่ SV-3 ต้อง เหลือ − ใช้ = คืน
