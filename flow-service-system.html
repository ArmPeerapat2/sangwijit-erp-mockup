เจอ S/N + ในประกัน → งานเคลม/ซ่อมในประกัน (②) — ดึงประวัติซื้อ + vendor + ตารางประกันรายชิ้น

🔒 ประกัน = per-component ไม่ใช่ธง in/out รายเครื่อง — งานเดียวเสียหลายชิ้น บางชิ้นในประกัน บางชิ้นหมด A/E → เข้าสาย ② งานบริการ · D → รอ admin · ของยังเป็นสต๊อกเรา (pre-sale/DOA) → เข้าสาย ① เคลมสินค้า
