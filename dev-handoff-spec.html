Golden Rule — Portal ห้ามทำ

ห้ามเหตุผล
❌ Post GL EntriesBC เป็นคนเดียวที่ post ลง General Ledger — Portal ส่ง document data ไป BC ทำ posting
❌ คำนวณ VAT/WHTBC มี Tax Posting Setup ครบ — Portal แค่แสดงผลลัพธ์ที่ BC คำนวณ
❌ Generate เลขเอกสารBC Number Series จัดการ — Portal ได้เลขกลับมาหลัง Post
❌ จัดการ Bin / InventoryBC Warehouse Module — Portal เรียก API ดู/ย้าย stock
❌ Approval Workflow engineBC Approval Entries — Portal เรียก API approve/reject

Portal ทำอะไรได้ (Custom Logic)

Portal ทำรายละเอียด
✅ UI/UX Layerหน้าจอ custom, dashboard, KPI aggregation, charts
✅ Tech Job Template (CF-2.5)ข้อมูลเฉพาะธุรกิจแสงวิจิตร — BC ไม่มี Job Template
✅ Trade Agreement (MD-3)Rebate/MDF/Co-op/Penalty — BC ไม่มี module นี้
✅ Commission Calculation (CM-1)4-layer commission — custom formula
✅ CRM Pipeline (SL-5)Kanban + Follow-up — BC CRM จำกัด
✅ Document Templates (CF-2.7)Print format — ใบเสนอราคา, Invoice, DO, Service
✅ Approval Matrix UI (CF-2.6)Visual matrix — Position × DocType × Threshold
✅ SKU Slot / Health (SM-1/2)Space management — BC ไม่มี quota per branch
✅ Delivery Planning (DL-1)Fleet + route + cubic meter — BC ไม่มี

🔌 API Patterns & Conventions

แนวปฏิบัติการเรียก BC365 API — ใช้ OData v4 / REST API v2.0

Base URL Pattern

// ─── Multi-company: ต้องระบุ company ID ทุกครั้ง ─── Base: https://{bc-host}/api/v2.0/companies({companyId})/{entity} // ─── Company IDs (ตัวอย่าง) ─── SWT: companies('swt-guid-here') SWE: companies('swe-guid-here') VMN: companies('vmn-guid-here') WPS: companies('wps-guid-here')

Authentication

Methodรายละเอียด
OAuth 2.0Azure AD — Client Credentials flow (service-to-service) หรือ Authorization Code (user-delegated)
HeaderAuthorization: Bearer {access_token}
Scopehttps://api.businesscentral.dynamics.com/.default

Common Query Patterns

// Pagination ?$top=50&$skip=0 // Filter + Sort ?$filter=status eq 'Open' and postingDate ge 2025-01-01&$orderby=postingDate desc // Expand relations ?$expand=salesOrderLines,dimensionSetLines // Select specific fields (performance) ?$select=no,customerName,totalAmountIncludingTax,status // Multi-company ข้ามนิติบุคคล → Portal ต้อง call แยก company แล้ว merge ฝั่ง frontend

Error Handling

HTTP CodeความหมายPortal ทำอะไร
200/201Successแสดงผลปกติ / toast success
400Bad Request — validation errorแสดง error message จาก BC ใน form field
401Unauthorized — token expiredRefresh token → retry, ถ้าไม่ได้ redirect login
404Not Foundแสดง "ไม่พบข้อมูล" + ให้ย้อนกลับ
409Conflict — concurrent editแสดง "ข้อมูลถูกแก้ไขแล้ว" → reload
429Rate LimitRetry with exponential backoff
