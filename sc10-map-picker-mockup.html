⑤ Design Notes — รายละเอียดสำหรับ Dev

Spec
  • Pin colors: 🟢 Start (#10B981), 🔵 Stop (#2563EB), 🔴 End/Single (#EF4444), 🟠 Draggable indicator (#F59E0B)
  • Map provider: Google Maps JavaScript API v3 — fallback Leaflet+OSM ถ้า quota เกิน
  • ค่าเริ่มต้น: Center = สาขาที่ user login (จาก MD-5), Zoom = 15
  • Lat/Lng precision: 13 ตำแหน่งทศนิยม (ตามฟอร์แมต Google Maps native)
  • Drag debounce: 300ms ก่อนยิง @pin-drag ป้องกัน spam event
  • Mobile fallback: ถ้า user เปิดบนมือถือ → ใช้ navigator.geolocation auto-fill ตำแหน่งฉัน
  • Offline mode: ถ้าโหลด map ไม่ได้ → แสดง Lat/Lng input + ปุ่ม "เปิดใน Google Maps" แทน
  • Permission: ผู้ใช้ทุก role ใช้ได้ ยกเว้น Multi-Pin Mode → จำกัดเฉพาะ Admin/Dispatcher
  • RBAC field-level: Lat/Lng input อาจถูกตั้งเป็น read-only ตาม role (เช่น Sale แก้ไม่ได้, Dispatcher แก้ได้)
