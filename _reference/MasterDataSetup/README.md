# Master Data Setup (1.5.1.x) — ERP เดิม

หน้ากำหนดข้อมูลหลัก (master) ทุกหน้าใช้ **pattern เดียวกัน: list ซ้าย + ฟอร์มแก้ไขขวา** (list-detail)
- ซ้าย: ตาราง รหัส · ชื่อ + ช่องค้น + ปุ่มคีย์/ปิดหน้าจอ
- ขวา: ฟอร์มแก้ไขรายการที่เลือก (มี "เปิดใช้งาน" ทุกหน้า = active/inactive)
> รูปจริง: ลากวาง `branch-1511.jpg`, `cardtype-151A.jpg` ในโฟลเดอร์นี้

## 1.5.1.A กำหนดประเภทบัตร (Card / Payment Channel) — ป้อน sc-payment
**Fields:** รหัส · ชื่อ · ชื่อย่อ · **%ชาร์จ** (0.00) · เปิดใช้งาน · รูป
→ นี่คือ master ของ "Select Credit Type" ในหน้ารับชำระ ([../ComponanceShare/](../ComponanceShare/) payment2) · แต่ละช่องมี % ชาร์จของตัวเอง

**รายการ (30+):**
- **มาร์เก็ตเพลส:** LaZaDa · SHOPEE · Noc Noc · JD (to C to P?) · ชิป ช้อป ใช้ · เฟรี้สช้อยส์
- **บัตรธนาคาร:** กรุงเทพ · กรุงไทย · กรุงศรี · กสิกรไทย · ซิตี้แบงก์ · ทหารไทย · ไทยพาณิชย์ · ธกส. · ยูโอบี · อิออน
- **e-wallet / gov:** ทรูมันนี่ · คนละครึ่ง · เราชนะ · ม33 (เรารักกัน)
- **ผ่อน (installment):** วินมันนี่ (ผ่อนกับวินมันนี่) · แสงวิจิตร (ผ่อนกับแสงวิจิตร) · บานาน่า
- **retail/อื่น:** โฮมโปร · เทสโก้ · ไฮเออร์คอมฯ · ไฮเออร์ติดตั้ง · ฟอลคอล · เจ ดี · คนละครึ่ง · **ปลายทาง (เก็บเงินปลายทาง = COD)**

> โยงพอร์ทัล: sc-payment แท็บ "บัตร/มาร์เก็ตเพลส" → dropdown มาจาก master นี้ + auto ดึง %ชาร์จ มาคิดยอดสุทธิ · เป็น CF master (BC อาจถือจริง)
