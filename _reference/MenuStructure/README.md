## เมนูบนสุด (module groups)

## 1.ไฟล์ (submenu)
- 1.1 สร้างบริษัททำงานใหม่
- 1.2 บันทึกข้อมูลบริษัท → (มี Company/Options tab · ดู `../SystemDefaults/`)
- 1.3 Verify Database · 1.4 Backup Database
- 1.5 ขึ้นระบบ/ข้อมูลหลัก → 1.5.1 ข้อมูลหลักต่างๆ · 1.5.2 ข้อมูลหลักสินค้า · 1.5.3 ข้อมูลหลักลูกค้า · 1.5.4 ข้อมูลหลักเจ้าหนี้ · 1.5.5 ลบข้อมูลรายวัน/ยกยอดสิ้นปี
- 1.6 นำเข้า/ส่งออกข้อมูล
- 1.7 สร้างฟอร์มเอกสาร → (ดู `../FormReportDesigner/`)
- 1.8 ปิดทุกหน้าจอ · 1.9 พักหน้าจอโปรแกรม · 1.A แสดงหน้าแรก · 1.B สร้างรายงาน · 1.Q ออกจากโปรแกรม
