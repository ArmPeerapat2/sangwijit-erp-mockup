📋 ขั้นตอนการนับ
  1. กดปุ่ม "📊 เริ่มนับ" → status เปลี่ยนเป็น "กำลังนับ"
  2. นับสินค้าจริงในคลัง · กรอกจำนวนใน column "นับจริง"
  3. ระบบคิดส่วนต่างให้อัตโนมัติ = นับจริง − (ยอดตั้งต้น + เคลื่อนไหวระหว่างนับ)
    ⚠️ ห้ามคิดจาก "นับจริง − ยอดระบบ ณ ตอนนี้" — เพราะระหว่างนับยังขาย/รับของได้ตามปกติ ยอดระบบจึงขยับตลอด · ฐานที่ใช้เทียบต้องเป็นยอดตั้งต้นที่แช่ไว้ตอนออกใบเตรียมนับเท่านั้น
  4. มีส่วนต่างเท่าไรก็ต้องนับซ้ำก่อนเสมอ (เคาะ 2026-07-20) — ไม่มีเกณฑ์ยกเว้น แม้ต่างชิ้นเดียว → ระบบสร้างใบนับซ้ำอัตโนมัติให้ยืนยัน
  5. ส่วนต่าง = 0 หรือผ่านการนับซ้ำแล้ว → กด "Submit" → ส่งให้หัวหน้าอนุมัติ
  6. Supervisor approve → BC365 post Stock Adjustment entry · stock update real-time
🔓 ระหว่างนับ ไม่ล็อกการเคลื่อนไหว (เคาะ 2026-07-20) — ขาย/เบิก/รับของ SKU ที่อยู่ในรอบนับได้ตามปกติ · ระบบบันทึกรายการที่ขยับไว้ในคอลัมน์ "เคลื่อนไหวระหว่างนับ" แล้วนำไปหักลบตอนคิดส่วนต่าง
