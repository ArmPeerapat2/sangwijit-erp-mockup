- **🔧 ช่างติดตั้ง** — ติดตั้ง (เฉพาะงานมีติดตั้ง) · QA
- **👤 ลูกค้า** — รับของ · เซ็นรับ (POD) · ชำระ (ถ้า COD)

## cross-link (เชื่อมโมดูลอื่น)
- **เข้า:** SL-4 บิลขาย (ส่งเฉยๆ/ติดตั้ง) → คิวจัดส่ง · SV งานซ่อมเสร็จ (SV-4) → ส่งงานคืน SV-7 · WH-2 เบิกของ
- **ออก:** ส่งมอบเสร็จ → ปิดบิล SL / ปิดงานซ่อม SV · COD → FI-1 รับชำระ · ของเสียหาย → CLM เคลม/WH-1 คืน · ค่าเที่ยวทีมส่ง → CM (ถ้ามี)

## ❓ จุดที่ flag (รอ Peerapat เคาะ)
1. ❓ **ค่าเที่ยว/incentive ทีมส่ง** — คิดเหมือนช่าง (CM) ไหม หรือแยก?
2. ❓ **ส่งไม่สำเร็จกี่ครั้งถึงยกเลิก** — นัดส่งใหม่ได้ไม่จำกัด หรือมีเพดาน?
3. ❓ **สิทธิ์มอบหมาย/reassign** = ตำแหน่งไหน (คาดว่า CF-1 เหมือน WH)
4. ❓ **แยกทีมส่งเอง vs จ้างขนส่งภายนอก** — มี tracking ภายนอกไหม
