# FI บัญชี/การเงิน — State Transition Table (ตารางเปลี่ยนสถานะ)

Module: **FI (บัญชี/การเงิน)** · **derived จาก mockup** (status pill/badge + doc-chain + ปุ่ม action) 2026-07-29
> ✅ **สถานะ: ตรวจ+เคาะครบ (Peerapat 2026-07-29)** — actor เคาะ (บัญชีออก/การเงินจ่าย · จริงกำหนด CF-1) · FI-1 เพิ่มอนุมัติ (Maker≠Checker) · FI-3/7/12=การเงิน · **เพิ่ม FI-4 ใบสำคัญค่าใช้จ่าย** (อ่าน mockup) · ไม่มี ❓ เหลือ
รูปแบบ: State → ขั้นถัดไป (transition+guard) · Actor · Action · สถานะใหม่ · Menu/หน้า
doc-chain หลัก 2 สาย:
- **แกนรับ (AR):** SL-4 บิลขาย (Posted) → **FI-1 รับชำระลูกหนี้** ดึงบิลค้างรับ (Apply AR) → Post → Bank รับเข้า · ปิด AR 🏁
- **แกนจ่าย (AP):** PO-6 ตั้งหนี้ (Posted) → **FI-2 จ่ายชำระเจ้าหนี้** ดึงใบตั้งหนี้ค้างจ่าย [+PO-DP มัดจำ] [+PO-CN ลดหนี้] [+WHT] → Post → Bank จ่ายออก · ปิด AP 🏁 → WHT → **FI-12 ภ.ง.ด.**
- **แกนภาษี/กระทบ:** Posted Invoice → **FI-7 VAT (ภ.พ.30)** · จ่ายเงิน → **FI-12 WHT (ภ.ง.ด.3/53)** · เงินเข้า-ออก → **FI-3 กระทบยอดธนาคาร (Bank Ledger)** · คิวรวม = **FI-Q**

## 🏊 Swimlane — คนเกี่ยวข้อง (✅ เคาะ Peerapat 2026-07-29)
FI เป็น **แกนเงิน + เอกสาร** ล้วน · **หลักการ:** บัญชี = ออก/รับเอกสาร · การเงิน = จ่าย+ภาษี+กระทบยอด · **แต่ตำแหน่งจริงกำหนดที่ CF-1 กลุ่มสิทธิ์** (เหมือน WH — ค่อยสร้างตำแหน่ง)
- **📗 บัญชี** — ออก/Post **รับชำระ RV (FI-1)** (Maker · mockup "วิภา บัญชี")
- **💰 การเงิน** — **จ่าย PV (FI-2)** · **ภาษี VAT/WHT (FI-7/FI-12)** · **กระทบยอดธนาคาร (FI-3)** · ค่าใช้จ่าย (FI-4) — (เคาะ 07-29: FI-3/7/12 = การเงิน)
- **👤 ลูกค้า** (จ่ายเงินให้เรา · แกน AR) · **🚚 เจ้าหนี้/vendor** (เรารับจ่าย · แกน AP)
- **อนุมัติ Maker ≠ Checker — ทั้ง FI-1 รับ + FI-2 จ่าย** (เคาะ 07-29: FI-1 ทำเหมือนฝั่งจ่าย) ผ่าน **AP-1 / CF-2.6**
- **⚙️ BC365** — Post/ออกเลขเอกสาร/Bank Ledger/Release VAT/ปิดงวด = BC ทำ (portal = thin UI · trigger)
