## ④c LINE ITEMS (SC-2 · SC-9) — หัวใจ

**คอลัมน์มาตรฐาน:**
| # | คอลัมน์ | แสดง | แก้ได้ |

| 3 | ชื่อสินค้า · Stock | ชื่อ + รุ่น/สเปก + chip คงเหลือ + **ref ต่อแถว (QT/จอง)** | ✗ |
| 4 | คลัง | badge คลัง | ✓ |

| 7 | ส่วนลด | **% หรือ บาท** ต่อรายการ | ✓ |
| 8 | **พนักงานขาย** | default=ผู้เปิดบิล · **แก้ต่อแถวได้** (split commission) | ✓ |
| 9 | รวม | qty × ราคา − ส่วนลด (auto) | ✗ |
| 10 | 🗑 | ลบแถว | — |

**เพิ่ม 4 ฟีเจอร์ (locked 2026-06-06):**
1. **พนักงานขาย** — header default = ผู้เปิดบิล (แก้ได้ + กรอกเบอร์) · ต่อแถวก็ override ได้
2. **อ้างอิงเอกสาร** — ดึงจาก QT/ใบจอง = **per-line** (หลังชื่อสินค้า) · มัดจำ = **per-bill** (ไปสรุปยอด) · ผ่าน **SC5 DocRef**
3. **ค่าแรง → เข้า SC-2** — ไม่ทำคอลัมน์แยก · "ค่าแรง/บริการ" = **ชนิดสินค้า** เลือกผ่าน modal เพิ่มสินค้า (SC-2 เพิ่มคอลัมน์ "ชนิด": สินค้า/ค่าแรง/บริการ)
4. **ช่องยิงบาร์โค้ด** — อ่านได้ทั้ง **barcode + S/N** · ยิง S/N สินค้าตัวเดิม → **+จำนวนแถวนั้นทันที** · shared ทุกหน้า

**modal เพิ่มสินค้า (SC-2) → 5 คอลัมน์ + ชนิด:** SKU · ชื่อ+รุ่น · คงเหลือต่อคลัง · ราคา · หน่วย · **ชนิด(สินค้า/ค่าแรง/บริการ)**

**Golden Rule:** ส่วนลด (คอลัมน์ 7) คำนวณก่อน VAT เสมอ

**Layout + การแก้ไข (locked 2026-06-06):**
- **ราคา/หน่วย + ส่วนลด** = editable input · จริงๆ จะแก้ได้/ไม่ได้ขึ้นกับ **สิทธิ์** → ตอนนี้เปิดให้แก้ได้ไปก่อน
- **คลัง** = dropdown เลือก (HQ/สาขา/คลังกลาง)
- **สัดส่วนหน้า:** รายการสินค้า = **ฟิก ~45vh** (เด่นสุด) · กลุ่มล่าง (ชำระเงิน-ประวัติ + สรุปยอด) ย่อให้เล็กลง

**จุดต่างรายหน้า:** ซื้อ(PO)=+"ขอ vs สั่งจริง"+VC · บริการ(SV)=+serial · โอน(WH-2)=ไม่มีราคา/ส่วนลด มี FROM→TO

## 🔗 การอ้างอิงเอกสาร — universal & optional (locked 2026-06-06)
- **ทุกฟอร์มต้องมีปุ่ม "🔗 อ้างอิงเอกสาร"** (ที่ header การ์ดข้อมูลเอกสาร) → เปิด finder เลือกเอกสารต้นทาง
- **อ้างอิงหรือไม่อ้างอิงก็ได้** — ไม่บังคับ (เช่น มัดจำ walk-in ไม่ผูกใบจองก็ได้) · field อ้างอิงใช้ "(ถ้ามี · ไม่บังคับ)" ไม่ใช่ `*`
- **ปุ่มค้นหาลูกค้า (🔍 เลือก/เปลี่ยน) ต้องมีเสมอทุกฟอร์ม** แม้ดึงจากเอกสารต้นทาง (กรณีไม่อ้างอิงต้องเลือกเองได้) — ห้ามล็อก/ซ่อน

## 🖥️ Layout — fit หน้าจอ ไม่มี scroll หน้า (locked 2026-06-06 · อ้างอิงระบบเดิม 3.2)

- **โครง full-height flex:** `body/layout/main = height:100vh; overflow:hidden` → หน้าไม่เลื่อน
- topbar · main-header · SAAB · party · สรุปยอด · doc-chain = **`flex:none` ตรึง**
- **ตารางสินค้า = ตัวดูดพื้นที่เดียว** `flex:1` · scroll ภายในตารางเท่านั้น · แสดงแถวว่างพร้อมกรอก **~15 บรรทัด** (เหมือน 3.2)
- **แถบล่าง (tabs ชำระเงิน-ประวัติ + สรุปยอด) ตรึงสูง ~150px** · เกินแล้ว scroll ในการ์ด
- **party card (ลูกค้า/ข้อมูลเอกสาร) ย่อเตี้ย** เพื่อคืนพื้นที่ตาราง
- **หมายเหตุ** ย่อ 1 บรรทัด · WHT/มัดจำหัก ซ่อน default (class `show-extra` เพื่อโชว์)
- ⚠️ บทเรียน: rule `.content>.card` อย่าเผลอครอบ `items-card` (ใช้ `:not(.items-card)`) ไม่งั้นตารางไม่ยืด → ตัวล่างโดน overflow ตัด

> **swt-doc-finder.js (shared):** 📂 ค้นหาเอกสารเก่า + Customer/Product picker แยกเป็นไฟล์ inject เอง · ทุกหน้าใช้ `dfOpen()/dfOpenCust()/dfOpenProd()/dfVendorMode()`
