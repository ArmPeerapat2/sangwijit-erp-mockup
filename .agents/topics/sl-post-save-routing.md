# SL — Action หลัง Save / Post (routing ปลายทาง)

> **ที่มา:** decision 2026-06-06 · ใช้ตอนทำ SL-Q + wire routing จริง + หน้า WH/PO/FI/SV ปลายทาง
> **อ่านคู่:** [[queue-dashboard-matrix]] (คิว "รอ" ต่อ module)

## SL-1 ใบเสนอราคา (QT)
| กด | สถานะ | action ต่อ |
|---|---|---|
| 💾 Save Draft | ร่าง | เข้าคิว "ติดตามใบเสนอราคา" (SL-Q) |
| 📤 ส่งขออนุมัติ *(เกินวงเงิน)* | รออนุมัติ | → SL-F1 (Maker≠Checker) → Approved |
| ลูกค้าตอบรับ | ยืนยัน | เปิดปุ่ม "แปลงเป็นใบจอง" |
| ↪ แปลงเป็นใบจอง | — | สร้าง **SL-2** (doc-chain ต่อ) |
| ครบ 30 วัน | หมดอายุ (auto) | — |

## SL-2 ใบจอง (SO) — แยก 2 โหมด (per-document)
| กด/โหมด | สถานะ | action ต่อ |
|---|---|---|
| Confirm · 🔒 **กันสต๊อก** | Confirmed + กันสต๊อก | → คลัง **"รอเบิก" (WH-3)** |
| Confirm · 🛒 **สั่งซื้อล่วงหน้า** | Confirmed | → จัดซื้อ **"รอสั่งซื้อ" (PO-Q → สร้าง PR)** |
| 💰 รับมัดจำ | — | เปิด **SL-3** (ผูกใบจอง) |
| ↪ แปลงเป็นบิล | — | สร้าง **SL-4** |
| ❌ ยกเลิก | ยกเลิก | คืนสต๊อกที่จองไว้ |

## SL-3 ใบมัดจำ (DP)
| กด | สถานะ | action ต่อ |
|---|---|---|
| 💾 Save | ร่าง | — |
| 📥 **Post** | Posted | บันทึก **Customer Ledger** (เงินมัดจำรับล่วงหน้า) |
| (ตอนออก SL-4) | — | **หักมัดจำอัตโนมัติ (SC6)** |

## SL-4 บิลขาย (INV)
| เงื่อนไข | action หลัง Post |
|---|---|
| **Post Invoice** (ทุกกรณี) | ตัดสต๊อก + VAT Output + **ตั้งลูกหนี้ (AR)** + หักมัดจำ |
| ประเภทรับ = 🏪 **รับเอง (กลับบ้านเลย)** | **เบิกสินค้าทันที** (WH-3 · ตัดสต๊อก + ส่งมอบเคาน์เตอร์) — จบที่เคาน์เตอร์ |
| ประเภทรับ = 🚚 **จัดส่งอย่างเดียว** | เบิก + เข้า **คิวจัดส่ง** (WH-3 → รอจัดส่ง) |
| ประเภทรับ = 🔧 **จัดส่ง + ติดตั้ง** | เบิก + จัดส่ง + auto สร้าง **Service Order (SV-1)** |
| 💳 รับชำระ | → **FI-1** รับชำระ AR (RV) |

## SL-CN ใบลดหนี้ (CN)
| กด/โหมด | สถานะ | action ต่อ |
|---|---|---|
| 💾 Save | ร่าง | — |
| *(เกิน threshold)* | รออนุมัติ | → อนุมัติ |
| 📥 **Post** | Posted | **ลด AR (Customer Ledger) + ปรับ VAT Output** |
| โหมด ✏️ ปรับราคา | — | ลดส่วนต่าง · ไม่คืนของ |
| โหมด 📦 คืนบางรายการ / ↩️ คืนทั้งบิล | — | trigger **WH Return** (คืนสต๊อก · คลัง "รอรับคืน") |
| เครดิตที่ได้ | — | หักบิลถัดไป / คืนเงินสด |

## ภาพรวม routing → ปลายทาง (ใช้ตอนทำ Q pages)
| ปลายทาง | มาจาก |
|---|---|
| **คลัง — เบิกทันที** | SL-4 รับเอง |
| **คลัง — รอเบิก (WH-3)** | SL-2 กันสต๊อก · SL-4 จัดส่ง/ติดตั้ง |
| **คลัง — รอรับคืน** | SL-CN คืนสินค้า (WH Return) |
| **จัดซื้อ — รอสั่งซื้อ (PO-Q/PR)** | SL-2 สั่งซื้อล่วงหน้า |
| **การเงิน — รับชำระ (FI-1)** | SL-4 |
| **การเงิน — มัดจำ (Customer Ledger)** | SL-3 |
| **บริการ — Service Order (SV-1)** | SL-4 จัดส่ง+ติดตั้ง |
| **อนุมัติ (SL-F1)** | SL-1/SL-2 เกินวงเงิน · SL-CN เกิน threshold |
