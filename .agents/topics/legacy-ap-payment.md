# Legacy อ้างอิง — การทำเอกสารจ่ายเจ้าหนี้การค้า (AP Payment)

ที่มา: PDF `การทำเอกสารจ่ายเจ้าหนี้การค้า.pdf` (ระบบ ERP เดิม · 4 หน้า · Peerapat ส่ง 2026-07-28)
คู่ขนานฝั่งลูกหนี้: [[legacy-ar-settlement-5-8]] (FI-1 รับชำระลูกหนี้ = legacy 5.8)
หน้า Portal ที่เกี่ยวข้อง: **FI-2 จ่ายชำระเจ้าหนี้** (`fi2-ap-payment-mockup.html`)

## Flow ระบบเดิม (เลขข้อ legacy)
รับเข้าสินค้า **(2.5.1)** → ตั้งหนี้ **(2.5.2)** → **ใบเตรียมจ่าย (4.8)** → **ตัดหนี้ (4.9)**

## 4 วิธีจ่าย (จาก PDF)

### 1. โอนชำระค่าสินค้า (bank transfer)
- ตั้งหนี้ (2.5.2) → ดึงไป **ใบเตรียมจ่าย (4.8)** รอโอนตามวันครบกำหนด
- **LG + SAMSUNG:** ต้องเข้าดูวันครบกำหนดในระบบ **EPP** เอง (ไม่มีใบแจ้งหนี้ส่งมา)
- **เจ้าหนี้ในเมือง:** ชำระทุกสิ้นเดือนของเดือนถัดไป (อาทิตย์แอร์ · สมบูรณ์โกดัง/ไลท์ติ้ง/หน้าร้าน · โรงกลึงพัฒนาการช่าง)
- **เจ้าหนี้อื่น:** มี **ใบวางบิล** ส่งมา (ตัวจริง + วางบิลในไลน์ก่อนเอกสารถึง)
- ใบเตรียมจ่าย (4.8) ดึงเอกสารตั้งหนี้ตาม **อินวอยซ์ที่วางบิลมา**
- ทำเสร็จ → **จัดซื้อ/ศูนย์บริการตรวจสอบ** → **บริหารเซ็นอนุมัติ**
- **ตัดหนี้ (4.9):** วันที่ = วันโอน · ใส่เลขบัญชีที่โอน + จำนวนเงิน

### 2. ชำระเงินสด (cash)
- ส่วนมาก = ค่าอุปกรณ์ศูนย์บริการ / สั่งของออนไลน์ที่เบิกเงินสด
- รับเข้า-ตั้งหนี้เหมือนกัน · ต่างที่ **ตัดชำระเลือกเป็นเงินสด + ใส่หมายเหตุทุกครั้งว่าเบิกเงินสด**

### 3. ตัดหนี้สินค้าที่โอนสด (prepaid deposit)
- โอนสด → ทำเอกสาร **4.2 บันทึกจ่ายเงินมัดจำ** ชำระค่าสินค้าก่อน → ใส่เลขบัญชีโอน + จำนวนที่ข้อ 4.2
- **ตัดหนี้:** ดึงเอกสารตั้งหนี้ + **เลือกเอกสารมัดจำ** → ดึงยอดที่ชำระมาตัดหนี้ (Deposit List)

### 4. ตัดหนี้สินค้าที่จ่ายเช็ค (cheque)
- ส่วนมาก = จ่ายเช็คค่าสินค้า **มิตซู / ไดกิ้น** · ทำเอกสาร **4.2 บันทึกจ่ายเงินมัดจำ**
- เขียนเช็คเสร็จ → ลงทะเบียนเช็คในข้อ **7.1.2 บันทึกทะเบียนเช็คจ่าย** (เลขเช็ค · ยอด · จ่ายให้ · วันที่ · สาขา)
- กลับมาเปลี่ยนการจ่ายเป็น **จ่ายด้วยเช็ค** · ใส่วันครบกำหนด + ยอด · **เลขเช็ค + เลขบัญชีตัดเช็ค ดึงจากทะเบียนเช็คจ่าย**
- ตัดหนี้เหมือนโอนสด

### CN (credit note) หักตัด — ใช้ได้ทุกวิธี
- มี CN → **ดึงมาหักตัดในขั้นตอนตัดหนี้ (4.9) ได้เลย** หรือ **ดึง CN ใส่ในใบเตรียมจ่าย (4.8) ได้**
- CN มาก่อนทำเอกสารจ่าย → ดึงหักได้เลย
- CN มาทีหลัง (ทำเอกสารแล้ว + ยังไม่ถึงวันครบกำหนด) → **เขียนเพิ่มในใบเตรียมจ่าย + แก้ยอดลดยอดชำระได้**

## ช่องว่างที่ควรอุด (เรียงตามผลกระทบ)
1. ✅ **CN offset (เสร็จ 2026-07-28)** — FI-2 เพิ่มปุ่ม "➖ ดึงใบลดหนี้ (PO-CN)" + picker → แถวติดลบ (พื้นแดง · ไม่คิด WHT) หักยอดจ่ายสุทธิเอง · เตือนถ้า CN>หนี้ (จ่ายสุทธิติดลบ) · reuse กลไก empty-row/recompute เดิม · **grill เคาะ: หักได้ทั้ง PO-6 และ FI-2 (ยืดหยุ่น)**
2. 🔴 **จ่ายมัดจำ/โอนสด** — เจ้าหนี้ที่ต้องจ่ายก่อนรับของ (มิตซู/ไดกิ้นบางเคส) → deposit (4.2) แล้วดึงมาตัดหนี้ตอนของเข้า
3. 🟡 **ทะเบียนเช็คจ่าย (7.1.2)** — จ่ายเช็คต้องผูกทะเบียน: เลขเช็ค · เลขบัญชีตัดเช็ค · วันครบกำหนด · สถานะเช็คขึ้นเงิน
4. 🟡 vendor payment-term profile (รอบจ่าย · ใบวางบิล · EPP)

## หมายเหตุแมป legacy→portal
- ใบเตรียมจ่าย 4.8 + ตัดหนี้ 4.9 → รวมใน **FI-2** (Post = ตัด)
- 4.2 บันทึกจ่ายเงินมัดจำ → ควรเป็น **FI-2 โหมดมัดจำ** หรือหน้าแยก (ยังไม่มี)
- 7.1.2 ทะเบียนเช็คจ่าย → ยังไม่มีหน้า (Treasury `tr`?) · FI-2 ควร link ไป
- 2.5.2 ตั้งหนี้ = **PO-6 ใบตั้งหนี้เจ้าหนี้**
