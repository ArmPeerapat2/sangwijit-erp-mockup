## 🏊 Swimlane — คนเกี่ยวข้อง (❓ actor flag · เดา/derive จาก mockup)
WH เป็น **ปลายทางของงานจากโมดูลอื่น** (ซื้อ/ขาย/บริการ) — คนเกี่ยวข้องต่างกันตามแกน:
- **แกนของ-เข้า (รับ):** 🏭 คลัง (ผู้รับ) · 🚚 vendor (ส่งของ) · 🛒 จัดซื้อ (เจ้าของ PO · คนปิดรายการค้างรับ) — รับซื้อ · รับโอนปลายทาง · รับคืน
- **แกนของ-ออก (เบิก/จ่าย):** 🧑‍💼 ขาย/🔧 service (ผู้ขอเบิก) · 🏭 คลัง (ผู้เบิก/หยิบจริง) · 👤 ลูกค้า (ปลายทาง) — **ผู้ขอ ≠ ผู้เบิก** (คล้าย Maker≠Checker แต่ mockup เรียก "ผู้ขอ/ผู้เบิก")
- **แกนโอน (ย้ายคลัง):** 🏭 คลังต้นทาง (Maker · ออก+ship) · 🏭 คลังปลายทาง (รับ) · ผจก.คลัง (Checker ❓ — mockup โชว์ Maker/Checker แต่ไม่อ้าง CF-2.6)
- **แกนควบคุม (นับ+ปรับยอด):** 🏭 คลัง (ผู้วางแผน/ผู้ทำรายการ = Maker) · ผู้นับ (รอมอบหมาย) · **AP-1 ศูนย์อนุมัติรวม (Checker · CF-2.6 · Maker≠Checker)** — ปรับ/ตัดจำหน่ายต้องอนุมัติ

## cross-link (เชื่อมโมดูลอื่น — จาก doc-chain/ตั๋วคิวจริง)
- **เข้า WH-1 (รับ):** PO ใบสั่งซื้อ → GR (`po4` → `wh1` → `po6`) · WH-3 In-Transit → WH-1 รับปลายทาง (TR-In) · PO-8 สินค้าฝาก → WH-1 · SV เคลม/อะไหล่คืน → WH-Q1 → WH-1 (RTN)
- **เข้า WH-2/2R (เบิก):** **SL-4 ใบขาย (SO) → WH-2R ขอเบิก → WH-Q2 → WH-2 เบิก** (`sl4`→`wh2r`→`wh-q2`→`wh2`) · SL-2 จอง → WH-Q2 · **SV-3 เบิกอะไหล่ → WH-Q2 → WH-2** (ISR-0044 · SVJ งานซ่อม)
- **เข้า WH-3/3R (โอน):** SL ขอโอน (สต็อกไม่พอ) → WH-3R → WH-Q2 → WH-3 · SM-3 Vendor Portal V4 เสนอย้ายคลัง → WH-3 (ref PO table)
- **ออก:** WH-1 รับครบ → **PO-6 ตั้งหนี้เจ้าหนี้** · WH-2 Post Shipment → SL จัดส่ง/ติดตั้ง (SL-6/SV) · WH-5 → **AP-1 อนุมัติ** → BC Post · ทุกสาย → **itemLedger (BC)**
